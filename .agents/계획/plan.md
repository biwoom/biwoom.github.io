## STORY ‘이야기불교’ 콘텐츠 분류안

- 계획 버전: v1.0
- 정리일: 2026-11-12
- 대상 프로젝트: Biwoom - 비움 (OL 코어)
- 배포 URL: https://biwoom.github.io/
- 상태: 2026-11-12 상위 카테고리 7개와 소개 파일 구성을 적용했다. 새 작품과 본문은 사용자가 향후 추가한다.

### 방향

STORY의 주제는 **이야기불교**로 한다. 인물의 생애, 전생, 가르침의 일화, 전승, 구법의 여정, 시와 게송처럼 독자가 찾아 읽는 이야기의 성격을 기준으로 상위 카테고리를 구성한다.

기존 ‘불전문학’은 ‘붓다전기’로 바꾸는 방향으로 정리한다. 기존 독립 ‘선시’ 카테고리는 일단 제외하고, 향후 선시 콘텐츠는 ‘시와 게송’ 아래에 작품·시리즈 단위로 배치한다. 콘텐츠가 있는 폴더를 정리할 때에는 원문을 임의로 삭제하지 않는다.

### 추천 카테고리와 예정 콘텐츠

| 카테고리 | 담을 콘텐츠 | 분류 기준 |
|---|---|---|
| **붓다전기** | 마하붓다왐사-미얀마본, 마하붓다왐사-ABT본, 불본행집경, 붓다짜리따 | 붓다의 생애를 중심으로 전개되는 작품 |
| **전생이야기** | 자따까 | 전생의 인연과 행적을 다루는 이야기 |
| **고승전기** | 인도·중국·한국 등 각국 승려 전기 | 한 인물의 생애와 수행 여정을 다루는 작품 |
| **가르침과 일화** | 담마빠다주석을 번역한 ‘담마빠다이야기’, 한국·티벳·인도·베트남·태국 등 각국 고승들의 일화 | 가르침이나 수행의 의미를 전하는 개별 사건과 짧은 이야기 |
| **설화와 전승** | 삼국유사, 정토왕생집, 사찰·불교 인물에 얽힌 전승과 영험 이야기 | 여러 시대에 걸쳐 전해진 이야기와 설화 모음 |
| **구법과 순례** | 스님들의 구법기, 순례기, 불교 유적 방문 기록 | 장소를 이동하며 가르침을 찾는 여정 |
| **시와 게송** | 선시, 경전게송, 한국사찰 주련 | 짧은 운문과 문구를 읽고 음미하는 콘텐츠 |

‘담마빠다이야기’는 **가르침과 일화**, 정확한 문헌명이 확인된 ‘정토왕생집’은 **설화와 전승**에 두는 안으로 정리한다. ‘완생집’이라는 임시 표기는 사용하지 않는다.

### 계층과 배치 원칙

- 기본 계층은 `카테고리 → 작품·시리즈 → 권·편 → 개별 문서`를 유지한다. 상위 카테고리와 작품·시리즈 이름을 구분한다.
- 한 사람의 삶 전체를 따라가는 작품은 ‘고승전기’, 여러 인물의 개별 사건을 모은 작품은 ‘가르침과 일화’에 둔다.
- 설법·수행의 계기를 중심으로 읽는 작품은 ‘가르침과 일화’, 전해지는 이야기와 문화적 배경을 중심으로 읽는 작품은 ‘설화와 전승’에 둔다.
- 한 문헌은 전체의 중심 성격에 따라 한 카테고리에 둔다. 붓다짜리따는 운문 형식이어도 ‘붓다전기’에 두고, 삼국유사처럼 여러 성격의 이야기가 섞인 작품도 하나의 시리즈로 유지한다.
- 국가·시대·종파는 작품 소개와 필요한 개별 문서의 선택적 태그로 표현한다. 작품·카테고리의 태그를 하위 문서에 자동 상속하지 않는다.
- 카테고리와 작품·시리즈의 `index.md`에 제목과 소개를 작성한다. 새 카테고리·작품은 콘텐츠 준비 순서에 맞춰 추가하며, 원고가 없는 작품의 본문을 임의로 만들지 않는다.

### 계층과 배치 원칙

- 기본 계층은 `카테고리 → 문헌·시리즈 → 자료 구분 → 개별 자료`를 유지한다. 번역과 연구는 독립된 자료 구분으로 관리하고 권별 대응을 강제하지 않는다.
- 각 카테고리의 소문자 `index.md`에 제목과 소개를 작성한다. 카테고리 소개는 메타정보로 취급하고 본문 문헌·자료 수에 포함하지 않는다.
- 문헌·시리즈 폴더에도 필요하면 `index.md`를 두어 작품 소개와 서지정보를 기록한다. 원고가 준비되지 않은 작품의 본문이나 예시 번역을 임의로 만들지 않는다.
- 한 문헌은 중심 성격에 따라 한 카테고리에 배치한다. 여러 범주와 관련된 경우 소개글·상대 링크·필요한 개별 문서의 선택적 태그로 연결한다. 카테고리·문헌 소개의 태그를 하위 문서에 자동 상속하지 않는다.
- ‘대승부’는 다른 전문 범주와의 배치 기준을 함께 검토하는 확장 영역으로 운영한다. 문헌이 늘어나면 독립 카테고리의 필요성을 다시 검토한다.
- TEXT의 경론·주석과 STORY의 이야기 콘텐츠는 각 메뉴의 목적에 따라 구분한다. 예를 들어 정토 경론의 번역·연구는 TEXT 정토부, 정토왕생집은 기존 계획에 따라 STORY 설화와 전승에 둔다.
- 기존 중관부와 문헌을 우선 보존한다. 향후 폴더 정리 시 ID·URL·발행일·권리·본문·첨부를 유지하고 상대 링크와 레지스트리를 함께 갱신한다.
