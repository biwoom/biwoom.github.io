# 향후 작업 계획

- 개별 페이지 본문 우상단 문서도구모음에 '각주아이콘' 추가, 원본 마크다운 문서의 각주를 빌드시 각주패널에 표시하도록 구현. 본문에서 각주아이콘 클릭시 각주패널이 열리도록 구현. 각주패널은 목차버튼과 같은 방식으로 구현.
- 개별 페이지 본문 우상단 문서도구모음에 '폰트아이콘' 추가. 이 아이콘 클릭시 아이콘 하단에 본문제목과 본문폰트 사이즈를 조정할 수 있는 슬라이더패널이 열림. 슬라이더로 조정시 본문제목과 본문폰트 사이즈가 실시간으로 조정되도록 구현.
- ASTRO glob() 로더 기능활용하여 프로젝트 루트로 content 폴더 이동하고 ASTRO 프로젝트 소스크드는 ol-core 폴더 내부로 이동.
- 공개사이트의 브랜드 주소를 borido.org 로 변경. 깃헙페이지에도 개인도메인을 연결한다.
- 미디어 페이지 구현. 미디어페이지는 홈 메뉴에는 숨김. 홈 랜딩 페이지 .ol-stat 섹션에 미디어 섹션추가하여 미디어자산 개수 표시. 미디어페이지 링크로 이동할 수 있게 함. 또 푸터영역에 미디어 링크를 추가하여 미디어페이지로 이동할 수 있도록 함. 미디어 폴더 하위 첫번재 폴더명을 카테고리로 활용. 이 카테고리 이요하여 미디어페이지에서 이미지 리스트 출력할 때 카테고리버튼을 표시. 이미지 리스트 형식은 masonry 형식으로 구현. 이미지 클릭시 모달로 이미지 확대보기 가능하도록 구현. 상세페이지 이동하지 않고 해당 미디어 페이지에서 모달로 구현.
- 랜딩페이지 ol-manifest 배경 컬러를 각 메뉴의 포인트 컬러로 랜덤하게 변경되도록 구현. 랜딩페이지 접속시 랜덤하게 변경되도록 구현.
