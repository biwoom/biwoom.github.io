# 보리도 브랜드 정의서

**문서 버전**: v1.13
**최종 업데이트**: 2026-10-31
**기준 프로젝트**: BORIDO HOME (`biwoom.github.io`)
**기준 배포 URL**: `https://biwoom.github.io/`

이 문서는 보리도 프로젝트의 브랜드 정체성을 정의합니다. 보리도를 함께 만들어가는 모든 참여자가 같은 기준을 공유하기 위한 약속이며, 기술적·디자인적·콘텐츠적 결정의 기준점입니다.

## 1. 브랜드 개요

### 1.1 브랜드명

| 항목 | 값 |
|------|------|
| 한글 | 보리도 |
| 영문 | BORIDO |
| 발음 | 보리도 |

### 1.2 핵심 정의

보리도는 불교 문헌, 이야기, 시각 자료, 작업 기록을 디지털 환경에 맞게 정리하고 공개하는 불교 콘텐츠 프로젝트입니다. 백과사전식 나열을 지양하고, 문맥과 개념이 유기적으로 연결된 살아있는 학습 환경을 지향합니다.

현재 BORIDO HOME은 Astro 기반 정적 사이트로 운영되며, 다음 주소를 공식 입구로 사용합니다.

```txt
https://biwoom.github.io/
```

### 1.3 브랜드 소개

보리도는 불교 문헌과 이야기, 작업 기록을 함께 읽고 나누는 열린 불교 콘텐츠 프로젝트입니다.

## 2. 브랜드와 기술 이름

**BORIDO(보리도)**는 독자에게 보여주는 프로젝트와 사이트의 이름입니다. **OL**은 이 사이트를 운영하는 소스코드 코어의 이름으로 사용합니다.

현재 공개 주소는 `https://biwoom.github.io/`입니다. `borido.org`는 향후 이전을 계획한 주소이며, 실제 주소와 배포 설정 변경은 별도로 진행합니다.

---

### 2.1 로고 사용

공식 심볼은 제공된 004(흰색 단색)와 006(금색) 원본을 사용합니다. 흰색 단색 로고(004)는 검정 라운딩 박스 안의 상단·푸터 로고와 파비콘·공유 이미지에 사용합니다. 금색 원본(006)은 보조 자산으로 보관합니다. 원본 파일은 `public/brand/`에 보관합니다.

## 3. 존재 이유

보리도의 출발점은 기술이 아닙니다.

> "나는 왜 불교 콘텐츠를 만들고 싶은가?"

그 답은 법을 만났을 때의 기쁨, 괴로움의 감소, 자비와 이타심, 존재에 대한 통찰, 명상을 통한 고요함과 자유를 다른 사람들과 나누고 싶다는 마음입니다.

따라서 보리도의 핵심은 정보 전달이 아니라 **고통 감소와 삶의 전환을 돕는 경험**입니다.

모든 결정의 기준이 되는 질문은 다음입니다.

> **사람들이 이 경험을 통해 정말 더 자유로워지는가?**

## 4. 브랜드 철학

### 4.1 핵심 가치

**연결(Connection)**  
문헌과 이야기의 맥락을 연결해 서로를 이해하는 데 도움을 줍니다.

**깊이(Depth)**  
가르침과 자료를 차분하게 읽고 깊이 탐구합니다.

**여정(Journey)**  
독자가 자신의 관심과 속도에 맞춰 배우고 실천할 수 있도록 돕습니다.

### 4.2 디자인 철학

**최소주의**  
덜어낼수록 더 많이 담는다는 태도를 따릅니다.

**유기성**  
정적 데이터베이스가 아닌, 콘텐츠가 서로 연결되는 구조를 지향합니다.

**개방성**  
로그인 장벽 없이 접근할 수 있어야 합니다. 지식은 열려 있어야 하며, 공개 가능한 결과물은 가능한 한 공개합니다.

### 4.3 문사수

보리도는 단순 지식 관리 시스템이 아니라 문사수 환경에 가깝습니다.

- **문(聞)**: 불교 이야기를 읽고 듣는다.
- **사(思)**: 질문하고, 사유하고, 연결하고, 삶과 대조한다.
- **수(修)**: 명상하고, 실천하고, 삶 속에서 체화한다.

## 5. 브랜드 체계

보리도는 하나의 앱이 아니라 역할이 분리된 체계입니다.

### 5.1 현재 BORIDO HOME 제품 구조

| 제품 | 역할 |
|------|------|
| **BORIDO HOME** | TEXT·STORY·BLOG를 연결하는 시작 화면 |
| **BORIDO TEXT** | 문헌별 번역·연구·시각자료를 카테고리와 자료 구분으로 탐색 |
| **BORIDO STORY** | 불교 인물·설화·가르침을 이야기 형식으로 읽기 |
| **BORIDO BLOG** | 집필·개발 과정과 생각의 기록 |

상단은 `HOME / TEXT / STORY (+ BLOG)`로 구성합니다. DESIGN·NET의 전용 메뉴와 엔터티·온톨로지 기능은 폐지했습니다. 기존 시각자료는 TEXT의 일반 자료로, 필요한 설명은 참고 문서로 보존합니다. 과거 공개 주소 일부에는 새 자료로 이동하는 안내만 남깁니다.

### 5.2 현재 저장소와 집필 구조

```text
src/content/                 ← Obsidian 보관함
├── text/카테고리/문헌/자료구분/문서.md
├── story/시리즈/파트/문서.md
├── blog/기록.md
└── pages/brand.md
```

폴더·파일 이름의 `001.` 같은 접두어는 순서로 사용하고 화면에서는 숨깁니다. 제목·본문만 있는 Markdown도 읽을 수 있으며, 소속·요약·목차 등은 자동 처리합니다. 폴더 소개 문서는 선택 사항입니다. 문헌의 자료 구분 버튼은 해당 구분의 첫 자료로 이동하고, 전체 목록은 펼침 목록으로 제공합니다.

### 5.3 기술 원칙

- **정적 배포**: BORIDO HOME은 Astro 정적 사이트로 빌드하여 GitHub Pages에 배포합니다.
- **콘텐츠 원본 우선**: 사람이 직접 관리하는 원본은 `src/content/` 안에 둡니다.
- **자산 파생 원칙**: `public/generated/`는 빌드 전 동기화로 생성되는 파생물입니다.
- **검색 가능성**: Pagefind 인덱스를 통해 정적 사이트 안에서 검색을 제공합니다.
- **개방성**: 공개 가능한 자료와 개발 기록은 가능한 한 사이트와 저장소에 남깁니다.

## 6. 디자인 시스템

### 6.1 핵심 원칙

보리도의 디자인은 사용자가 디자인 자체보다 콘텐츠에 집중하도록 돕는 것을 목표로 합니다.

```txt
모던        → 무채색 베이스 + 정확한 1px 보더
심플        → 장식 제거, 충분한 여백, 명확한 위계
세련        → 정밀한 간격, 일관된 radius
질리지 않음 → 개인 취향이 강한 컬러 사용 지양
```

### 6.2 색상

현재 BORIDO HOME은 CSS 토큰 기반 라이트/다크 모드를 사용합니다.

| 용도 | 라이트 | 다크 |
|------|--------|------|
| 배경 | `#FFFFFF` 계열 | `#0A0A0A` 계열 |
| 본문 | neutral ink | light neutral ink |
| 보조 텍스트 | muted neutral | muted light neutral |
| 테두리 | neutral border | dark border |

정확한 값은 `src/styles/tokens.css`와 관련 CSS 파일을 기준으로 합니다.

### 6.2.1 메뉴별 포인트 컬러

흑백 바탕과 검정 본문을 유지하며 HOME은 `#00d3f3`, TEXT는 `#f0b100`, STORY는 `#7ccf00`을 포인트 컬러로 사용합니다. 포인트 컬러는 선택 상태·버튼·강조선에 적용합니다. HOME과 TEXT·STORY 메뉴 첫 화면의 히어로에는 낮은 농도의 포인트 컬러 그라디언트를 사용합니다. TEXT·STORY 카테고리 상세 히어로는 포인트 컬러를 4% 섞은 옅은 단색 배경과 하단 구분선을 사용합니다. 메뉴 첫 화면의 카테고리 카드와 카테고리 상세의 시리즈 행도 같은 4% 배경을 사용하고, 마우스 호버·키보드 포커스에서는 8%로 강조합니다. 시리즈·개별 문서 히어로는 배경색과 그라디언트 없이 표시합니다. BLOG는 기존 흑백 스타일을 유지합니다. 밝은 포인트 배경 위에는 검정 글자를 사용합니다.

### 6.3 타이포그래피

한국어 본문의 가독성을 우선합니다. 현재 사이트는 `Pretendard`를 기본 외부 폰트로 사용하고, `Noto Sans KR`, `Inter`는 CSS fallback stack에서 함께 동작합니다. 본문과 UI 라벨은 공통 타이포그래피 토큰을 기준으로 통일합니다.

TEXT·STORY 히어로 제목은 데스크탑 40px, 모바일(화면 너비 900px 이하) 30px로 표시합니다. 카테고리 목록과 카테고리별 시리즈 목록은 컨테이너 최대 너비 1200px, 좌우 패딩 32px를 사용하고 제목과 설명을 좌측 정렬합니다.

카테고리 상세 히어로의 위·아래 패딩은 데스크탑 40px·28px, 모바일 28px·20px입니다. 개별 문서 히어로는 데스크탑 20px·16px, 모바일 16px·12px로 줄이고, 아래 여백은 20px를 사용합니다. 제목·설명 간격은 8~12px로 정리합니다. 시리즈 히어로는 기존 배경과 정렬을 유지하며, 위·아래 패딩은 데스크탑 24px·20px, 모바일 20px·16px, 아래 여백은 32px를 사용합니다.

태그는 `tags: [수메다, 수밋따]`처럼 분류 접두어 없는 선택적 배열로 작성합니다. 해당 문서에 태그가 있을 때만 제목 아래에 표시하며 시리즈 태그는 상속하지 않습니다. 시리즈의 태그 메뉴·모달은 제거하고, BLOG 메뉴에서는 태그 버튼과 연도 필터를 함께 사용합니다.

### 6.4 간격과 Radius

간격은 4px 단위의 절제된 리듬을 기본으로 하며, 카드와 버튼의 radius는 작고 일관되게 유지합니다.

### 6.5 아이콘

현재 BORIDO HOME은 주로 인라인 SVG 아이콘을 사용합니다. 단일 HTML 산출물이나 독립 자산에서는 외부 런타임 의존을 최소화합니다.

## 7. 브랜드 보이스

### 7.1 톤

- **명상적**: 서두르지 않고 깊이 생각하게 합니다.
- **초대적**: 강요하지 않고 탐험을 권유합니다.
- **지혜로운**: 가르치려 하기보다 통찰을 나눕니다.

### 7.2 언어 스타일

- **간결함**: 짧고 명확한 문장
- **시적임**: 은유와 비유의 절제된 사용
- **존중함**: 사용자를 학습자이자 탐험가로 대우

### 7.3 피해야 할 톤

교조적, 권위적, 과도하게 기술적, 상업적, 마케팅적인 톤은 피합니다.

## 8. 보리도가 하지 않는 것들

이 목록은 기술적 한계가 아니라 의지적 결정입니다.

- 사용자 간 공유/협업을 강제하는 기능
- 배지, 점수, 연속 사용일 같은 게이미피케이션
- 푸시 알림과 학습 리마인더
- 소셜 로그인과 계정 중심 구조
- 사용 통계 수집과 추적
- 추천 알고리즘 중심의 체류 유도
- 광고와 후원 콘텐츠
- 별점, 좋아요, 댓글 등 평가 중심 기능

보리도는 사용자를 더 오래 붙잡아 두는 것보다, 사용자가 자신의 삶으로 더 잘 돌아가는 것을 중요하게 봅니다.

---

## 9. 대상 독자

보리도는 우선 일반 대중을 바라봅니다.

- 불교를 처음 접하는 사람
- 삶의 의미를 찾고 있는 사람
- 마음의 고통을 줄이고 싶은 사람
- 수행에 관심은 있으나 어렵게 느끼는 사람
- 깊은 이야기를 원하지만 지루한 설명은 원하지 않는 사람

따라서 보리도의 콘텐츠는 쉽고, 명료하며, 아름답고, 집중 가능하며, 반복해서 다시 찾아오고 싶어야 합니다.

## 10. 보리도 결정 카드

보리도 개발 중 어떤 결정 앞에 섰을 때 다음 질문을 확인합니다.

> 이 결정이 다음을 만족하는가?

1. 깊은 체류를 돕는가, 빠른 소비를 부추기는가?
2. 사용자의 사유를 돕는가, 방해하는가?
3. AI가 청하지 않은 개입을 하게 만드는가?
4. 사용자의 기록을 사용자에게 속하게 두는가?
5. 가르침으로부터의 자유로 이끄는가, 가르침에의 집착을 강화하는가?
6. 단순함을 늘리는가, 복잡함을 늘리는가?
7. 사용자가 보리도에 더 오래 머물게 만드는가, 자기 삶으로 더 잘 돌아가게 만드는가?

하나라도 답이 어긋난다면 다시 생각합니다.
