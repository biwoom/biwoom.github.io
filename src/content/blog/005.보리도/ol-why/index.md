# 보리도는 왜 시작되었는가 — 존재 선언문과 브랜드 체계

보리도 프로젝트의 출발점은 기술이 아니었다. 법(法)을 만났을 때의 기쁨, 괴로움의 감소, 자비와 이타심 — 이런 것들을 나누고 싶다는 마음이었다.

## 핵심 질문

> *"사람들이 이 경험을 통해 정말 더 자유로워지는가?"*

이 질문이 보리도의 모든 기술적·디자인적·콘텐츠적 결정의 기준점이다. 보리도는 정보 전달이 아니라, 고통 감소와 삶의 전환을 돕는 경험을 지향한다.

## 브랜드 체계

보리도(BORIDO)는 불교 문헌과 이야기, 기록을 함께 읽고 나누는 프로젝트다.

- **BORIDO TEXT** — 문헌별 번역·연구·시각자료를 카테고리와 자료 구분으로 탐색한다.
- **BORIDO STORY** — 불교의 인물·설화·가르침을 이야기로 읽는다.
- **BORIDO BLOG** — 집필·개발 과정과 생각을 기록한다.

OL은 소스코드 코어의 이름이다. ATLAS는 이전 OL 도구의 개발 이력으로 남으며, 현재 보리도 사이트의 별도 메뉴가 아니다.

## 문사수(聞思修) 환경

보리도는 지식 관리 시스템이 아니라 문사수 환경에 가깝다. 읽고(聞), 사유하고(思), 실천한다(修). 빠른 소비, 과잉 인터랙션, 게임화는 하지 않는다. 대신 깊은 체류, 조용한 탐색, 의미의 여운을 중요하게 여긴다.

## 보리도가 하지 않는 것들

- 게이미피케이션 (배지, 점수, 연속 사용일)
- 푸시 알림, 추천 알고리즘
- 소셜 로그인, 사용 통계
- 광고, 평가 기능 (별점, 좋아요, 댓글)

이 목록은 기술적 한계가 아니라 의지적 결정이다. 가능하지만 하지 않는다.

## 콘텐츠와 기술

현재 콘텐츠는 `src/content/`를 Obsidian 보관함으로 사용해 관리한다. 보리도는 이 자료를 Astro 정적 페이지로 제공하며, 내부 코드에는 OL 이름을 유지한다.

현재 공개 주소는 https://borido.org/ 이다. GitHub Pages를 통해 기존 문서 경로를 유지하며 제공한다.
