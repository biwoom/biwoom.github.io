# 삼론현의 — 여러 논서의 명칭

## 법·사람·비유에서 이름을 짓는 세 방식

다음으로 여러 논서가 이름을 세우는 방식이 다름을 밝힌다. 여러 논서가 이름을 세우는 데에는 세 종류가 있다.

첫째는 법에서 이름을 짓는 것으로 『성실론』 등과 같다. 실은 사제의 이치이고 성은 능히 이루는 글이다. 그러므로 이 법을 성취하기 위하여 이 논서를 지었다고 하니 법에서 이름을 세운 것이다.

둘째는 사람에서 이름을 짓는 것으로 『사리불아비담』 등과 같다. 『지도론』에서는 독자도인이 이 비담을 받아 지녔으므로 『독자비담』이라고도 한다고 하였다.

셋째는 비유에서 이름을 짓는 것으로 『감로미비담』 등과 같다. 또한 하리발마의 스승 구마라타가 지은 『일출론』 등도 그러하다.

```original
次明眾論立名不同門。眾論立名凡有三種。一從法為名。如成實論等。實謂四諦之理。成謂能成之文。故云為成是法故造斯論。謂從法立名也。二從人立名。如舍利弗阿毘曇等。智度論云。犢子道人受持此毘曇。亦名犢子毘曇也。三從喻立名。如甘露味毘曇等。亦如訶梨跋摩師鳩摩羅陀造日出論等也。
```

## 사론이 법에서 이름을 얻는 네 방식

사론이 이름을 세운 것은 모두 법에서 비롯되었으며 사람이나 비유에서 비롯된 것이 아니다. 그 가운데 다시 네 종류를 연다. 『대지도론』은 풀이하는 경에서 이름을 세웠다. 대는 마하이고 지는 반야이며 도는 바라밀이다. 논이 경의 제목을 풀이하므로 풀이되는 것에서 이름을 얻었다. 『중론』은 이치의 진실에서 이름을 세웠고, 『십이문론』은 언교를 이름으로 삼았으며, 『백론』은 게구를 명칭으로 삼았다.[^slx-사론명칭]

[^slx-사론명칭]: 앞 단락의 법·사람·비유는 논서 이름의 유래를 나누는 세 부류이다. 여기서는 사론이 모두 법에서 이름을 취했다고 보고, 다시 경 제목·이치·언교·게구 중 무엇을 근거로 삼는지 나눈다. [앞 단락](#SLX-U000112)

```original
四論立名。並是從法。非人非喻。就中自開四種。大智度論從所釋之經立名。大謂摩訶。智謂般若。度謂波羅蜜。論釋經題。故從所釋為名。中論從理實立名。十二門從言教為目。百論從偈句為稱也。
```

## 통하는 뜻과 이름을 달리한 이유

통틀어 말하면 사론은 중도의 참된 이치를 함께 드러내므로 모두 이치에 의하여 이름을 세울 수 있다. 사론에는 똑같이 언교가 있어 참된 이치를 열어 통하게 하므로 모두 가르침을 명칭으로 삼을 수 있다. 또한 똑같이 게구가 있으므로 모두 게에서 이름을 세울 수 있다. 이제 서로 구별하여 겹치지 않게 하려 하므로 네 부의 차이를 두었다. 그러므로 이름을 세운 방식이 다르다.

```original
若通而為言。四論通顯中道理實。並得就理立名。四論同有言教開通理實。並得以教為稱。同有偈句。通得從偈立名。今欲互相開避。故有四部差別。所以立名不同也。
```
