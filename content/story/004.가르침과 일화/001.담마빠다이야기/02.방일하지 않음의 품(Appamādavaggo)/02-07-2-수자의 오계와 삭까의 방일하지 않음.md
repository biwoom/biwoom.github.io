# 02-07-2 수자의 오계와 삭까의 방일하지 않음
원문서명: 담마빠다 주석서(Dhammapada-aṭṭhakathā) | 저자: 미확정 | 출처: 《담마빠다 주석서》 제1부, VRI CSCD 로마자 XML 3153–3309행

- **품** · 제2품 방일하지 않음의 품(Appamādavaggo)
- **빨리어 표제** · Maghavatthu

<a id="cscd-02-07-u006"></a>
## 에라와나와 네 여인의 다시 태어남

<a id="cscd-02-07-u006-p001"></a>

코끼리는 에라와나라는 신으로 태어났다. 신들의 세계에는 짐승이 없기 때문이다. 그는 동산에 놀러 갈 때마다 신의 모습에서 백오십 요자나 크기의 에라와나 코끼리로 모습을 바꾸었다. 서른세 신을 위해 각각 앉을 수 있는 머리 서른세 개를 만들었다. 머리의 둘레는 세 가우따나 반 요자나[^r3-07]였다. 한가운데에는 삭까를 위해 삼십 요자나에 이르는 수닷사나라는 머리를 만들었다. 수닷사나 머리 위에는 열두 요자나에 이르는 보배 누각이 있었다. 누각 곳곳에 일곱 보배로 만든 높이 한 요자나의 깃발이 솟았고, 가장자리에는 작은 방울을 단 그물이 늘어져 있었다. 산들바람이 불면 방울 소리가 다섯 가지 악기 소리와 어우러진 하늘 노래처럼 울렸다.

[^r3-07]: 이 대목은 머리의 둘레에 두 크기를 붙인다. 요자나 하나가 네 가우따이므로, 세 가우따는 사분의 삼 요자나다. 다른 치수인 반 요자나는 두 가우따에 해당한다.

```original
Hatthī pana erāvaṇo nāma devaputto hutvā nibbatti. Devalokasmiñhi tiracchānagatā na honti. Tasmā so uyyānakīḷāya nikkhamanakāle attabhāvaṃ vijahitvā diyaḍḍhayojanasatiko erāvaṇo nāma hatthī ahosi. So tettiṃsajanānaṃ atthāya tettiṃsa kumbhe māpesi  āvaṭṭena tigāvutaaḍḍhayojanappamāṇe, sabbesaṃ majjhe sakkassa atthāya sudassanaṃ nāma tiṃsayojanikaṃ kumbhaṃ māpesi. Tassa upari dvādasayojaniko ratanamaṇḍapo  hoti. Tattha antarantarā sattaratanamayā yojanubbedhā dhajā uṭṭhahanti. Pariyante kiṅkiṇikajālaṃ olambati. Yassa mandavāteritassa pañcaṅgikatūriyasaddasaṃmisso dibbagītasaddo viya ravo niccharati.
```

<a id="cscd-02-07-u006-p002"></a>

누각 가운데에는 삭까를 위해 한 요자나에 이르는 보석 자리가 마련되어 있었다. 삭까는 거기에 앉았고 서른세 신은 저마다 에라와나가 마련한 머리 위의 보배 자리에 앉았다. 에라와나는 서른세 머리 하나하나에 엄니 일곱 개씩을 만들었다. 엄니마다 길이가 오십 요자나였다. 엄니마다 연못이 일곱 개씩, 연못마다 연꽃 포기가 일곱 개씩, 포기마다 꽃이 일곱 송이씩, 꽃마다 꽃잎이 일곱 장씩 있었다. 꽃잎 하나하나에서 하늘의 여인 일곱 명씩이 춤추었다. 그렇게 코끼리의 엄니마다 오십 요자나에 걸쳐 춤판이 벌어졌다. 신들의 왕 삭까는 이처럼 큰 영화를 누리며 지냈다.


```original
Maṇḍapamajjhe sakkassatthāya yojaniko maṇipallaṅko paññatto hoti, tattha sakko nisīdi. Tettiṃsa devaputtā attano kumbhe ratanapallaṅke nisīdiṃsu. Tettiṃsāya kumbhānaṃ ekekasmiṃ kumbhe satta satta dante māpesi. Tesu ekeko paṇṇāsayojanāyāmo, ekekasmiñcettha dante satta satta pokkharaṇiyo honti, ekekāya pokkharaṇiyā satta satta paduminīgacchāni, ekekasmiṃ gacche satta satta pupphāni honti, ekekasmiṃ pupphe satta satta pattāni, ekekasmiṃ patte satta satta devadhītaro naccanti. Evaṃ samantā paṇṇāsayojanaṭhānesu hatthidantesuyeva naṭasamajjā honti. Evaṃ mahantaṃ yasaṃ anubhavanto sakko devarājā vicarati.
```

<a id="cscd-02-07-u006-p003"></a>

수담마도 죽어서 그곳에 태어났다. 그에게 구백 요자나에 이르는 수담마라는 신들의 회당이 생겨났다. 그보다 아름다운 곳은 없었다고 한다. 신들은 한 달에 여드레를 그곳에 모여 가르침을 들었다. 오늘날에도 아름다운 곳을 보면 “수담마 신들의 회당 같구나”라고 한다.

```original
Sudhammāpi kālaṃ katvā gantvā tattheva nibbatti. Tassā sudhammā nāma nava yojanasatikā devasabhā nibbatti. Tato ramaṇīyataraṃ kira aññaṃ ṭhānaṃ nāma natthi, māsassa aṭṭha divase dhammassavanaṃ tattheva hoti. Yāvajjatanā aññataraṃ ramaṇīyaṃ ṭhānaṃ disvā, ‘‘sudhammā devasabhā viyā’’ti vadanti.
```

<a id="cscd-02-07-u006-p004"></a>

난다도 죽어 그곳에 태어났고, 그에게 오백 요자나에 이르는 난다라는 연못이 생겨났다. 찟따도 죽어 그곳에 태어났고, 그에게 오백 요자나에 이르는 찟따라따 숲이 생겨났다. 신들은 죽음의 징조가 나타난 동료를 그 숲에 데려가 즐거움에 빠지게 했다.

```original
Nandāpi kālaṃ katvā gantvā tattheva nibbatti, tassā pañcayojanasatikā nandā nāma pokkharaṇī nibbatti. Cittāpi kālaṃ katvā gantvā tattheva nibbatti, tassāpi pañcayojanasatikaṃ cittalatāvanaṃ nāma nibbatti, tattha uppannapubbanimitte devaputte netvā mohayamānā vicaranti.
```

<a id="cscd-02-07-u006-p005"></a>

수자는 죽어서 산골짜기에 사는 왜가리로 태어났다. 삭까가 자신을 시중들던 여인들이 어디에 태어났는지 살피다가 ‘수담마도 여기에 태어났고 난다와 찟따도 그러한데, 수자는 어디에 태어났을까?’ 하고 생각했다. 수자가 산골짜기에 태어난 것을 보고 ‘어리석게도 아무 공덕도 짓지 않아 이제 짐승으로 태어났구나. 공덕을 짓게 하여 여기로 데려와야겠다’고 생각했다. 삭까는 신의 모습을 벗고 수자가 알아볼 수 없는 모습으로 다가가 물었다.

```original
Sujā pana kālaṃ katvā ekissā girikandarāya ekā bakasakuṇikā hutvā nibbatti. Sakko attano paricārikā olokento ‘‘sudhammā idheva nibbattā, tathā nandā ca cittā ca, sujā nu kho kuhiṃ nibbattā’’ti cintento taṃ tattha nibbattaṃ disvā, ‘‘bālā kiñci puññaṃ akatvā idāni tiracchānayoniyaṃ nibbattā, idāni pana taṃ puññaṃ kāretvā idhānetuṃ vaṭṭatī’’ti attabhāvaṃ vijahitvā aññātakavesena tassā  santikaṃ gantvā,
```

<a id="cscd-02-07-u006-p006"></a>

“여기서 무엇을 하며 지내느냐?”

```original
‘‘kiṃ karontī idha vicarasī’’ti pucchi.
```

<a id="cscd-02-07-u006-p007"></a>

“어른은 누구십니까?”

```original
‘‘Ko pana tvaṃ, sāmī’’ti?
```

<a id="cscd-02-07-u006-p008"></a>

“나는 네 남편 마가다.”

```original
‘‘Ahaṃ te sāmiko magho’’ti.
```

<a id="cscd-02-07-u006-p009"></a>

“어디에 태어나셨습니까, 어른?”

```original
‘‘Kuhiṃ nibbattosi, sāmī’’ti?
```

<a id="cscd-02-07-u006-p010"></a>

“나는 삼십삼천에 태어났다. 네 벗들이 어디에 태어났는지 아느냐?”

```original
‘‘Ahaṃ tāvatiṃsadevaloke nibbatto’’. ‘‘Tava sahāyikānaṃ pana nibbattaṭṭhānaṃ jānāsī’’ti?
```

<a id="cscd-02-07-u006-p011"></a>

“모릅니다, 어른.”

```original
‘‘Na jānāmi, sāmī’’ti.
```

<a id="cscd-02-07-u006-p012"></a>

“그들도 내 곁에 태어났다. 그 벗들을 만나 보아라.”

```original
‘‘Tāpi mameva santike nibbattā, passissasi tā sahāyikā’’ti.
```

<a id="cscd-02-07-u006-p013"></a>

“제가 어떻게 그곳에 갑니까?”

```original
‘‘Kathāhaṃ tattha gamissāmī’’ti?
```

<a id="cscd-02-07-u006-p014"></a>

삭까는 “내가 너를 데려가마” 하며 손바닥에 올려 신들의 세계로 데려갔다. 난다의 연못가에 수자를 내려놓고 세 여인에게 “벗인 수자를 만나 보아라”라고 했다. “신이시여, 어디에 있습니까?” “난다의 연못가에 있다.” 셋은 가서 “아이고, 이 아가씨가 몸을 꾸민 결과가 이렇구나. 이제 부리를 보렴. 발을 보렴. 다리를 보렴. 참으로 아름다운 몸이구나!” 하고 놀린 뒤 떠났다.

```original
Sakko ‘‘ahaṃ taṃ tattha nessāmī’’ti vatvā hatthatale ṭhapetvā devalokaṃ netvā nandāya pokkharaṇiyā tīre vissajjetvā itarāsaṃ tissannaṃ ārocesi – ‘‘tumhākaṃ sahāyikaṃ sujaṃ passissathā’’ti. ‘‘Kuhiṃ sā, devā’’ti? ‘‘Nandāya pokkharaṇiyā tīre ṭhitā’’ti āha. Tā tissopi gantvā, ‘‘aho ayyāya evarūpaṃ attabhāvamaṇḍanassa phalaṃ, idānissā tuṇḍaṃ passatha, pāde passatha, jaṅghā passatha, sobhati vatassā attabhāvo’’ti keḷiṃ katvā pakkamiṃsu.
```

<a id="cscd-02-07-u007"></a>
## 수자가 오계를 지키다

<a id="cscd-02-07-u007-p001"></a>

삭까가 다시 수자에게 와서 “벗들을 보았느냐?” 하고 물었다. 수자가 “보았습니다. 저를 놀리고 떠났습니다. 저를 원래 있던 곳으로 데려다주십시오” 하자, 삭까는 산골짜기로 돌아가 수자를 물에 놓아준 뒤 물었다.

```original
Puna sakko tassā santikaṃ gantvā, ‘‘diṭṭhā te sahāyikā’’ti vatvā ‘‘diṭṭhā maṃ uppaṇḍetvā gatā, tattheva maṃ nehī’’ti vutte taṃ tattheva netvā udake vissajjetvā,
```

<a id="cscd-02-07-u007-p002"></a>

“그들이 누리는 영화를 보았느냐?”

```original
‘‘diṭṭhā te tāsaṃ sampattī’’ti pucchi.
```

<a id="cscd-02-07-u007-p003"></a>

“보았습니다, 신이시여.”

```original
‘‘Diṭṭhā, devā’’ti?
```

<a id="cscd-02-07-u007-p004"></a>

“너도 그곳에 태어날 방도를 마련해야 한다.”

```original
‘‘Tayāpi tattha nibbattanūpāyaṃ kātuṃ vaṭṭatī’’ti.
```

<a id="cscd-02-07-u007-p005"></a>

“제가 무엇을 해야 합니까, 신이시여?”

```original
‘‘Kiṃ karomi, devā’’ti?
```

<a id="cscd-02-07-u007-p006"></a>

“내가 일러 주는 계를 지키겠느냐?”

```original
‘‘Mayā dinnaṃ ovādaṃ rakkhissasī’’ti.
```

<a id="cscd-02-07-u007-p007"></a>

“지키겠습니다, 신이시여.”

```original
‘‘Rakkhissāmi, devā’’ti.
```

<a id="cscd-02-07-u007-p008"></a>

삭까는 수자에게 오계[^r3-08]를 일러 주고 “방일하지 말고 지켜라” 하고 떠났다. 그때부터 수자는 이미 죽은 물고기만 찾아 먹었다. 며칠 뒤 삭까는 수자가 계를 지키는지 알아보려고, 모래밭에서 배를 드러내고 누운 죽은 물고기 모습을 했다. 수자는 죽은 물고기인 줄 알고 집었다. 수자가 삼키려는데 물고기가 꼬리를 움직였다. 수자는 살아 있는 물고기임을 알고 물에 놓아주었다.

[^r3-08]: 살생, 도둑질, 그릇된 성행위, 거짓말, 정신을 흐리게 하는 술을 삼가는 다섯 가지 생활 규범이다. 여기서 수자는 살아 있는 물고기를 놓아주어 첫째 계를 지킨다.

```original
Athassā pañca sīlāni datvā, ‘‘appamattā rakkhāhī’’ti vatvā pakkāmi. Sā tato paṭṭhāya sayaṃmatamacchakeyeva pariyesitvā khādati. Sakko katipāhaccayena tassā vīmaṃsanatthāya gantvā, vālukāpiṭṭhe matamacchako viya hutvā uttāno nipajji. Sā taṃ disvā ‘‘matamacchako’’ti saññāya aggahesi. Maccho gilanakāle naṅguṭṭhaṃ cālesi. Sā ‘‘sajīvamacchako’’ti udake vissajjesi.
```

<a id="cscd-02-07-u007-p009"></a>

조금 뒤 삭까는 다시 수자 앞에서 죽은 물고기처럼 배를 드러내고 누웠다. 수자는 또 죽은 물고기인 줄 알고 집었다. 수자가 삼키려는데 물고기가 꼬리 끝을 움직였다. 수자는 살아 있는 것을 보고 놓아주었다. 삭까는 모두 세 차례 살펴 수자가 계를 잘 지킨다는 것을 알고, 자신의 모습을 드러내며 말했다. “너를 시험하려고 왔다. 계를 잘 지키는구나. 그렇게 지키면 오래지 않아 내 곁에 태어날 것이다. 방일하지 말아라.” 그리고 떠났다.

```original
So thokaṃ vītināmetvā puna tassā purato uttāno hutvā nipajji. Puna sā ‘‘matamacchako’’ti saññāya gahetvā gilanakāle agganaṅguṭṭhaṃ cālesi. Taṃ disvā ‘‘sajīvamaccho’’ti vissajjesi. Evaṃ tikkhattuṃ vīmaṃsitvā ‘‘sādhukaṃ sīlaṃ rakkhatī’’ti attānaṃ jānāpetvā ‘‘ahaṃ tava vīmaṃsanatthāya āgato, sādhukaṃ sīlaṃ rakkhasi, evaṃ rakkhamānā  na cirasseva mama santike nibbattissasi, appamattā hohī’’ti vatvā pakkāmi.
```

<a id="cscd-02-07-u007-p010"></a>

그 뒤로도 수자는 죽은 물고기를 구할 때도 있고 못 구할 때도 있었다. 얼마 못 가 먹이를 얻지 못하고 몸이 말라 죽었다. 계를 지킨 과보로 바라나시에서 옹기장이의 딸로 태어났다. 수자가 열다섯이나 열여섯쯤 되었을 때 삭까는 수자가 어디에 태어났는지 살피다가 그곳을 알고 ‘이제 그곳에 가야겠다’고 생각했다. 수레에 오이처럼 보이는 일곱 보배를 가득 싣고 바라나시에 들어갔다. “여러분, 오이 받아 가시오. 받아 가시오” 하고 외치며 거리를 돌았다.

```original
Sā  tato paṭṭhāya pana sayaṃmatamacchaṃ labhati vā, na vā. Alabhamānā katipāhaccayeneva sussitvā kālaṃ katvā tassa sīlassa phalena bārāṇasiyaṃ kumbhakārassa dhītā hutvā nibbatti. Athassā pannarasasoḷasavassuddesikakāle sakko ‘‘kuhiṃ nu kho sā nibbattā’’ti āvajjento disvā, ‘‘idāni mayā tattha gantuṃ vaṭṭatī’’ti eḷālukavaṇṇena paññāyamānehi sattahi ratanehi yānakaṃ pūretvā taṃ pājento bārāṇasiṃ pavisitvā, ‘‘ammatātā, eḷālukāni gaṇhatha gaṇhathā’’ti ugghosento vīthiṃ paṭipajji.
```

<a id="cscd-02-07-u007-p011"></a>

녹두와 검정콩 등을 가지고 온 사람에게 “값을 받고 파는 것이 아니오”라고 했다. “그러면 어떻게 줍니까?” “계를 지키는 여자에게 주겠소.” “어른, 계가 어떤 것입니까? 검은 것입니까, 푸른 것입니까?” “그대들은 계가 어떤 것인지도 모르는데 어떻게 지키겠소? 계를 지키는 여자에게 주겠소.” “어른, 저 옹기장이의 딸은 자기가 계를 지킨다고 말합니다. 그에게 주십시오.”

```original
Muggamāsādīni gahetvā āgate pana ‘‘mūlena na demī’’ti vatvā, ‘‘kathaṃ desī’’ti vutte, ‘‘sīlarakkhikāya itthiyā dammī’’ti āha. ‘‘Sīlaṃ nāma, sāmi, kīdisaṃ, kiṃ kāḷaṃ, udāhu nīlādivaṇṇa’’nti? ‘‘Tumhe ‘sīlaṃ kīdisa’ntipi na jānātha, kimeva naṃ rakkhissatha, sīlarakkhikāya pana dassāmī’’ti. ‘‘Sāmi, esā kumbhakārassa dhītā ‘sīlaṃ rakkhāmī’ti vicarati, etissā dehī’’ti.
```

<a id="cscd-02-07-u007-p012"></a>

수자가 “그러면 저에게 주십시오, 어른” 하자 삭까는 “그대는 누구요?” 했다. “저는 오계를 저버리지 않는 사람입니다.” 삭까는 “이것들은 그대에게 주려고 가져왔소” 하며 수레를 몰아 수자의 집에 갔다. 남들이 가져갈 수 없도록 해 놓고, 수자에게 오이처럼 보이는 하늘의 재물을 건넨 뒤 자기 모습을 드러냈다. “이 재물로 살아가거라. 오계를 하나도 깨뜨리지 말고 온전히 지켜라.” 그러고는 떠났다.

```original
Sāpi naṃ ‘‘tena hi mayhaṃ dehi, sāmī’’ti āha. ‘‘Kāsi tva’’nti? ‘‘Ahaṃ avijahitapañcasīlā’’ti. ‘‘Tuyhamevetāni  mayā ānītānī’’ti yānakaṃ pājento tassā gharaṃ gantvā aññehi anāhariyaṃ katvā eḷālukavaṇṇena devadattiyaṃ dhanaṃ datvā attānaṃ jānāpetvā, ‘‘idaṃ te jīvitavuttiyā dhanaṃ, pañcasīlāni akhaṇḍādīni katvā rakkhāhī’’ti vatvā pakkāmi.
```

<a id="cscd-02-07-u008"></a>
## 수자의 혼인과 삭까의 방일하지 않음

<a id="cscd-02-07-u008-p001"></a>

수자는 옹기장이의 딸로 살다 죽어서 삭까와 적대하는 아수라 우두머리의 딸로 태어났다. 두 생에 걸쳐 계를 잘 지킨 덕에 황금빛 몸과 비할 데 없는 아름다움을 갖추었다. 아수라 왕 웨빠찟띠는 혼인을 청하러 오는 아수라들에게 “너희는 내 딸에게 어울리지 않는다” 하며 아무에게도 딸을 주지 않았다. ‘딸이 자기에게 맞는 남편을 고를 것이다’ 하고 아수라 무리를 모은 뒤 “네게 맞는 남편을 골라라” 하며 딸의 손에 꽃다발을 쥐여 주었다.

```original
Sāpi tato cavitvā asurabhavane asurajeṭṭhakassa dhītā hutvā sakkassa verighare nibbatti. Dvīsu pana attabhāvesu sīlassa surakkhitattā abhirūpā ahosi suvaṇṇavaṇṇā asādhāraṇāya rūpasiriyā samannāgatā. Vepacittiasurindo āgatāgatānaṃ asurānaṃ ‘‘tumhe mama dhītu anucchavikā na hothā’’ti taṃ kassaci adatvā, ‘‘mama dhītā attanāva attano anucchavikaṃ sāmikaṃ gahessatī’’ti asurabalaṃ sannipātāpetvā, ‘‘tuyhaṃ anucchavikaṃ sāmikaṃ gaṇhā’’ti tassā, hatthe pupphadāmaṃ adāsi.
```

<a id="cscd-02-07-u008-p002"></a>

그때 삭까는 수자가 태어난 곳을 살피다가 그 일을 알았다. ‘지금 가서 데려와야겠다’고 생각하고 늙은 아수라의 모습으로 바꾸고 무리 가장자리에 섰다. 수자가 이리저리 살피다가 그를 보자 전생에 함께 산 인연으로 사랑이 일어나 큰물처럼 마음을 덮었다. ‘이분이 내 남편이다’ 하고 그에게 꽃다발을 던졌다. 아수라들은 “우리 왕이 그 오랜 세월 딸에게 맞는 사람을 찾지 못하더니 이제 찾았군. 이 늙은이가 딸의 할아버지보다도 나이가 많은데 참 어울리는군” 하며 민망해하며 물러갔다.

```original
Tasmiṃ khaṇe sakko tassā nibbattaṭṭhānaṃ olokento taṃ pavattiṃ ñatvā, ‘‘idāni mayā gantvā taṃ ānetuṃ vaṭṭatī’’ti mahallakaasuravaṇṇaṃ nimminitvā gantvā parisapariyante aṭṭhāsi. Sāpi ito cito ca olokentī taṃ diṭṭhamattāva pubbasannivāsavasena uppannena pemena mahogheneva ajjhotthaṭahadayā hutvā, ‘‘eso me sāmiko’’ti tassa upari pupphadāmaṃ khipi. Asurā ‘‘amhākaṃ rājā ettakaṃ kālaṃ dhītu anucchavikaṃ alabhitvā idāni labhi, ayamevassa dhītu pitāmahato mahallako anucchaviko’’ti lajjamānā  apakkamiṃsu.
```

<a id="cscd-02-07-u008-p003"></a>

삭까는 수자의 손을 잡고 “내가 삭까다!” 하고 외치며 하늘로 솟았다. 아수라들은 “늙은 삭까에게 속았구나” 하며 뒤쫓았다. 마부 마딸리는 웨자얀따 수레를 몰고 와 길목에서 기다리고 있었다. 삭까는 수자를 수레에 태우고 신들의 도성으로 향했다. 시빨리 숲에 이르렀을 때 어린 가룰라[^r3-09]들이 수레 소리에 놀라 울었다. 삭까가 소리를 듣고 마딸리에게 물었다.

[^r3-09]: 이야기에서 신들의 세계에 사는 큰 새다. 뒤에 나오는 수빤나도 이 새를 가리킨다.

```original
Sakkopi taṃ hatthe gahetvā ‘‘sakkohamasmī’’ti naditvā ākāse pakkhandi. Asurā ‘‘vañcitamhā jarasakkenā’’ti taṃ anubandhiṃsu. Mātali, saṅgāhako vejayantarathaṃ āharitvā antarāmagge aṭṭhāsi. Sakko taṃ tattha āropetvā devanagarābhimukho pāyāsi. Athassa sippalivanaṃ sampattakāle rathasaddaṃ sutvā bhītā garuḷapotakā  viraviṃsu. Tesaṃ saddaṃ sutvā sakko mātaliṃ pucchi –
```

<a id="cscd-02-07-u008-p004"></a>

“무엇이 우는가?”

```original
‘‘ke ete viravantī’’ti?
```

<a id="cscd-02-07-u008-p005"></a>

“신이시여, 어린 가룰라들입니다.”

```original
‘‘Garuḷapotakā, devā’’ti.
```

<a id="cscd-02-07-u008-p006"></a>

“왜 우는가?”

```original
‘‘Kiṃ kāraṇā’’ti?
```

<a id="cscd-02-07-u008-p007"></a>

“수레 소리를 듣고 죽을까 두려워서입니다.”

```original
‘‘Rathasaddaṃ sutvā maraṇabhayenā’’ti.
```

<a id="cscd-02-07-u008-p008"></a>

“나 한 사람 때문에 많은 새가 수레에 치여 죽어서는 안 된다. 수레를 돌려라.”

```original
‘‘Maṃ ekaṃ nissāya ettako dijo rathavegena vicuṇṇito mā nassi, nivattehi ratha’’nti.
```

<a id="cscd-02-07-u008-p009"></a>

마딸리는 신다와 말 천 마리에게 채찍으로 신호해 수레를 돌렸다. 아수라들은 그 모습을 보고 ‘늙은 삭까가 우리 도성에서부터 달아나더니 이제 수레를 돌렸다. 틀림없이 지원군을 얻었을 것이다’ 하고 돌아섰다. 왔던 길로 아수라 도성에 들어가 다시는 고개를 들지 못했다.

```original
Sopi sindhavasahassassa daṇḍakasaññaṃ datvā rathaṃ nivattesi. Taṃ disvā asurā ‘‘jarasakko asurapurato paṭṭhāya palāyanto idāni rathaṃ nivattesi, addhā tena upatthambho laddho bhavissatī’’ti nivattetvā āgamanamaggeneva asurapuraṃ pavisitvā puna sīsaṃ na ukkhipiṃsu.
```

<a id="cscd-02-07-u008-p010"></a>

삭까는 아수라의 딸 수자를 신들의 도성으로 데려가 두 꼬띠 반[^r3-10]에 이르는 하늘 여인들 중 으뜸 자리를 주었다. 수자가 삭까에게 소원을 청했다. “대왕이시여, 이 신들의 세계에는 제 부모도 형제자매도 없습니다. 어디를 가시든 저도 데려가 주십시오.” 삭까는 좋다고 약속했다.

[^r3-10]: 꼬띠는 천만을 뜻한다. 두 꼬띠 반은 2,500만이다.

```original
Sakkopi sujaṃ asurakaññaṃ devanagaraṃ netvā aḍḍhateyyānaṃ accharākoṭīnaṃ jeṭṭhikaṭṭhāne ṭhapesi. Sā sakkaṃ varaṃ yāci – ‘‘mahārāja, mama imasmiṃ devaloke mātāpitaro vā bhātikabhaginiyo vā natthi, yattha yattha gacchasi, tattha tattha maṃ gahetvāva  gaccheyyāsī’’ti. So ‘‘sādhū’’ti tassā paṭiññaṃ adāsi.
```

<a id="cscd-02-07-u008-p011"></a>

그때부터 찟따빠딸리 나무에 꽃이 피면 아수라들은 ‘우리가 태어났던 곳에서 하늘의 빠릿찻따까 나무가 꽃필 때로구나’ 하며 싸우러 하늘로 올라왔다. 삭까는 바다 아래쪽은 나가들에게 지키게 했다. 그 위는 차례로 수빤나들, 꿈반다들, 약카들, 사천왕에게 맡겼다. 맨 위에서는 침입을 막으려고 신들의 도성 성문들에 금강저를 손에 든 인다의[^r3-11] 모습을 새겨 세웠다. 아수라들은 나가 등을 이기고 올라와도 멀리서 인다의 형상을 보면 “삭까가 나왔다” 하고 달아났다.

[^r3-11]: 인다(*Inda*)는 삭까의 또 다른 이름이다. 성문 앞 형상을 본 아수라들이 삭까가 나왔다고 여긴 까닭이다.

```original
Tato paṭṭhāya cittapāṭaliyā pupphitāya asurā ‘‘amhākaṃ nibbattaṭṭhāne dibbapāricchattakassa pupphanakālo’’ti yuddhatthāya saggaṃ abhiruhanti. Sakko heṭṭhāsamudde nāgānaṃ ārakkhaṃ adāsi, tato supaṇṇānaṃ, tato kumbhaṇḍānaṃ, tato yakkhānaṃ. Tato catunnaṃ mahārājānaṃ. Sabbūpari pana upaddavanivattanatthāya devanagaradvāresu vajirahatthā indapaṭimā ṭhapesi. Asurā nāgādayo jinitvā āgatāpi indapaṭimā dūrato disvā ‘‘sakko nikkhanto’’ti palāyanti.
```

<a id="cscd-02-07-u008-p012"></a>

스승께서 말씀하셨다. “마할리여, 젊은 마가는 이렇게 마음을 놓지 않고 살았다. 그래서 그런 권세를 얻어 신들이 사는 두 세계[^r3-12]를 다스렸다. 방일하지 않음은 붓다 등께서 칭찬하신다. 방일하지 않는 삶에서 세상에서 얻는 성취와 깨달음에 이르는 성취가 모두 나오기 때문이다.” 그리고 이 게송을 설하셨다.

[^r3-12]: 삼십삼천과 사천왕천을 가리킨다. 앞 대목에서 삼십삼천의 왕인 삭까는 그 아래 수비를 사천왕에게 맡긴다. [《디가 니까야》 15 주석](https://epitaka.org/en/book/Sv-ii/nid%C4%81nava%E1%B9%87%E1%B9%87an%C4%81-283).

```original
Evaṃ, mahāli, magho māṇavo appamādapaṭipadaṃ paṭipajji. Evaṃ appamatto panesa evarūpaṃ issariyaṃ patvā dvīsu devalokesu rajjaṃ kāresi. Appamādo nāmesa buddhādīhi pasattho. Appamādañhi nissāya sabbesampi lokiyalokuttarānaṃ visesānaṃ adhigamo hotīti vatvā imaṃ gāthamāha –
```

<a id="cscd-02-07-u009"></a>
## 제30게

<a id="cscd-02-07-u009-v001"></a>

<pali-poem>

> **제30게**  
> 방일하지 않음으로 마가와는  
> 신들 가운데 으뜸에 이르렀다.  
> 방일하지 않음은 칭찬받고,  
> 방일은 언제나 꾸지람을 받는다.

```original
30.
‘‘Appamādena  maghavā, devānaṃ seṭṭhataṃ gato;
Appamādaṃ pasaṃsanti, pamādo garahito sadā’’ti.
```

</pali-poem>

<a id="cscd-02-07-u010"></a>
## 게송의 어구 풀이와 마할리의 예류과

<a id="cscd-02-07-u010-p001"></a>

여기서 ‘방일하지 않음으로’는 마짤라 마을에서 자리를 말끔히 닦는 일부터 시작해, 마음을 놓지 않고 해 온 일들 덕분이라는 뜻이다. 젊은 마가는 마가와라는 이름으로도 알려졌다. 그는 신들이 사는 두 세계의 왕이 되어 신들 가운데 으뜸에 이르렀다.

```original
Tattha appamādenāti macalagāme bhūmippadesasodhanaṃ ādiṃ katvā katena appamādena. Maghavāti idāni ‘‘maghavā’’tipaññāto magho māṇavo dvinnaṃ devalokānaṃ rājabhāvena devānaṃ seṭṭhataṃ gato.
```

<a id="cscd-02-07-u010-p002"></a>

‘칭찬한다’는 붓다 등 지혜로운 이들이 바로 방일하지 않음을 기리고 칭찬한다는 말이다. 방일하지 않는 삶이 세상에서 이루는 일과 깨달음으로 가는 길 모두에서 뛰어난 성취로 이어지기 때문이다. ‘방일은 언제나 꾸지람을 받는다’는 방일을 성자들이 늘 꾸짖고 나무란다는 뜻이다. 방일이 온갖 불행의 뿌리이기 때문이다. 주석은 사람이 겪는 불운이나 괴로운 곳에 다시 태어나는 일을 방일에서 비롯하는 것으로 풀이한다.

```original
Pasaṃsantīti buddhādayo paṇḍitā appamādameva thomenti  vaṇṇayanti. Kiṃ kāraṇā? Sabbesaṃ lokiyalokuttarānaṃ visesānaṃ paṭilābhakāraṇattā. Pamādo garahito sadāti pamādo pana tehi ariyehi niccaṃ garahito nindito. Kiṃ kāraṇā? Sabbavipattīnaṃ mūlabhāvato. Manussadobhaggaṃ vā hi apāyuppatti vā sabbā pamādamūlikāyevāti.
```

<a id="cscd-02-07-u010-p003"></a>

게송이 끝나자 릿차위 사람 마할리는 예류과에 이르렀다. 모인 이들 가운데도 많은 사람이 예류과를 비롯한 성취를 얻었다.

```original
Gāthāpariyosāne  mahāli licchavī sotāpattiphale patiṭṭhahi, sampattaparisāyapi bahū sotāpannādayo jātāti.
```

<a id="cscd-02-07-u010-e001"></a>

마가 이야기, 일곱째.

```original
Maghavatthu sattamaṃ.
```
