# 02-02-2 꿈바고사까가 부호가 되다
원문서명: 담마빠다 주석서(Dhammapada-aṭṭhakathā) | 저자: 미확정 | 출처: 《담마빠다 주석서》 제1부, VRI CSCD 로마자 XML 2777–2841행

- **품** · 제2품 방일하지 않음의 품(Appamādavaggo)
- **빨리어 표제** · Kumbhaghosakaseṭṭhivatthu

<a id="cscd-02-02-u005"></a>
## 잔치 명령과 왕의 소환

<a id="cscd-02-02-u005-p001"></a>

며칠 뒤 시녀는 왕에게 전갈을 보냈다. “품꾼들의 거리에서 잔치를 열게 하십시오. 잔치를 열지 않는 집에는 정해진 액수의 벌금을 물리겠다고 알리십시오.” 왕은 그대로 했다.

```original
Sā katipāhaccayena rañño sāsanaṃ pesesi – ‘‘bhatakavīthiyaṃ chaṇaṃ karontu. Yassa pana ghare chaṇo na karīyati, tassa ettako nāma daṇḍoti ghosanaṃ kāretū’’ti. Rājā tathā kāresi.
```

<a id="cscd-02-02-u005-p002"></a>

장모가 그에게 물었다. “얘야, 왕명으로 품꾼들의 거리에서 잔치를 열게 됐는데, 우리는 어떻게 하느냐?”

```original
Atha naṃ sassu āha – ‘‘tāta, bhatakavīthiyaṃ rājāṇāya chaṇo kattabbo jāto, kiṃ karomā’’ti?
```

<a id="cscd-02-02-u005-p003"></a>

“아주머니, 저는 품팔이를 해도 먹고살기가 어렵습니다. 어떻게 하겠습니까?”

```original
‘‘Amma, ahaṃ bhatiṃ karontopi jīvituṃ na sakkomi, kiṃ karissāmī’’ti?
```

<a id="cscd-02-02-u005-p004"></a>

“얘야, 살림을 하다 보면 빚도 지는 법이다. 왕명을 어길 수는 없지 않으냐. 빚은 어떻게든 갚을 수 있으니 어디서든 돈 한두 닢을 구해 오너라.”

```original
‘‘Tāta, gharāvāsaṃ vasantā nāma iṇampi gaṇhanti, rañño  āṇā akātuṃ na labbhā. Iṇato nāma yena kenaci upāyena muccituṃ sakkā, gaccha, kutoci ekaṃ vā dve vā kahāpaṇe āharā’’ti āha.
```

<a id="cscd-02-02-u005-p005"></a>

꿈바고사까는 불평하면서도 재산을 묻어 둔 곳에 가서 까하빠나 한 닢[^r3-03]만 가져왔다. 시녀는 그가 가져온 돈을 왕에게 보내고 잔치는 자기 돈으로 치렀다. 며칠 뒤 시녀가 다시 같은 전갈을 보내자 왕은 다시 잔치를 열라 하고, 잔치를 열지 않는 집에는 벌금을 물리게 했다. 시녀가 전과 같이 말하며 다그치자 그는 이번에는 까하빠나 세 닢을 가져왔다. 시녀는 그것도 왕에게 보내고 며칠 뒤 다시 전갈을 보냈다. “이제 사람들을 보내 이 사람을 불러들이십시오.”

[^r3-03]: 까하빠나는 옛 인도에서 쓰던 화폐 단위다. 시녀는 꿈바고사까가 어떤 돈을 가져오는지 왕이 보게 하려고 그 돈을 보냈다.

```original
So ujjhāyanto khīyanto gantvā cattālīsakoṭidhanaṭṭhānato ekameva kahāpaṇaṃ āhari. Sā taṃ kahāpaṇaṃ rañño pesetvā attano kahāpaṇena chaṇaṃ katvā puna katipāhaccayena tatheva sāsanaṃ pahiṇi. Puna rājā tatheva ‘‘chaṇaṃ karontu, akarontānaṃ ettako daṇḍo’’ti āṇāpesi. Punapi so tāya tatheva vatvā nippīḷiyamāno gantvā tayo kahāpaṇe āhari. Sā tepi kahāpaṇe rañño pesetvā puna katipāhaccayena tatheva sāsanaṃ pahiṇi – ‘‘idāni purise pesetvā imaṃ pakkosāpetū’’ti.
```

<a id="cscd-02-02-u005-p006"></a>

왕이 사람들을 보냈다. 왕의 사람들은 “꿈바고사까가 누구냐?” 하며 그를 찾았다. 그러다 마침내 발견하고 “이리 오게. 왕께서 부르시네” 했다. 꿈바고사까는 겁이 나 “왕께서는 저를 모르십니다”라고 하며 버티었다. 왕의 사람들은 억지로 그의 팔 등을 붙들어 끌고 갔다. 시녀는 그 모습을 보고 꾸짖었다. “이 무례한 자들아, 내 사위의 팔을 함부로 붙잡다니!” 그리고 그에게 말했다. “오너라, 얘야. 두려워하지 마라. 내가 왕을 뵙고 네 팔을 붙잡은 자들의 손을 잘라 버리게 하겠다.”

```original
Rājā pesesi. Purisā gantvā, ‘‘kumbhaghosako nāma kataro’’ti pucchitvā pariyesantā taṃ disvā ‘‘ehi, bho rājā, taṃ pakkosatī’’ti āhaṃsu. So bhīto ‘‘na maṃ rājā jānātī’’tiādīni vatvā gantuṃ na icchi. Atha naṃ balakkārena hatthādīsu gahetvā  ākaḍḍhiṃsu. Sā itthī te disvā, ‘‘are, dubbinītā, tumhe mama jāmātaraṃ hatthādīsu gahetuṃ ananucchavikā’’ti tajjetvā, ‘‘ehi, tāta, mā bhāyi, rājānaṃ disvā tava hatthādigāhakānaṃ hattheyeva chindāpessāmī’’ti
```

<a id="cscd-02-02-u005-p007"></a>

시녀는 딸을 데리고 앞서 궁에 이르렀다. 옷을 갈아입고 온갖 장신구로 단장한 뒤 한쪽에 섰다. 왕의 사람들은 꿈바고사까를 계속 끌고 와 마침내 궁에 들였다.

```original
dhītaraṃ ādāya purato hutvā rājagehaṃ patvā vesaṃ parivattetvā sabbālaṅkārapaṭimaṇḍitā ekamantaṃ aṭṭhāsi. Itarampi parikaḍḍhitvā ānayiṃsuyeva.
```

<a id="cscd-02-02-u006"></a>
## 부호가 된 꿈바고사까와 바른 생계

<a id="cscd-02-02-u006-p001"></a>

그가 절하고 서 있자 왕이 물었다. “네가 꿈바고사까냐?”

```original
Atha naṃ vanditvā ṭhitaṃ rājā āha – ‘‘tvaṃ kumbhaghosako nāmā’’ti?
```

<a id="cscd-02-02-u006-p002"></a>

“그렇습니다, 전하.”

```original
‘‘Āma, devā’’ti.
```

<a id="cscd-02-02-u006-p003"></a>

“왜 많은 재산을 숨기고 지내느냐?”

```original
‘‘Kiṃ kāraṇā mahādhanaṃ vañcetvā khādasī’’ti?
```

<a id="cscd-02-02-u006-p004"></a>

“전하, 품팔이로 살아가는 제게 어디 재산이 있겠습니까?”

```original
‘‘Kuto me, deva, dhanaṃ bhatiṃ katvā jīvantassā’’ti?
```

<a id="cscd-02-02-u006-p005"></a>

“그러지 마라. 왜 나를 속이느냐?”

```original
‘‘Mā evaṃ kari, kiṃ amhe vañcesī’’ti?
```

<a id="cscd-02-02-u006-p006"></a>

“속이지 않습니다, 전하. 제게 재산은 없습니다.”

```original
‘‘Na vañcemi, deva, natthi me dhana’’nti.
```

<a id="cscd-02-02-u006-p007"></a>

왕이 까하빠나들을 보여 주며 물었다. “이 돈은 누구의 것이냐?” 그는 돈을 알아보고 ‘아, 어리석었구나. 어쩌다 이 돈이 왕의 손에 들어갔을까?’ 하고 이리저리 둘러보았다. 두 여자가 곱게 차려 입고 방 입구에 서 있는 것이 보였다. ‘이 두 사람이 내게 온 것은 우연이 아니었구나. 왕이 보냈음이 틀림없다’고 생각했다.

```original
Athassa rājā te kahāpaṇe dassetvā, ‘‘ime kassa kahāpaṇā’’ti āha. So sañjānitvā, ‘‘aho bālomhi, kathaṃ nu kho ime rañño hatthaṃ pattā’’ti ito cito ca olokento tā dvepi paṭimaṇḍitapasādhanā gabbhadvāramūle ṭhitā disvā, ‘‘bhāriyaṃ vatidaṃ kammaṃ, imāhi raññā payojitāhi bhavitabba’’nti cintesi.
```

<a id="cscd-02-02-u006-p008"></a>

왕이 다시 물었다. “말해 보아라. 왜 그렇게 했느냐?”

```original
Atha naṃ rājā ‘‘vadehi, bho, kasmā evaṃ karosī’’ti āha.
```

<a id="cscd-02-02-u006-p009"></a>

“전하, 제게 의지할 이가 없습니다.”

```original
‘‘Nissayo me natthi, devā’’ti.
```

<a id="cscd-02-02-u006-p010"></a>

“내가 네 뒤를 돌봐 주면 되지 않겠느냐?”

```original
‘‘Mādiso nissayo bhavituṃ na vaṭṭatī’’ti.
```

<a id="cscd-02-02-u006-p011"></a>

“전하께서 제 뒤를 돌봐 주신다면 좋겠습니다.”

```original
‘‘Kalyāṇaṃ, deva, sace me devo avassayo hotī’’ti.
```

<a id="cscd-02-02-u006-p012"></a>

“그렇게 하마. 재산이 얼마나 되느냐?”

```original
‘‘Homi, bho, kittakaṃ te dhana’’nti?
```

<a id="cscd-02-02-u006-p013"></a>

“마흔 꼬띠입니다, 전하.”

```original
‘‘Cattālīsakoṭiyo, devā’’ti.
```

<a id="cscd-02-02-u006-p014"></a>

“그 재산을 가져오는 데 무엇이 필요하냐?”

```original
‘‘Kiṃ laddhuṃ vaṭṭatī’’ti?
```

<a id="cscd-02-02-u006-p015"></a>

“수레가 필요합니다, 전하.”

```original
‘‘Sakaṭāni devā’’ti?
```

<a id="cscd-02-02-u006-p016"></a>

왕은 소가 끄는 수레 수백 대를 보냈다. 재산을 실어 와 궁 뜰에 쌓게 하고 라자가하 주민을 모아 물었다. “이 도성에 이만큼 재산을 가진 이가 있느냐?”

```original
Rājā anekasatāni sakaṭāni yojāpetvā pahiṇitvā taṃ dhanaṃ āharāpetvā rājaṅgaṇe rāsiṃ kārāpetvā rājagahavāsino sannipātāpetvā, ‘‘atthi kassaci imasmiṃ nagare ‘‘ettakaṃ dhana’’nti pucchitvā
```

<a id="cscd-02-02-u006-p017"></a>

“없습니다, 전하.”

```original
‘‘natthi, devā’’ti.
```

<a id="cscd-02-02-u006-p018"></a>

“그에게 무엇을 해 주면 좋겠느냐?”

```original
‘‘Kiṃ panassa kātuṃ vaṭṭatī’’ti?
```

<a id="cscd-02-02-u006-p019"></a>

“예우를 해 주십시오, 전하.”

```original
‘‘Sakkāraṃ, devā’’ti
```

<a id="cscd-02-02-u006-p020"></a>

왕은 꿈바고사까를 극진히 대우하며 부호의 자리에 앉혔고, 딸도 그에게 시집보냈다. 꿈바고사까와 함께 스승께 가서 예를 올리고 말씀드렸다.

```original
vutte mahantena sakkārena taṃ seṭṭhiṭṭhāne ṭhapetvā dhītaraṃ tasseva datvā tena saddhiṃ satthu santikaṃ gantvā vanditvā
```

<a id="cscd-02-02-u006-p021"></a>

“세존이시여, 이 사람을 보십시오. 이렇게 마음이 굳은 사람은 드뭅니다. 마흔 꼬띠의 재산을 지녔는데도 그 재산에 들뜨거나 자기를 내세우는 기색이 없습니다. 그는 가난한 사람처럼 해진 옷을 입고 품꾼들 사이에서 일하며 살아왔습니다. 제가 이런 방도를 써서 그 사정을 알게 되었습니다. 그래서 그를 불러 재산이 있음을 인정하게 하고, 재산을 가져오게 하여 그를 부호의 자리에 앉혔습니다. 딸도 그에게 시집보냈습니다. 세존이시여, 저는 이런 굳센 사람을 전에 본 적이 없습니다.”

```original
‘‘bhante, passathimaṃ purisaṃ, evarūpo dhitimā nāma natthi, cattālīsakoṭivibhavo hontopi uppilāvitākāraṃ vā asmimānamattaṃ vā na karoti, kapaṇo viya pilotikaṃ  nivāsetvā bhatakavīthiyaṃ bhatiṃ katvā jīvanto mayā iminā nāma upāyena ñāto. Jānitvā ca pana pakkosāpetvā sadhanabhāvaṃ sampaṭicchāpetvā taṃ dhanaṃ āharāpetvā  seṭṭhiṭṭhāne ṭhapito, dhītā cassa mayā dinnā. Bhante, mayā ca evarūpo dhitimā na diṭṭhapubbo’’ti āha.
```

<a id="cscd-02-02-u006-p022"></a>

스승께서 그 말을 듣고 말씀하셨다. “대왕이여, 그렇게 살아가는 이의 생계를 바른 생계[^r3-04]라고 하오. 도둑질 같은 행위는 이 세상과 다음 세상에서 그 사람을 괴롭히고 해치오. 그런 일에서 행복이 생기지 않소. 재산이 다했을 때 농사를 짓거나 품을 팔아 살아가는 것이 바른 생계요. 이처럼 정진과 마음챙김을 갖추고 몸으로나 말로 허물을 짓지 않으며, 행동하기 전에 잘 살피고 자신을 절제하며, 법에 맞게 살며 마음챙김을 잃지 않는 사람은 위세가 커지오.” 그리고 이 게송을 설하셨다.

[^r3-04]: 남에게 해를 끼치거나 속이는 일을 피하고 정당하게 먹고살 방도를 마련하는 것을 말한다.

```original
Taṃ sutvā satthā ‘‘evaṃ jīvantassa jīvikaṃ dhammikajīvikaṃ nāma, mahārāja, corikādikammaṃ pana idhaloke ceva pīḷeti hiṃseti, paraloke ca, tatonidānaṃ sukhaṃ nāma natthi. Purisassa hi dhanapārijuññakāle kasiṃ vā bhatiṃ vā katvā jīvikameva dhammikajīvikaṃ nāma. Evarūpassa hi vīriyasampannassa satisampannassa kāyavācāhi parisuddhakammassa paññāya nisammakārino kāyādīhi saññatassa dhammajīvikaṃ jīvantassa satiavippavāse ṭhitassa issariyaṃ vaḍḍhatiyevā’’ti vatvā imaṃ gāthamāha –
```

<a id="cscd-02-02-u007"></a>
## 제24게

<a id="cscd-02-02-u007-v001"></a>

<pali-poem>

> **제24게**  
> 부지런히 힘쓰고 마음챙김을 갖추며,  
> 행실이 깨끗하고 살핀 뒤에 행동하며,  
> 자신을 절제하고 법에 맞게 살아가며,  
> 방일하지 않는 이의 명망은 커진다.

```original
24.
‘‘Uṭṭhānavato satīmato,
Sucikammassa nisammakārino;
Saññatassa  dhammajīvino,
Appamattassa yasobhivaḍḍhatī’’ti.
```

</pali-poem>

<a id="cscd-02-02-u008"></a>
## 게송의 어구 풀이와 예류과

<a id="cscd-02-02-u008-p001"></a>

여기서 ‘부지런히 힘쓰는 이’는 떨쳐 일어나 힘써 일하는 사람이다. ‘마음챙김을 갖춘 이’는 자기 마음과 행동을 잊지 않고 알아차리는 사람이다. ‘행실이 깨끗한 이’는 몸으로 하는 행위 등을 허물 없이 바르게 하는 사람이다. ‘살핀 뒤에 행동하는 이’는 ‘이렇게 된다면 이렇게 하겠다’거나 ‘이 일을 이렇게 하면 이런 결과가 생기겠다’고 그 원인을 살피고, 병을 고치려면 먼저 원인을 살피듯, 무슨 일이든 충분히 따져 본 뒤 행동하는 사람이다.

```original
Tattha uṭṭhānavatoti uṭṭhānavīriyavantassa. Satimatoti satisampannassa. Sucikammassāti niddosehi niraparādhehi kāyakammādīhi samannāgatassa. Nisammakārinoti evañce bhavissati, evaṃ karissāmīti vā, imasmiṃ kamme evaṃ kate idaṃ nāma bhavissatīti vā evaṃ nidānaṃ sallakkhetvā rogatikicchanaṃ  viya sabbakammāni nisāmetvā upadhāretvā karontassa.
```

<a id="cscd-02-02-u008-p002"></a>

‘자신을 절제하는 이’는 몸과 말 등의 행동을 빈틈없이 가다듬는 사람이다. ‘법에 맞게 살아가는 이’는 재가자라면 저울의 눈금을 속이는 것 같은 일을 피하고 농사를 짓거나 소를 돌보는 일로 생계를 꾸리는 사람이다. 출가자라면 진료나 심부름을 생계 수단으로 삼는 일을 피하고, 법에 맞게 탁발하여 살아가는 사람이다. ‘방일하지 않는 이’는 마음챙김을 잃지 않은 사람이다. ‘명망은 커진다’는 권세와 재산에서 오는 위세도, 좋은 평판과 칭찬에서 오는 명성도 함께 커진다는 뜻이다.

```original
Saññatassāti kāyādīhi saññatassa nicchiddassa. Dhammajīvinoti agārikassa tulākūṭādīni vajjetvā kasigorakkhādīhi, anagārikassa vejjakammadūtakammādīni vajjetvā dhammena samena bhikkhācariyāya jīvikaṃ kappentassa. Appamattassāti avippavutthasatino. Yasobhivaḍḍhatīti issariyabhogasampannasaṅkhāto ceva kittivaṇṇabhaṇanasaṅkhāto ca yaso abhivaḍḍhatīti.
```

<a id="cscd-02-02-u008-p003"></a>

게송이 끝나자 꿈바고사까는 예류과[^r3-05]에 이르렀다. 그 밖에도 많은 이들이 예류과를 비롯한 성취를 얻었다. 이처럼 법문은 많은 사람에게 이로움을 주었다.

[^r3-05]: 깨달음에 이르는 흐름에 처음 들어선 사람이 얻는 수행의 첫 성취다.

```original
Gāthāpariyosāne kumbhaghosako sotāpattiphale patiṭṭhahi. Aññepi bahū sotāpattiphalādīni pāpuṇiṃsu. Evaṃ mahājanassa sātthikā dhammadesanā jātāti.
```
