# 02-01-1 우데나의 탄생과 왕위 계승
원문서명: 담마빠다 주석서(Dhammapada-aṭṭhakathā) | 저자: 미확정 | 출처: 《담마빠다 주석서》 제1부, VRI CSCD 로마자 XML 2261–2773행

- **품** · 제2품 방일하지 않음의 품(Appamādavaggo)
- **빨리어 표제** · Sāmāvatīvatthu
- **게송** · 《담마빠다》 제21–23게
- **전체 이야기 요약** · 우데나가 왕위를 잇고 고사까가 부호가 되는 사연, 사마와띠와 마간디야가 왕궁에 들어오기까지의 일이 이어진다. 두 왕비의 죽음 뒤 붓다께서는 비구들에게 방일하지 않음과 죽음 없는 경지에 관해 설하신다.
- **전체 이야기 핵심어** · 사마와띠, 우데나, 고사까, 마간디야, 쿳줏따라, 방일하지 않음, 열반
- **평행문헌** · [《우다나》 7.10 〈우데나 경〉](https://suttacentral.net/ud7.10/en/anandajoti)의 궁중 화재와 비구들의 문답. 코끼리 발자국의 비유는 [《앙굿따라 니까야》 10.15](https://suttacentral.net/an10.15/en/bodhi)에도 나온다. 그 밖의 원문 출전 표기는 인용 대목에 병기했다.

<a id="cscd-02-01-u001"></a>
## 설법의 계기와 출가한 두 왕

<a id="cscd-02-01-u001-e001"></a>

```original
2. Appamādavaggo
1. Sāmāvatīvatthu
```

<a id="cscd-02-01-u001-p001"></a>

스승께서는 꼬삼비를 의지하여 고시따 정사에 머무실 때 사마와띠를 비롯한 여인 오백 명과 마간디야를 비롯한 그의 친족 오백 명이 비참하게 죽은 일을 두고 ‘방일하지 않음은 죽음 없는 경지에 이르는 길’로 시작하는 이 법문을 설하셨다. 그 일의 경위는 다음과 같다.

```original
Appamādo  amatapadanti imaṃ dhammadesanaṃ satthā kosambiṃ upanissāya ghositārāme viharanto sāmāvatippamukhānaṃ pañcannaṃ itthisatānaṃ, māgaṇḍiyappamukhānañca etissā pañcannaṃ ñātisatānaṃ maraṇabyasanaṃ ārabbha kathesi.
```

<a id="cscd-02-01-u001-p002"></a>

옛날 알라깝빠 나라에는 알라깝빠 왕이, 웨타디빠까 나라에는 웨타디빠까 왕이 있었다. 두 사람은 어려서부터 벗이었고 한 스승의 집에서 기술을 배웠다. 각자의 아버지가 죽자 각자 왕의 일산[^r3-01]을 올리고, 길이가 열 요자나[^r3-02]에 이르는 나라를 하나씩 다스렸다. 이따금 만나 서서, 앉아서, 누워서 함께 시간을 보냈다. 그러는 동안 많은 사람이 태어나고 늙고 죽는 모습을 보았다. 두 사람은 의논했다. “다음 세상으로 갈 때 따라오는 것은 없다. 자기 몸조차 따라오지 않는다. 모든 것을 버리고 가야 하니 집에서 사는 것이 우리에게 무슨 소용인가? 출가하자.”

[^r3-01]: 왕의 머리 위를 가리는 큰 양산이다. 일산을 올리는 일은 왕이 되었음을 뜻한다.
[^r3-02]: 요자나는 옛 인도에서 먼 거리를 재던 단위다. 이 주석서는 제60게의 풀이에서 한 요자나가 네 가우따라고 설명한다.

```original
Tatrāyaṃ anupubbikathā – atīte allakapparaṭṭhe allakapparājā nāma, veṭhadīpakaraṭṭhe veṭhadīpakarājā nāmāti ime dve daharakālato paṭṭhāya sahāyakā hutvā ekācariyakule sippaṃ uggaṇhitvā attano attano pitūnaṃ accayena chattaṃ ussāpetvā āyāmena dasadasayojanike raṭṭhe rājāno ahesuṃ. Te kālena kālaṃ samāgantvā ekato tiṭṭhantā nisīdantā nipajjantā mahājanaṃ jāyamānañca jīyamānañca mīyamānañca disvā ‘‘paralokaṃ gacchantaṃ anugacchanto nāma natthi, antamaso  attano sarīrampi nānugacchati, sabbaṃ pahāya gantabbaṃ, kiṃ no gharāvāsena, pabbajissāmā’’ti mantetvā
```

<a id="cscd-02-01-u001-p003"></a>

두 사람은 왕국을 아들과 아내에게 맡기고 집을 떠나 히말라야에서 수행자로 살았다. 그들은 의논했다. “우리는 살아갈 방도가 없어 출가한 것이 아니라 왕국을 버리고 출가했다. 한곳에서 함께 살면 출가하지 않은 것과 다를 바 없으니 따로 살자. 그대는 저 산에서 살고 나는 이 산에서 살겠다. 보름마다 돌아오는 포살일[^r3-03]에는 만나자.” 다시 생각했다. “그렇게 해도 여럿이 어울려 지내는 셈이겠구나. 그대는 그대의 산에서 불을 피우고 나는 내 산에서 불을 피우자. 그 불이 보이면 서로 살아 있다는 뜻으로 알자.” 두 사람은 그대로 했다.

[^r3-03]: 출가자가 함께 모여 계율을 되새기는 날이다. 두 수행자는 이날을 서로의 생사를 확인할 날로 삼았다.

```original
rajjāni puttadārānaṃ niyyādetvā isipabbajjaṃ pabbajitvā himavantappadese vasantā mantayiṃsu – ‘‘mayaṃ rajjaṃ pahāya pabbajitā, na jīvituṃ asakkontā. Te mayaṃ ekaṭṭhāne vasantā apabbajitasadisāyeva homa, tasmā visuṃ vasissāma. Tvaṃ etasmiṃ pabbate vasa, ahaṃ imasmiṃ pabbate vasissāmi. Anvaḍḍhamāsaṃ pana uposathadivase ekato bhavissāmā’’ti. Atha kho nesaṃ etadahosi – ‘‘evampi no gaṇasaṅgaṇikāva bhavissati, tvaṃ pana tava pabbate aggiṃ jāleyyāsi, ahaṃ mama pabbate aggiṃ jālessāmi, tāya saññāya atthibhāvaṃ jānissāmā’’ti. Te tathā kariṃsu.
```

<a id="cscd-02-01-u001-p004"></a>

얼마 뒤 수행자 웨타디빠까는 죽어 큰 위력을 지닌 신들의 왕으로 태어났다. 보름날이 되어도 그 산에 불빛이 보이지 않자 알라깝빠는 ‘내 벗이 죽었구나’ 하고 알았다. 웨타디빠까도 태어나자마자 자신이 누리는 천상의 영화가 생전의 어떤 일에서 왔는지 돌아보았다. 집을 떠난 뒤 해 온 수행이 그 까닭임을 알고 ‘벗을 만나러 가야겠다’고 생각했다. 길손의 모습을 하고 찾아가 예를 올린 뒤 한쪽에 섰다.

```original
Atha aparabhāge veṭhadīpakatāpaso kālaṃ katvā mahesakkho devarājā hutvā nibbatto. Tato aḍḍhamāse sampatte aggiṃ adisvāva itaro ‘‘sahāyako me kālakato’’ti aññāsi. Itaropi nibbattakkhaṇeyeva attano devasiriṃ oloketvā kammaṃ upadhārento nikkhamanato paṭṭhāya attano tapacariyaṃ disvā ‘‘gantvā mama sahāyakaṃ passissāmī’’ti  taṃ attabhāvaṃ vijahitvā maggikapuriso viya tassa santikaṃ gantvā vanditvā ekamantaṃ aṭṭhāsi.
```

<a id="cscd-02-01-u001-p005"></a>

“어디에서 왔는가?”

```original
Atha naṃ so  āha – ‘‘kuto āgatosī’’ti?
```

<a id="cscd-02-01-u001-p006"></a>

“존자시여, 저는 먼 곳에서 온 길손입니다. 존자께서는 이곳에 혼자 사십니까? 함께 사는 이가 있습니까?”

```original
‘‘Maggikapuriso  ahaṃ, bhante, dūratova āgatomhi. Kiṃ pana, bhante, ayyo imasmiṃ ṭhāne ekakova vasati, aññopi koci atthī’’ti?
```

<a id="cscd-02-01-u001-p007"></a>

“벗이 하나 있네.”

```original
‘‘Atthi me eko sahāyako’’ti.
```

<a id="cscd-02-01-u001-p008"></a>

“그 벗은 어디에 있습니까?”

```original
‘‘Kuhiṃ so’’ti?
```

<a id="cscd-02-01-u001-p009"></a>

“저 산에 사네. 그런데 포살일에 불을 피우지 않으니 아마 죽었을 걸세.”

```original
‘‘Etasmiṃ pabbate vasati, uposathadivase pana aggiṃ na jāleti, mato nūna bhavissatī’’ti.
```

<a id="cscd-02-01-u001-p010"></a>

“그렇습니까, 존자시여?”

```original
‘‘Evaṃ, bhante’’ti?
```

<a id="cscd-02-01-u001-p011"></a>

“그렇다네, 벗이여.”

```original
‘‘Evamāvuso’’ti.
```

<a id="cscd-02-01-u001-p012"></a>

“존자시여, 제가 그 사람입니다.”

```original
‘‘Ahaṃ so, bhante’’ti.
```

<a id="cscd-02-01-u001-p013"></a>

“어디에 태어났는가?”

```original
‘‘Kuhiṃ nibbattosī’’ti?
```

<a id="cscd-02-01-u001-p014"></a>

“존자시여, 신들의 세계에 큰 위력을 지닌 신들의 왕으로 태어났습니다. 존자를 뵈려고 다시 왔습니다. 이곳에 지내시면서 불편한 일이 있으십니까?”

```original
‘‘Devaloke mahesakkho devarājā hutvā nibbattosmi, bhante, ‘ayyaṃ passissāmī’ti puna āgatomhi. Api nu kho ayyānaṃ imasmiṃ ṭhāne vasantānaṃ koci upaddavo atthī’’ti?
```

<a id="cscd-02-01-u001-p015"></a>

“그렇다네, 벗이여. 코끼리들 때문에 고생하고 있네.”

```original
‘‘Āma, āvuso, hatthī nissāya kilamāmī’’ti.
```

<a id="cscd-02-01-u001-p016"></a>

“존자시여, 코끼리들이 어떻게 합니까?”

```original
‘‘Kiṃ vo, bhante, hatthī karontī’’ti?
```

<a id="cscd-02-01-u001-p017"></a>

“내가 쓸어 놓은 곳에 똥을 누고 발을 굴러 먼지를 일으키네. 똥을 치우고 땅을 고르느라 힘이 드네.”

```original
‘‘Sammajjanaṭṭhāne laṇḍaṃ pātenti, pādehi bhūmiyaṃ paharitvā paṃsuṃ uddharanti, svāhaṃ laṇḍaṃ chaḍḍento paṃsuṃ samaṃ karonto kilamāmī’’ti.
```

<a id="cscd-02-01-u001-p018"></a>

“그들이 오지 않기를 바라십니까?”

```original
‘‘Kiṃ pana tesaṃ anāgamanaṃ icchathā’’ti?
```

<a id="cscd-02-01-u001-p019"></a>

“그렇다네, 벗이여.”

```original
‘‘Āmāvuso’’ti.
```

<a id="cscd-02-01-u001-p020"></a>

“그러면 그들이 오지 않게 해 드리겠습니다.”

```original
‘‘Tena hi tesaṃ anāgamanaṃ karissāmī’’ti
```

<a id="cscd-02-01-u001-p021"></a>

그는 수행자에게 코끼리를 부리는 비나[^r3-04]를 주고 주문을 가르쳐 주었다. 비나의 세 줄을 보여 주면서 줄에 맞춰 주문을 외우라고 했다. “이 줄을 타고 이 주문을 외우면 코끼리들이 뒤돌아보지도 못하고 달아납니다. 이 줄을 타고 이 주문을 외우면 뒤를 돌아보면서 달아납니다. 이 줄을 타고 이 주문을 외우면 우두머리 코끼리가 다가와 등에 태워 줍니다. 바라시는 대로 하십시오.” 이렇게 말하고 수행자에게 예배한 뒤 떠났다. 수행자는 코끼리를 달아나게 하는 주문을 외우고 그에 맞는 줄을 타서 코끼리들을 쫓으며 지냈다.

[^r3-04]: 손으로 줄을 타서 소리를 내는 옛 인도의 현악기다. 이 이야기에서는 세 줄의 소리와 주문이 각각 코끼리에 다른 영향을 준다.

```original
tāpasassa hatthikantavīṇañceva hatthikantamantañca adāsi. Dadanto ca pana vīṇāya tisso tantiyo dassetvā tayo mante uggaṇhāpetvā ‘‘imaṃ tantiṃ paharitvā imasmiṃ mante vutte nivattitvā oloketumpi asakkontā hatthī palāyanti, imaṃ tantiṃ paharitvā imasmiṃ mante vutte nivattitvā pacchato olokentā olokentā palāyanti, imaṃ tantiṃ paharitvā imasmiṃ mante vutte hatthiyūthapati piṭṭhiṃ upanāmento āgacchatī’’ti ācikkhitvā, ‘‘yaṃ vo ruccati, taṃ kareyyāthā’’ti  vatvā tāpasaṃ vanditvā pakkāmi. Tāpaso palāyanamantaṃ vatvā palāyanatantiṃ paharitvā hatthī palāpetvā vasi.
```

<a id="cscd-02-01-u002"></a>
## 우데나의 탄생과 왕비를 거둔 수행자

<a id="cscd-02-01-u002-p001"></a>

그때 꼬삼비에는 뿌란땁빠라는 왕이 있었다. 어느 날 왕은 아이를 밴 왕비와 함께 바깥에 앉아 막 떠오른 아침 해의 볕을 쬐고 있었다. 왕비는 십만 값어치가 나가는 왕의 붉은 모직 담요를 두르고 앉아 왕과 이야기를 나누다가, 왕의 손가락에서 십만 값어치가 나가는 왕실 인장 반지를 빼 자기 손가락에 끼웠다.

```original
Tasmiṃ samaye kosambiyaṃ pūrantappo nāma rājā hoti. So ekadivasaṃ gabbhiniyā deviyā saddhiṃ bālasūriyatapaṃ tappamāno abbhokāsatale nisīdi. Devī rañño pārupanaṃ satasahassagghanikaṃ rattakambalaṃ pārupitvā nisinnā raññā saddhiṃ samullapamānā rañño aṅgulito satasahassagghanikaṃ rājamuddikaṃ nīharitvā attano aṅguliyaṃ pilandhi.
```

<a id="cscd-02-01-u002-p002"></a>

그때 핫틸링가 새가 하늘을 지나가다가 멀리서 붉은 담요를 두른 왕비를 보고 고깃덩어리라 여겨 날개를 펼치고 내려왔다. 왕은 새가 내려오는 소리에 놀라 일어나 궁 안으로 들어갔다. 왕비는 겁에 질린 데다 몸도 만삭이라 얼른 자리를 피할 수 없었다. 새는 왕비를 덮쳐 발톱으로 움켜쥐고 하늘로 날아갔다. 이 새들은 코끼리 다섯 마리의 힘을 지녔다고 한다. 그래서 먹이를 움켜쥐고 하늘을 날다가 알맞은 곳에 앉아 먹는다.

```original
Tasmiṃ samaye hatthiliṅgasakuṇo ākāsena gacchanto dūrato rattakambalapārupanaṃ deviṃ disvā ‘‘maṃsapesī’’ti saññāya pakkhe vissajjetvā otari. Rājā  tassa otaraṇasaddena bhīto uṭṭhāya antonivesanaṃ pāvisi. Devī garugabbhatāya ceva bhīrukajātikatāya ca vegena gantuṃ nāsakkhi. Atha naṃ so sakuṇo ajjhappatto nakhapañjare nisīdāpetvā ākāsaṃ pakkhandi. Te kira sakuṇā pañcannaṃ hatthīnaṃ balaṃ dhārenti. Tasmā ākāsena netvā yathārucitaṭṭhāne nisīditvā maṃsaṃ khādanti.
```

<a id="cscd-02-01-u002-p003"></a>

새의 발톱에 붙들려 가던 왕비는 죽음이 두려워 생각했다. ‘내가 소리를 지르면 짐승은 사람 소리에 놀라 나를 떨어뜨릴 것이다. 그러면 아이와 함께 죽고 만다. 이 새가 어디에 앉아 나를 먹기 시작할 때 소리를 내어 쫓아야겠다.’ 왕비는 그렇게 때를 기다렸다.

```original
Sāpi tena nīyamānā maraṇabhayabhītā cintesi – ‘‘sacāhaṃ viravissāmi, manussasaddo nāma tiracchānagatānaṃ ubbejanīyo, taṃ sutvā maṃ chaḍḍessati. Evaṃ sante  saha gabbhena jīvitakkhayaṃ pāpuṇissāmi, yasmiṃ pana ṭhāne nisīditvā maṃ khādituṃ ārabhissati, tatra naṃ saddaṃ katvā palāpessāmī’’ti. Sā attano paṇḍitatāya adhivāsesi.
```

<a id="cscd-02-01-u002-p004"></a>

그때 히말라야에 가지가 옆으로 뻗어 둥글게 퍼진 큰 니그로다 나무가 있었다. 그 새는 사슴 따위를 그곳으로 가져가 먹곤 했다. 새는 왕비도 그곳으로 데려가 가지 사이에 내려놓고는 지나온 쪽을 바라보았다. 이 새들은 지나온 쪽을 돌아보는 습성이 있었다고 한다. 왕비는 지금이 기회라고 생각했다. 두 손을 들어 손뼉을 치고 소리를 지르자 새가 달아났다.

```original
Tadā ca himavantapadese thokaṃ vaḍḍhitvā maṇḍapākārena  ṭhito eko mahānigrodho hoti. So sakuṇo migarūpādīni tattha netvā khādati, tasmā tampi tattheva netvā viṭapabbhantare ṭhapetvā āgatamaggaṃ olokesi. Āgatamaggolokanaṃ kira tesaṃ dhammatā. Tasmiṃ khaṇe devī, ‘‘idāni imaṃ palāpetuṃ vaṭṭatī’’ti cintetvā ubho hatthe ukkhipitvā pāṇisaddañceva mukhasaddañca katvā taṃ palāpesi.
```

<a id="cscd-02-01-u002-p005"></a>

해 질 무렵 진통이 시작되었다. 큰 구름이 일고 사방에서 천둥이 쳤다. 편안하게 자란 왕비는 “마님, 두려워하지 마십시오” 하는 말 한마디도 듣지 못하고 고통을 견디며 밤새 잠들지 못했다. 날이 밝자 구름이 걷히고 동이 트는 바로 그때 왕비가 아이를 낳았다. 왕비는 아들이 구름과 산과 새벽의 기운을 받아 태어났다고 하여 우데나라 이름 붙였다.

```original
Athassā sūriyatthaṅgamanakāle gabbhe kammajavātā caliṃsu. Sabbadisāsu gajjanto mahāmegho uṭṭhahi. Sukhedhitāya rājamahesiyā ‘‘mā bhāyi, ayye’’ti vacanamattampi alabhamānāya dukkhaparetāya sabbarattiṃ niddā nāma nāhosi. Vibhātāya pana rattiyā valāhakavigamo ca aruṇuggamanañca tassā gabbhavuṭṭhānañca ekakkhaṇeyeva ahosi. Sā meghautuñca pabbatautuñca aruṇautuñca gahetvā jātattā puttassa utenoti nāmaṃ akāsi.
```

<a id="cscd-02-01-u002-p006"></a>

그곳에서 멀지 않은 곳에 수행자 알라깝빠가 살았다. 그는 평소에도 비가 오면 추위를 피해 열매를 구하러 숲에 들어가지 않았다. 그 나무 밑에 가서 새들이 살을 발라 먹고 남긴 뼈를 가져와 빻은 뒤 즙을 내어 마시곤 했다. 그날도 ‘뼈를 가져와야겠다’ 하고 나무 밑에서 뼈를 찾다가 머리 위에서 아이 우는 소리를 들었다. 올려다보니 왕비가 보였다.

```original
Allakappatāpasassapi kho tato avidūre vasanaṭṭhānaṃ hoti. So pakatiyāva vassadivase sītabhayena phalāphalatthāya vanaṃ na pavisati, taṃ rukkhamūlaṃ gantvā sakuṇehi khāditamaṃsānaṃ aṭṭhiṃ āharitvā koṭṭetvā rasaṃ katvā pivati. Tasmā taṃ divasaṃ ‘‘aṭṭhiṃ āharissāmī’’ti tattha gantvā rukkhamūle aṭṭhiṃ pariyesento  upari dārakasaddaṃ sutvā ullokento deviṃ disvā
```

<a id="cscd-02-01-u002-p007"></a>

“그대는 누구인가?” “사람 여자입니다.” “어떻게 왔는가?” “핫틸링가 새가 저를 데려왔습니다.” “내려오시오.” “존자시여, 다른 신분의 사람과 어울리게 될까 두렵습니다.” “어떤 신분인가?” “왕족입니다.” “나도 왕족이오.” “그러면 왕족만 아는 비밀을 말해 보십시오.”

```original
‘‘kāsi tva’’nti vatvā ‘‘mānusitthimhī’’ti. ‘‘Kathaṃ āgatāsī’’ti? ‘‘Hatthiliṅgasakuṇenānītāmhī’’ti vutte ‘‘otarāhī’’ti āha. ‘‘Jātisambhedato bhāyāmi, ayyā’’ti. ‘‘Kāsi tva’’nti? ‘‘Khattiyāmhī’’ti. ‘‘Ahampi khattiyoyevā’’ti. ‘‘Tena hi khattiyamāyaṃ kathehī’’ti.
```

<a id="cscd-02-01-u002-p008"></a>

수행자가 그 비밀을 말하자 왕비가 “그러면 올라와 제 아들을 내려 주십시오”라고 했다. 수행자는 나무 한쪽에 올라갈 길을 내어 올라가 아이를 안았다. 왕비가 “저를 손으로 건드리지 마십시오” 하므로 왕비에게 손대지 않고 아이를 내려 주었다. 왕비도 내려왔다.

```original
So khattiyamāyaṃ kathesi. ‘‘Tena hi āruyha puttaṃ me otārehī’’ti. So ekena passena abhiruhanamaggaṃ katvā abhiruhitvā dārakaṃ gaṇhi. ‘‘Mā maṃ hatthena chupī’’ti ca vutte taṃ achupitvāva dārakaṃ otāresi. Devīpi otari.
```

<a id="cscd-02-01-u002-p009"></a>

수행자는 왕비를 암자로 데리고 가 가엾게 여겨 자기 계를 지키며 보살폈다. 파리가 없는 꿀과 저절로 자란 쌀을 가져와 죽을 끓여 주었다. 그렇게 보살핌을 받다가 왕비는 생각했다. ‘어디로 와서 이곳에 이르렀는지, 어느 쪽으로 가야 할지 모르겠다. 이 사람과 나는 어디까지나 낯선 사이다. 이 사람이 우리를 버리고 어디로 가 버리면 둘 다 여기서 죽는다. 어떻게든 이 사람의 계를 깨뜨려 나를 버리지 않게 해야겠다.’ 왕비는 옷을 흐트러뜨린 채 그 앞에 나서 그를 유혹하여 계를 깨뜨리게 했다. 그 뒤로 두 사람은 화목하게 살았다.

```original
Atha naṃ assamapadaṃ netvā sīlabhedaṃ akatvāva anukampāya paṭijaggi, nimmakkhikamadhuṃ āharitvā sayaṃjātasāliṃ āharitvā yāguṃ pacitvā adāsi. Evaṃ tasmiṃ paṭijaggante sā aparabhāge cintesi – ‘‘ahaṃ neva āgatamaggaṃ jānāmi, na gamanamaggaṃ jānāmi, imināpi me saddhiṃ vissāsamattampi natthi. Sace panāyaṃ amhe pahāya katthaci gamissati, ubhopi idheva maraṇaṃ pāpuṇissāma, yaṃkiñci katvā imassa sīlaṃ bhinditvā yathā maṃ  na muñcati, tathā taṃ kātuṃ vaṭṭatī’’ti. Atha naṃ dunnivatthaduppārutadassanena palobhetvā sīlavināsaṃ pāpesi. Tato paṭṭhāya dvepi samaggavāsaṃ vasiṃsu.
```

<a id="cscd-02-01-u003"></a>
## 코끼리를 부리는 주문과 왕위 계승

<a id="cscd-02-01-u003-p001"></a>

어느 날 수행자는 하늘의 별자리를 살피다가 뿌란땁빠의 별이 빛을 잃는 것을 보고 말했다. “부인이여, 꼬삼비의 뿌란땁빠 왕이 죽었소.” “존자시여, 왜 그렇게 말씀하십니까? 그분에게 원한이 있으십니까?” “없소, 부인이여. 그의 별이 빛을 잃는 것을 보고 하는 말이오.”

```original
Athekadivasaṃ tāpaso nakkhattayogaṃ ullokento pūrantappassa nakkhattamilāyanaṃ disvā ‘‘bhadde kosambiyaṃ pūrantapparājā  mato’’ti āha. ‘‘Kasmā, ayya, evaṃ vadesi? Kiṃ te tena saddhiṃ āghāto atthī’’ti? ‘‘Natthi, bhadde, nakkhattamilāyanamassa disvā evaṃ vadāmī’’ti, sā parodi.
```

<a id="cscd-02-01-u003-p002"></a>

왕비는 울음을 터뜨렸다. 수행자가 까닭을 묻자 왕비는 왕이 자기 남편이라고 말했다. “울지 마시오, 부인이여. 태어난 이는 반드시 죽소.” “압니다, 존자시여.” “그런데 왜 우시오?” “제 아들은 집안의 왕위를 이을 만합니다. 궁에 있었다면 왕의 흰 일산을 올렸을 아이입니다. 이제 그 큰 자리를 잃었구나 싶어 슬퍼 웁니다.” “그러면 걱정하지 마시오. 아들이 왕위를 얻기를 바란다면 내가 방도를 마련하겠소.”

```original
Atha naṃ ‘‘kasmā rodasī’’ti pucchitvā tāya tassa attano sāmikabhāve akkhāte āha – ‘‘mā, bhadde, rodi, jātassa nāma niyato maccū’’ti. ‘‘Jānāmi, ayyā’’ti vutte ‘‘atha kasmā rodasī’’ti? ‘‘Putto me kulasantakassa rajjassa anucchaviko, ‘sace tatra abhavissa, setacchattaṃ ussāpayissa. Idāni mahājāniko vata jāto’ti sokena rodāmi, ayyā’’ti. ‘‘Hotu, bhadde, mā cintayi, sacassa rajjaṃ patthesi, ahamassa rajjalabhanākāraṃ karissāmī’’ti.
```

<a id="cscd-02-01-u003-p003"></a>

수행자는 아들에게 코끼리를 부리는 비나와 주문을 주었다. 그때 수천 마리의 코끼리가 와서 와따 나무 아래 모여 쉬곤 했다. “코끼리들이 오기 전에 나무에 올라라. 코끼리들이 오거든 이 주문을 외우고 이 줄을 타라. 모두 뒤돌아보지도 못하고 달아날 것이다. 그러면 내려와 내게 오너라.” 아들은 시키는 대로 해 보고 돌아와 그 일을 알렸다. 둘째 날 수행자가 “오늘은 이 주문을 외우고 이 줄을 타라. 모두 뒤돌아보면서 달아날 것이다”라고 하자 그날도 그대로 하고 와서 알렸다. 셋째 날에는 “오늘은 이 주문을 외우고 이 줄을 타라. 무리의 우두머리가 다가와 등을 내줄 것이다”라고 하니 그날도 그대로 하고 와서 알렸다.

```original
Athassa hatthikantavīṇañceva hatthikantamante ca adāsi. Tadā anekāni hatthisahassāni āgantvā vaṭarukkhamūle nisīdanti. Atha naṃ āha – ‘‘hatthīsu anāgatesuyeva rukkhaṃ abhiruhitvā tesu āgatesu imaṃ mantaṃ vatvā imaṃ tantiṃ pahara, sabbe nivattitvā oloketumpi asakkontā palāyissanti, atha otaritvā āgaccheyyāsī’’ti. So tathā katvā āgantvā taṃ pavattiṃ ārocesi. Atha naṃ dutiyadivase āha – ‘‘ajja imaṃ mantaṃ vatvā imaṃ tantiṃ pahareyyāsi, sabbe nivattitvā olokentā palāyissantī’’ti. Tadāpi tathā katvā āgantvā ārocesi. Atha naṃ tatiyadivase āha – ‘‘ajja imaṃ mantaṃ vatvā imaṃ tantiṃ pahareyyāsi, yūthapati piṭṭhiṃ upanāmento āgamissatī’’ti. Tadāpi tathā katvā ārocesi.
```

<a id="cscd-02-01-u003-p004"></a>

수행자는 어머니를 불러 “부인이여, 아들에게 말해 줄 사정이 있으면 알려 주시오. 이제 이곳을 떠나 왕이 될 것이오”라고 말했다. 어머니가 아들에게 말했다. “얘야, 너는 꼬삼비의 뿌란땁빠 왕의 아들이다. 내가 너를 배었을 때 핫틸링가 새가 나를 데려왔다.” 어머니는 군대 지휘관들의 이름을 비롯해 필요한 것을 알려 주고 “믿지 않는 사람들에게는 네 아버지가 두르던 이 담요와 끼던 인장 반지를 보여 주어라” 하고 떠나보냈다.

```original
Athassa mātaraṃ āmantetvā, ‘‘bhadde, puttassa te sāsanaṃ vadehi, ettova gantvā rājā bhavissatī’’ti āha. Sā puttaṃ āmantetvā, ‘‘tāta, tvaṃ kosambiyaṃ pūrantapparañño putto, maṃ sagabbhaṃ hatthiliṅgasakuṇo ānesī’’ti vatvā senāpatiādīnaṃ nāmāni ācikkhitvā ‘‘asaddahantānaṃ imaṃ pitu pārupanakambalañceva pilandhanamuddikañca dasseyyāsī’’ti vatvā uyyojesi.
```

<a id="cscd-02-01-u003-p005"></a>

왕자가 수행자에게 “이제 무엇을 해야 합니까?” 하고 물었다. 수행자는 “나무의 가장 낮은 가지에 앉아 이 주문을 외우고 이 줄을 타라. 우두머리 코끼리가 다가와 등을 내줄 것이다. 그 등에 앉은 채 나라로 가서 왕위를 차지하여라”라고 했다. 왕자는 부모에게 절하고 그대로 했다. 다가온 코끼리 등에 올라타 귓가에 말했다. “나는 꼬삼비의 뿌란땁빠 왕의 아들이다. 그대여, 아버지의 왕위를 차지할 수 있게 해 다오.”

```original
Kumāro tāpasaṃ ‘‘idāni kiṃ karomī’’ti āha. ‘‘Rukkhassa heṭṭhimasākhāya nisīditvā imaṃ mantaṃ vatvā imaṃ tantiṃ pahara, jeṭṭhakahatthī te piṭṭhiṃ upanāpetvā upasaṅkamissati, tassa piṭṭhiyaṃ nisinnova raṭṭhaṃ gantvā rajjaṃ gaṇhāhī’’ti. So mātāpitaro vanditvā tathā katvā āgatassa hatthino piṭṭhiyaṃ nisīditvā kaṇṇe mantayi – ‘‘ahaṃ kosambiyaṃ pūrantapparañño putto, pettikaṃ me rajjaṃ gaṇhitvā dehi sāmī’’ti.
```

<a id="cscd-02-01-u003-p006"></a>

코끼리는 그 말을 듣고 울음소리를 내어 수천 마리의 코끼리를 불렀다. 수천 마리가 모였다. 다시 늙은 코끼리들에게 물러가라고 울자 늙은 코끼리들이 물러갔다. 다시 너무 어린 코끼리들에게 돌아가라고 울자 그들도 돌아갔다. 왕자는 수천 마리의 코끼리를 거느리고 변방 마을에 이르러 “나는 왕의 아들이다. 영화를 바라는 이들은 나와 함께 가자”라고 했다.

```original
So taṃ sutvā ‘‘anekāni  hatthisahassāni sannipatantū’’ti hatthiravaṃ ravi, anekāni hatthisahassāni sannipatiṃsu. Puna ‘‘jiṇṇā hatthī paṭikkamantū’’ti hatthiravaṃ ravi, jiṇṇā hatthī paṭikkamiṃsu. Puna ‘‘atitaruṇā hatthī nivattantū’’ti hatthiravaṃ ravi, tepi nivattiṃsu.
```

<a id="cscd-02-01-u003-p007"></a>

우데나는 사람들을 자기 편으로 받아들이며 도성에 이르러 성을 에워쌌다. “나와 싸우든지, 내게 왕위를 내주든지 하라”는 전갈을 보냈다. 도성 사람들은 “싸울 수도, 왕위를 내줄 수도 없다. 우리 왕비께서 만삭일 때 핫틸링가 새에게 잡혀 갔다. 살아 계신지 돌아가셨는지 알지 못하니 그 일을 밝혀 듣기 전에는 싸우지도 왕위를 내주지도 않겠다”라고 답했다. 당시 그 왕위는 대대로 이어지는 자리였다. 왕자는 “내가 그분의 아들이다”라고 하며 군대의 지휘관 등의 이름을 댔다. 그래도 믿지 않는 사람들에게 담요와 인장 반지를 보여 주었다. 사람들은 그것을 알아보고 의심을 풀어 문을 열고 그를 왕위에 세웠다.

```original
So anekehi yūthahatthisahasseheva parivuto paccantagāmaṃ patvā ‘‘ahaṃ rañño putto, sampattiṃ  patthayamānā mayā saddhiṃ āgacchantū’’ti āha. ‘‘Tato paṭṭhāya manussānaṃ saṅgahaṃ karonto gantvā nagaraṃ parivāretvā ‘yuddhaṃ vā me detu, rajjaṃ vā’’’ti sāsanaṃ pesesi. Nāgarā āhaṃsu – ‘‘mayaṃ dvepi na dassāma. Amhākañhi devī garugabbhā hatthiliṅgasakuṇena nītā, tassā atthibhāvaṃ vā natthibhāvaṃ vā mayaṃ na jānāma. Yāva tassā pavattiṃ na suṇāma. Tāva neva yuddhaṃ dassāma, na rajja’’nti. Tadā kira taṃ paveṇirajjaṃ ahosi. Tato kumāro ‘‘ahaṃ tassā putto’’ti vatvā senāpatiādīnaṃ nāmāni kathetvā tathāpi asaddahantānaṃ kambalañca muddikañca dassesi. Te kambalañca muddikañca sañjānitvā nikkaṅkhā hutvā dvāraṃ vivaritvā taṃ rajje abhisiñciṃsu.
```

<a id="cscd-02-01-u003-p008"></a>

여기까지가 우데나가 왕이 되기까지의 이야기이다.

```original
Ayaṃ tāva utenassa uppatti.
```
