# 02-05 마하깟사빠 장로 이야기
원문서명: 담마빠다 주석서(Dhammapada-aṭṭhakathā) | 저자: 미확정 | 출처: 《담마빠다 주석서》 제1부, VRI CSCD 로마자 XML 3077–3113행

- **품** · 제2품 방일하지 않음의 품(Appamādavaggo)
- **빨리어 표제** · Mahākassapattheravatthu
- **게송** · 《담마빠다》 제28게
- **요약** · 마하깟사빠 장로가 천안으로 중생들의 죽음과 다시 태어남을 살핀다. 붓다께서는 그가 볼 수 있는 범위를 말씀하시고, 지혜의 누각에 올라 중생을 바라보는 이의 비유를 설하신다.
- **핵심어** · 마하깟사빠, 천안, 방일하지 않음, 지혜, 다시 태어남

<a id="cscd-02-05-u001"></a>
## 천안으로 중생을 살피는 마하깟사빠

<a id="cscd-02-05-u001-e001"></a>

```original
5. Mahākassapattheravatthu
```

<a id="cscd-02-05-u001-p001"></a>

스승께서는 제따와나에 머무실 때 마하깟사빠 장로를 두고 ‘방일하지 않음으로 방일을’로 시작하는 이 법문을 설하셨다.

```original
Pamādaṃ  appamādenāti imaṃ dhammadesanaṃ satthā jetavane viharanto mahākassapattheraṃ ārabbha kathesi.
```

<a id="cscd-02-05-u001-p002"></a>

삡팔리 동굴에 머물던 장로는 어느 날 라자가하에서 탁발하고 식사를 마친 뒤 동굴로 돌아왔다. 장로는 앉아서 빛이 비치는 범위를 넓히고, 물과 땅과 산 등에서 방일한 이와 방일하지 않은 이가 죽고 다시 태어나는 모습을 천안[^r3-01]으로 살폈다.

[^r3-01]: 보통 눈으로는 볼 수 없는 것을 보는 능력이다. 여기서는 중생들이 죽고 다시 태어나는 모습을 보는 데 쓰인다. [《사문과경》](https://suttacentral.net/dn2/en/sujato#95.2).

```original
Ekasmiñhi divase thero pipphaliguhāyaṃ viharanto rājagahe piṇḍāya caritvā pacchābhattaṃ piṇḍapātapaṭikkanto ālokaṃ vaḍḍhetvā pamatte ca appamatte ca udakapathavīpabbatādīsu cavanake upapajjanake ca satte  dibbena cakkhunā olokento nisīdi.
```

<a id="cscd-02-05-u001-p003"></a>

스승께서는 제따와나에 앉으신 채 ‘오늘 내 아들 깟사빠는 어떤 수행을 하며 지내는가?’ 하고 천안으로 살피셨다. 장로가 중생들이 죽고 다시 태어나는 모습을 살피는 줄 아시고 말씀하셨다.

```original
Satthā jetavane nisinnakova  ‘‘kena nu kho vihārena ajja mama putto kassapo viharatī’’ti dibbena cakkhunā upadhārento ‘‘sattānaṃ cutūpapātaṃ olokento viharatī’’ti ñatvā
```

<a id="cscd-02-05-u001-p004"></a>

“중생들이 죽고 다시 태어나는 일은 붓다의 지혜로도 그 수를 다 헤아릴 수 없다. 어머니의 태 속에 새 생명을 받고도 부모가 알기 전에 죽는 중생이 얼마나 많은지 헤아릴 수 없다. 깟사빠여, 그 중생들은 네가 볼 수 있는 범위를 벗어나 있다. 네가 살필 수 있는 범위는 좁다. 중생이 죽고 다시 태어나는 모습을 두루 보고 아는 것은 오직 붓다들의 영역이다.”[^r3-02]

[^r3-02]: 이 대목은 죽고 다시 태어나는 중생을 보는 범위와 그 수를 헤아리는 일을 구별한다. 붓다는 장로가 보지 못하는 중생까지 두루 보지만, 죽고 다시 태어나는 중생의 수에는 헤아려 정할 수 있는 한계가 없다고 한다.

```original
‘‘sattānaṃ cutūpapāto nāma buddhañāṇenapi aparicchinno, mātukucchiyaṃ paṭisandhiṃ gahetvā mātāpitaro ajānāpetvā cavanasattānaṃ paricchedo kātuṃ na sakkā, te jānituṃ tava avisayo, kassapa, appamattako tava visayo, sabbaso pana cavante ca upapajjante ca jānituṃ passituṃ buddhānameva visayo’’ti vatvā
```

<a id="cscd-02-05-u001-p005"></a>

스승께서는 빛을 내어 장로 앞에 앉으신 듯 모습을 드러내고 이 게송을 설하셨다.

```original
obhāsaṃ pharitvā sammukhe nisinno viya hutvā imaṃ gāthamāha –
```

<a id="cscd-02-05-u002"></a>
## 제28게

<a id="cscd-02-05-u002-v001"></a>

<pali-poem>

> **제28게**  
> 지혜로운 이가 방일하지 않음으로 방일을 몰아내고  
> 지혜의 누각에 오르면  
> 슬픔을 벗은 그는 산 위에서 아래 있는 사람들을 보듯  
> 슬픔에 잠긴 어리석은 중생들을 내려다본다.

```original
28.
‘‘Pamādaṃ appamādena, yadā nudati paṇḍito;
Paññāpāsādamāruyha, asoko sokiniṃ pajaṃ;
Pabbataṭṭhova bhūmaṭṭhe, dhīro bāle avekkhatī’’ti.
```

</pali-poem>

<a id="cscd-02-05-u003"></a>
## 지혜의 누각과 산꼭대기의 비유

<a id="cscd-02-05-u003-p001"></a>

여기서 ‘몰아낸다’는 것은 새 물이 연못에 밀려들어 묵은 물을 휘저어 밖으로 밀어내는 것과 같다. 지혜로운 이도 마음챙김을 길러 방일이 자리 잡을 틈을 주지 않고, 방일하지 않는 힘으로 방일을 몰아낸다.

```original
Tattha nudatīti yathā nāma pokkharaṇiṃ pavisantaṃ navodakaṃ purāṇodakaṃ khobhetvā tassokāsaṃ adatvā taṃ attano matthakamatthakena palāyantaṃ nudati nīharati, evameva paṇḍito appamādalakkhaṇaṃ brūhento pamādassokāsaṃ adatvā yadā appamādavegena taṃ nudati nīharati,
```

<a id="cscd-02-05-u003-p002"></a>

주석에서 ‘지혜의 누각’은 맑은 천안을 뜻한다. 방일을 몰아낸 이는 천안을 얻는 데 필요한 수행을 마친다. 그 수행은 높은 누각에 오르는 사다리처럼 그를 맑은 천안에 이르게 한다. 그는 슬픔의 화살을 뽑아 더는 슬퍼하지 않는다. 슬픔의 화살이 여전히 박힌 중생들이 죽고 다시 태어나는 모습을 천안으로 내려다본다.

```original
atha so panunnapamādo accuggatatthena parisuddhaṃ dibbacakkhusaṅkhātaṃ paññāpāsādaṃ tassa anucchavikaṃ paṭipadaṃ pūrento tāya paṭipadāya nisseṇiyā pāsādaṃ viya āruyha pahīnasokasallatāya asoko, appahīnasokasallatāya sokiniṃ pajaṃ sattanikāyaṃ cavamānañceva upapajjamānañca dibbacakkhunā avekkhati passati.
```

<a id="cscd-02-05-u003-p003"></a>

산꼭대기에 선 사람은 아래에 있는 이들을, 높은 누각에 선 사람은 누각 둘레에 있는 이들을 어렵지 않게 내려다본다. 그처럼 지혜로운 아라한은 윤회를 이어 가는 씨앗을 뿌리째 뽑지 못한 이들이 죽고 다시 태어나는 모습을 어렵지 않게 내려다본다.

```original
Yathā kiṃ? Pabbataṭṭhova  bhūmaṭṭheti pabbatamuddhani ṭhito bhūmiyaṃ ṭhite, uparipāsāde vā pana ṭhito pāsādapariveṇe ṭhite akicchena avekkhati, tathā sopi dhīro paṇḍito mahākhīṇāsavo asamucchinnavaṭṭabīje bāle cavante ca upapajjante ca akicchena avekkhatīti.
```

<a id="cscd-02-05-u003-p004"></a>

게송이 끝나자 많은 이들이 예류과를 비롯한 성취를 직접 깨달았다.

```original
Gāthāpariyosāne  bahū sotāpattiphalādīni sacchikariṃsūti.
```

<a id="cscd-02-05-u003-e001"></a>

마하깟사빠 장로 이야기, 다섯째.

```original
Mahākassapattheravatthu pañcamaṃ.
```
