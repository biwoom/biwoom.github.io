# 02-06 방일한 비구와 방일하지 않은 비구, 두 벗 이야기
원문서명: 담마빠다 주석서(Dhammapada-aṭṭhakathā) | 저자: 미확정 | 출처: 《담마빠다 주석서》 제1부, VRI CSCD 로마자 XML 3117–3149행

- **품** · 제2품 방일하지 않음의 품(Appamādavaggo)
- **빨리어 표제** · Pamattāpamattadvesahāyakavatthu
- **게송** · 《담마빠다》 제29게
- **요약** · 두 비구가 숲에서 안거한다. 한 사람은 초저녁 내내 불을 쬐며 시간을 보내고, 다른 사람은 꾸준히 수행하여 아라한과를 얻는다. 붓다께서는 빠른 말이 힘없는 말을 앞지르는 비유로 두 사람의 차이를 말씀하신다.
- **핵심어** · 방일, 안거, 마음챙김, 지혜, 아라한과

<a id="cscd-02-06-u001"></a>
## 숲에서 안거한 두 벗

<a id="cscd-02-06-u001-e001"></a>

```original
6. Pamattāpamattadvesahāyakavatthu
```

<a id="cscd-02-06-u001-p001"></a>

스승께서는 제따와나에 머무실 때 벗인 두 비구를 두고 ‘방일한 이들 가운데 방일하지 않고’로 시작하는 이 법문을 설하셨다.

```original
Appamatto  pamattesūti imaṃ dhammadesanaṃ satthā jetavane viharanto dve sahāyake bhikkhū ārabbha kathesi.
```

<a id="cscd-02-06-u001-p002"></a>

두 사람은 스승께 수행 주제를 배운 뒤 숲속 정사로 갔다. 그중 한 사람은 일찍부터 땔나무를 가져다 화로에 불을 피웠다. 그러고는 밤을 셋으로 나눈 첫 구간인 초야 내내 불을 쬐며 어린 사미들과 이야기를 나눴다. 다른 비구는 꾸준히 수행하며 벗을 타일렀다. “벗이여, 그렇게 하지 마시오. 방일한 이에게 네 가지 악처[^r3-01]는 제집과 같소. 겉으로만 수행하는 체해서는 붓다를 기쁘게 해 드릴 수 없소.” 그러나 벗은 그 충고를 귀담아듣지 않았다. 수행하던 비구는 ‘내 말을 듣지 않는구나’ 하고 더 타이르지 않고 자기 수행을 이어 갔다.

[^r3-01]: 괴로움이 많은 네 가지 태어날 곳을 가리킨다. ‘제집과 같다’는 말은 방일한 이는 그곳에 그만큼 쉽게 간다는 뜻이다.

```original
Te kira satthu santike kammaṭṭhānaṃ gahetvā āraññakavihāraṃ pavisiṃsu. Tesu eko kira kālasseva dārūni āharitvā aṅgārakapallaṃ sajjetvā daharasāmaṇerehi saddhiṃ sallapanto paṭhamayāmaṃ visibbamāno nisīdati. Eko appamatto samaṇadhammaṃ karonto itaraṃ ovadati, ‘‘āvuso, mā evaṃ kari, pamattassa hi cattāro apāyā sakagharasadisā. Buddhā nāma sāṭheyyena ārādhetuṃ na sakkā’’ti so tassovādaṃ na suṇāti. Itaro ‘‘nāyaṃ vacanakkhamo’’ti taṃ avatvā appamattova samaṇadhammamakāsi.
```

<a id="cscd-02-06-u001-p003"></a>

게으른 장로는 초야에 불을 쬔 뒤, 다른 비구가 걸으면서 하는 수행을 마치고 제 방으로 들어가자 그를 따라 들어가 말했다. “이 게으른 이여, 누워 자려고 숲에 들어왔소? 붓다께 수행 주제를 배웠으면 일어나 수행해야 하지 않겠소?” 그러고는 장로 자신이 숙소로 돌아가 누워 잤다. 수행하던 비구는 한밤중인 중야에 쉬고 밤이 끝나 가는 후야에 일어나 다시 수행했다. 그렇게 마음을 놓지 않고 지내다 오래지 않아 무애해[^r3-02]를 갖추고 아라한과를 얻었다. 게으른 비구는 내내 방일하게 지냈다.

[^r3-02]: 뜻과 가르침과 말, 그리고 앞의 세 가지를 풀이하는 데 막힘이 없는 네 가지 앎이다.

```original
Alasattheropi  paṭhamayāme visibbetvā itarassa caṅkamitvā gabbhaṃ paviṭṭhakāle pavisitvā, ‘‘mahākusīta, tvaṃ nipajjitvā sayanatthāya araññaṃ paviṭṭhosi, kiṃ buddhānaṃ santike kammaṭṭhānaṃ gahetvā uṭṭhāya samaṇadhammaṃ kātuṃ vaṭṭatī’’ti vatvā attano vasanaṭṭhānaṃ pavisitvā nipajjitvā supati. Itaropi majjhimayāme vissamitvā pacchimayāme paccuṭṭhāya samaṇadhammaṃ karoti. So evaṃ appamatto viharanto na cirasseva saha paṭisambhidāhi arahattaṃ pāpuṇi. Itaro pamādeneva kālaṃ vītināmesi.
```

<a id="cscd-02-06-u001-p004"></a>

안거를 마친 두 비구는 스승을 찾아가 예를 올리고 한쪽에 앉았다. 스승께서는 그들과 인사를 나누고 물으셨다. “비구들이여, 방일하지 않고 수행했느냐? 출가자가 해야 할 일을 마쳤느냐?”

```original
Te vuṭṭhavassā satthu santikaṃ gantvā satthāraṃ vanditvā ekamantaṃ nisīdiṃsu. Satthā tehi saddhiṃ paṭisanthāraṃ katvā, ‘‘kacci, bhikkhave, appamattā samaṇadhammaṃ karittha, kacci vo pabbajitakiccaṃ matthakaṃ patta’’nti pucchi.
```

<a id="cscd-02-06-u001-p005"></a>

방일한 비구가 먼저 말씀드렸다. “세존이시여, 이 사람이 어찌 방일하지 않았겠습니까? 숲에 가고 나서부터 줄곧 누워 자기만 했습니다.”

```original
Paṭhamaṃ pamatto bhikkhu āha – ‘‘kuto, bhante, etassa appamādo, gatakālato paṭṭhāya nipajjitvā niddāyanto kālaṃ vītināmesī’’ti.
```

<a id="cscd-02-06-u001-p006"></a>

“그러면 비구여, 너는 어떻게 지냈느냐?”

```original
‘‘Tvaṃ pana bhikkhū’’ti.
```

<a id="cscd-02-06-u001-p007"></a>

“세존이시여, 저는 이른 시각부터 땔나무를 가져다 화로에 불을 피웠습니다. 초야에는 자지 않고 불을 쬐며 앉아 있었습니다.”

```original
‘‘Ahaṃ, bhante, kālasseva dārūni āharitvā aṅgārakapallaṃ sajjetvā paṭhamayāme visibbento nisīditvā aniddāyantova kālaṃ vītināmesi’’nti.
```

<a id="cscd-02-06-u001-p008"></a>

스승께서 그에게 말씀하셨다. “너는 방일하게 시간을 보내고도 ‘나는 방일하지 않았다’고 하며, 꾸준히 수행한 이를 도리어 방일했다고 하는구나.” 이어 방일의 허물과 방일하지 않음의 이로움을 밝히시려고 말씀하셨다. “너와 내 아들을 나란히 놓고 보면, 너는 달릴 힘을 잃은 말과 같고 그는 빠르게 달리는 말과 같다.” 그리고 이 게송을 설하셨다.

```original
Atha naṃ satthā ‘‘tvaṃ pamatto kālaṃ vītināmetvā ‘appamattomhī’ti vadasi, appamattaṃ pana pamattaṃ karosī’’ti āha. Puna pamāde dose, appamāde ānisaṃse pakāsetuṃ, ‘‘tvaṃ mama puttassa  santike javacchinno dubbalasso viya, esa pana tava santike sīghajavasso viyā’’ti vatvā imaṃ gāthamāha –
```

<a id="cscd-02-06-u002"></a>
## 제29게

<a id="cscd-02-06-u002-v001"></a>

<pali-poem>

> **제29게**  
> 방일한 이들 가운데 방일하지 않고  
> 잠든 이들 가운데 밝게 깨어 있는 지혜로운 이는  
> 빠른 말이 힘없는 말을 앞지르듯  
> 그들을 뒤로하고 나아간다.

```original
29.
‘‘Appamatto  pamattesu, suttesu bahujāgaro;
Abalassaṃva sīghasso, hitvā yāti sumedhaso’’ti.
```

</pali-poem>

<a id="cscd-02-06-u003"></a>
## 배움과 성취에서 앞서가는 지혜로운 이

<a id="cscd-02-06-u003-p001"></a>

여기서 ‘방일하지 않는 이’는 마음챙김을 충분히 길러 번뇌를 다한 이를 가리킨다. ‘방일한 이들 가운데’는 마음챙김을 놓아 버린 중생들 가운데라는 뜻이다. ‘잠든 이들 가운데’는 마음챙김이 없어 어떤 자세로 있든 잠든 것과 같은 이들 가운데라는 뜻이다. ‘밝게 깨어 있는 이’는 마음챙김을 키워 늘 또렷이 깨어 있는 이다. ‘힘없는 말을 앞지르듯’이란 빠른 신다와 말[^r3-03]이 발을 제대로 쓰지 못해 달릴 힘을 잃은 말을 앞질러 가는 것과 같다. ‘지혜로운 이’는 뛰어난 지혜를 갖춘 이다.

[^r3-03]: 옛 인도의 신다와 지방에서 난 말을 이른다. 이 주석서는 제322게의 해당 풀이에서 이 뜻을 밝힌다.

```original
Tattha appamattoti sativepullappattatāya appamādasampanne khīṇāsavo. Pamattesūti sativosagge ṭhitesu sattesu. Suttesūti satijāgariyābhāvena sabbiriyāpathesu niddāyantesu. Bahujāgaroti mahante sativepulle jāgariye ṭhito. Abalassaṃvāti kuṇṭhapādaṃ chinnajavaṃ dubbalassaṃ sīghajavo sindhavājānīyo viya. Sumedhasoti uttamapañño.
```

<a id="cscd-02-06-u003-p002"></a>

지혜로운 이는 배움과 수행의 성취 모두에서 그런 사람을 앞지른다. 상대가 경 하나를 익히려고 애쓰는 동안 지혜로운 이는 여러 경을 모은 한 품을 익힌다. 상대가 밤낮으로 머물 곳을 마련하느라 애쓰며 배운 수행 주제를 되뇌는 동안, 지혜로운 이는 처음부터 남이 마련해 둔 밤이나 낮의 거처에 들어가 수행 주제를 깊이 살핀다. 그렇게 온갖 번뇌를 없애고 아홉 가지 출세간법[^r3-04]을 얻는다. 마침내 상대가 윤회에 머무는 동안 지혜로운 이는 그곳에서 벗어나 나아간다.

[^r3-04]: 아홉 가지 출세간법은 깨달음에 이르는 네 가지 도와 각각의 결과인 네 가지 과, 그리고 열반이다. 이 대목의 CSCD에 있는 *neva*를 부정으로 읽으면, 지혜로운 이가 수행의 성취에서도 앞선다는 문맥과 어긋난다. 그래서 수사 *nava*(아홉)를 전하는 태국 전자판의 독법을 따랐다. 같은 주석서의 제33게 풀이에서도 모든 번뇌를 없앤 이가 ‘아홉 가지 출세간법’을 얻는다고 한다. [태국 전자판 해당 대목](https://84000.org/tipitaka/atthapali/read_rm.php?A=1947&B=19&pagebreak=1), [제33게 풀이](https://epitaka.org/ru/book/Dhp-a/1.-meghiyattheravatthu-851).


```original
Tathārūpaṃ puggalaṃ āgamenapi adhigamenapi hitvā yāti. Mandapaññasmiñhi ekaṃ suttaṃ gahetuṃ vāyamanteyeva sumedhaso ekaṃ vaggaṃ gaṇhāti, evaṃ tāva āgamena hitvā yāti. Mandapaññe pana rattiṭṭhānadivāṭṭhānāni kātuṃ vāyamanteyeva kammaṭṭhānaṃ uggahetvā sajjhāyanteyeva ca sumedhaso pubbabhāgepi parena kataṃ rattiṭṭhānaṃ vā divāṭṭhānaṃ vā pavisitvā kammaṭṭhānaṃ sammasanto sabbakilese khepetvā neva lokuttaradhamme hatthagate  karoti, evaṃ adhigamenapi hitvā yāti. Vaṭṭe pana naṃ hitvā chaḍḍetvā vaṭṭato nissaranto yātiyevāti.
```

```original
Gāthāpariyosāne bahū sotāpattiphalādīni pāpuṇiṃsūti.
```
