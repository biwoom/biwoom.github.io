# 02-07-1 마가의 일곱 서원과 서른세 벗의 공덕
원문서명: 담마빠다 주석서(Dhammapada-aṭṭhakathā) | 저자: 미확정 | 출처: 《담마빠다 주석서》 제1부, VRI CSCD 로마자 XML 3153–3309행

- **품** · 제2품 방일하지 않음의 품(Appamādavaggo)
- **빨리어 표제** · Maghavatthu
- **게송** · 《담마빠다》 제30게
- **전체 이야기 요약** · 마할리는 붓다께 삭까를 보셨는지 묻는다. 붓다께서는 삭까가 인간 마가였을 때 세운 일곱 서원과 그 행적을 들려주시고 방일하지 않음을 칭찬하신다.
- **전체 이야기 핵심어** · 마가, 삭까, 마할리, 일곱 서원, 삼십삼천, 방일하지 않음
- **평행문헌** · 마할리의 문답, 삭까의 이름, 일곱 서원은 [〈마할리 경〉(《상윳따 니까야》 11.13)](https://dhammatalks.net/suttacentral/sc2016/sc/pi/sn11.13.html)에도 나온다. 마가와 벗들이 길을 닦고 삭까가 어린 새를 피하려 수레를 돌리는 이야기는 [《자따까》 제31편 주석](https://epitaka.org/en/book/Ja-a-i/%5B31%5D-1.-kul%C4%81vakaj%C4%81takava%E1%B9%87%E1%B9%87an%C4%81-1405)에도 나온다.

<a id="cscd-02-07-u001"></a>
## 마할리의 질문과 삭까의 일곱 이름

<a id="cscd-02-07-u001-e001"></a>

```original
7. Maghavatthu
```

<a id="cscd-02-07-u001-p001"></a>

스승께서는 웨살리 근처 꾸따가라 강당에 머무실 때 신들의 왕 삭까를 두고 ‘방일하지 않음으로 마가와는’으로 시작하는 이 법문을 설하셨다.

```original
Appamādena maghavāti imaṃ dhammadesanaṃ satthā vesāliyaṃ upanissāya kūṭāgārasālāyaṃ viharanto sakkaṃ devarājānaṃ ārabbha kathesi.
```

<a id="cscd-02-07-u001-p002"></a>

웨살리에 마할리라는 릿차위 사람이 살았다. 그는 여래께서 〈삭까의 질문 경〉[^r3-01]을 설하시는 것을 듣고 생각했다. ‘정등각자께서 삭까가 얼마나 큰 영화를 누리는지 말씀하셨다. 직접 보고 말씀하신 것일까, 보지 않고 말씀하신 것일까? 삭까를 아시는지 여쭤보자.’

[^r3-01]: 《디가 니까야》 제21경이다. 주석서의 출전 번호는 2.344 이하다. [〈삭까의 질문 경〉](https://dhammatalks.net/suttacentral/sc2016/sc/pi/dn21.html).

```original
Vesāliyañhi mahāli nāma licchavī vasati, so tathāgatassa sakkapañhasuttantadesanaṃ (dī. ni. 2.344 ādayo) sutvā ‘‘sammāsambuddho sakkasampattiṃ mahatiṃ katvā kathesi, ‘disvā nu kho kathesi, udāhu adisvā. Jānāti nu kho sakkaṃ, udāhu no’ti pucchissāmi na’’nti cintesi.
```

<a id="cscd-02-07-u001-p003"></a>

마할리는 세존께 다가가 예를 올리고 한쪽에 앉아 여쭈었다. “세존이시여, 세존께서는 신들의 제왕 삭까를 보셨습니까?”

```original
Atha kho, mahāli, licchavī yena bhagavā tenupasaṅkami, upasaṅkamitvā bhagavantaṃ abhivādetvā ekamantaṃ nisīdi, ekamantaṃ nisinno kho, mahāli, licchavī bhagavantaṃ etadavoca – ‘‘diṭṭho  kho, bhante, bhagavatā sakko devānamindo’’ti?
```

<a id="cscd-02-07-u001-p004"></a>

“마할리여, 나는 신들의 제왕 삭까를 보았다.”

```original
‘‘Diṭṭho kho me, mahāli, sakko devānamindo’’ti.
```

<a id="cscd-02-07-u001-p005"></a>

“세존이시여, 아마 삭까를 닮은 이였을 것입니다. 신들의 제왕 삭까는 보기 어렵기 때문입니다.”

```original
‘‘So hi nuna, bhante, sakkapatirūpako bhavissati. Duddaso hi, bhante, sakko devānamindo’’ti.
```

<a id="cscd-02-07-u001-p006"></a>

“마할리여, 나는 삭까를 안다. 그를 삭까가 되게 한 실천도 알고, 그가 무엇을 받아들여 지켰기에 삭까의 지위에 이르렀는지도 안다.

```original
‘‘Sakkañca khvāhaṃ, mahāli, pajānāmi sakkakaraṇe ca dhamme, yesaṃ dhammānaṃ samādinnattā sakko sakkattaṃ ajjhagā, tañca pajānāmi’’.
```

<a id="cscd-02-07-u001-p007"></a>

마할리여, 신들의 제왕 삭까는 전에 인간이었을 때 마가라는 젊은이였다. 그래서 ‘마가와’라고 불린다.

```original
Sakko, mahāli, devānamindo pubbe manussabhūto samāno magho nāma māṇavo ahosi, tasmā ‘‘maghavā’’ti vuccati.
```

<a id="cscd-02-07-u001-p008"></a>

마할리여, 신들의 제왕 삭까는 전에 인간이었을 때 먼저 나서서 보시했다. 그래서 ‘뿌린다다’라고 불린다.

```original
Sakko, mahāli, devānamindo pubbe manussabhūto samāno pure dānaṃ adāsi, tasmā ‘‘purindado’’ti vuccati.
```

<a id="cscd-02-07-u001-p009"></a>

마할리여, 신들의 제왕 삭까는 전에 인간이었을 때 정성껏 보시했다. 그래서 ‘삭까’라고 불린다.

```original
Sakko, mahāli, devānamindo pubbe manussabhūto samāno sakkaccaṃ dānaṃ adāsi, tasmā ‘‘sakko’’ti vuccati.
```

<a id="cscd-02-07-u001-p010"></a>

마할리여, 신들의 제왕 삭까는 전에 인간이었을 때 머물 곳을 마련해 주었다. 그래서 ‘와사와’라고 불린다.

```original
Sakko, mahāli, devānamindo pubbe manussabhūto samāno āvasathaṃ adāsi, tasmā ‘‘vāsavo’’ti vuccati.
```

<a id="cscd-02-07-u001-p011"></a>

마할리여, 신들의 제왕 삭까는 한순간에 천 가지 일도 생각할 수 있다. 그래서 ‘사핫삭카’라고 불린다.

```original
Sakko, mahāli, devānamindo sahassampi atthaṃ muhuttena cinteti, tasmā ‘‘sahassakkho’’ti vuccati.
```

<a id="cscd-02-07-u001-p012"></a>

마할리여, 신들의 제왕 삭까의 아내는 아수라 집안의 딸 수자다. 그래서 ‘수잠빠띠’라고 불린다.

```original
Sakkassa, mahāli, devānamindassa sujā nāma asurakaññā, pajāpati, tasmā ‘‘sujampatī’’ti vuccati.
```

<a id="cscd-02-07-u001-p013"></a>

마할리여, 신들의 제왕 삭까는 삼십삼천 신들의 왕으로서 그들을 다스린다. 그래서 ‘신들의 제왕’이라고 불린다.”

```original
Sakko, mahāli, devānamindo devānaṃ tāvatiṃsānaṃ issariyādhipaccaṃ rajjaṃ kāreti, tasmā ‘‘devānamindo’’ti vuccati.
```

<a id="cscd-02-07-u002"></a>
## 삭까의 일곱 서원

<a id="cscd-02-07-u002-p001"></a>

“마할리여, 신들의 제왕 삭까는 전에 인간이었을 때 일곱 가지 서원을 세워 모두 지켰다. 그렇게 살았기에 삭까의 지위를 얻었다. 어떤 일곱 가지인가?

```original
Sakkassa, mahāli, devānamindassa pubbe manussabhūtassa satta vatapadāni samattāni samādinnāni ahesuṃ, yesaṃ samādinnattā sakko sakkattaṃ  ajjhagā. Katamāni satta vatapadāni?
```

<a id="cscd-02-07-u002-p002"></a>

‘평생 부모를 봉양하리라. 평생 집안의 어른을 공경하리라. 평생 부드럽게 말하리라. 평생 이간질하는 말을 하지 않으리라. 평생 인색함을 버리고 살림을 꾸리며, 청하는 이에게 아낌없이 내주고 기꺼이 베풀며, 보시하고 나누는 일을 즐기리라. 평생 진실하게 말하리라. 평생 성내지 않으리라. 내게 성냄이 일어나더라도 곧 가라앉히리라.’[^r3-02]

[^r3-02]: 이 대목은 〈마할리 경〉의 *naṃ*(그것을)에 따라 ‘그 성냄을 가라앉히리라’로 읽었다. CSCD 주석서에는 *na*로 적혀 있다. [〈마할리 경〉](https://dhammatalks.net/suttacentral/sc2016/sc/pi/sn11.13.html).

```original
Yāvajīvaṃ mātāpettibharo assaṃ, yāvajīvaṃ kule jeṭṭhāpacāyī assaṃ, yāvajīvaṃ saṇhavāco assaṃ, yāvajīvaṃ apisuṇavāco assaṃ, yāvajīvaṃ vigatamalamaccherena cetasā agāraṃ ajjhāvaseyyaṃ, muttacāgo payatapāṇi vosaggarato yācayogo dānasaṃvibhāgarato assaṃ. Yāvajīvaṃ  saccavāco assaṃ, yāvajīvaṃ akkodhano assaṃ, ‘‘sacepi me kodho uppajjeyya, khippameva na paṭivineyya’’nti.
```

<a id="cscd-02-07-u002-p003"></a>

마할리여, 신들의 제왕 삭까는 전에 인간이었을 때 이 일곱 가지 서원을 세워 모두 지켰다. 그렇게 살았기에 삭까의 지위를 얻었다.

```original
Sakkassa, mahāli, devānamindassa pubbe manussabhūtassa imāni  satta vatapadāni samattāni samādinnāni ahesuṃ, yesaṃ samādinnattā sakko sakkattaṃ ajjhagāti.
```

<a id="cscd-02-07-u002-m001"></a>

<pali-poem>

> 부모를 봉양하고 집안 어른을 공경하며,  
> 온화하고 다정하게 말하며 이간질을 버리고,  
> 인색함을 다스리고 진실하게 말하며 성냄을 이긴 이,  
> 바로 그를 삼십삼천의 신들은 ‘어진 사람’이라 부른다.”  
> — 원문 출전 표기 《상윳따 니까야》 1.257

```original
‘‘Mātāpettibharaṃ jantuṃ, kule jeṭṭhāpacāyinaṃ;
Saṇhaṃ sakhilasambhāsaṃ, pesuṇeyyappahāyinaṃ.
‘‘Maccheravinaye yuttaṃ, saccaṃ kodhābhibhuṃ naraṃ;
Taṃ ve devā tāvatiṃsā, āhu sappuriso itī’’ti. (saṃ. ni. 1.257) –
```

</pali-poem>

<a id="cscd-02-07-u002-p004"></a>

“마할리여, 이것이 삭까가 젊은 마가였을 때 한 일이다.” 이렇게 말씀하시자 마할리는 그의 행실을 자세히 듣고 싶어 “세존이시여, 젊은 마가는 어떻게 살았습니까?” 하고 여쭈었다. 스승께서는 “그러면 마할리여, 들어라” 하시며 과거의 일을 들려주셨다.

```original
Idaṃ, mahāli, sakkena maghamāṇavakāle katakammanti vatvā puna tena ‘‘kathaṃ, bhante, maghamāṇavo paṭipajjī’’ti? Tassa paṭipattiṃ vitthārato sotukāmena puṭṭho ‘‘tena hi, mahāli, suṇāhī’’ti vatvā atītaṃ āhari –
```

<a id="cscd-02-07-u003"></a>
## 마가와 서른세 벗의 길 닦기

<a id="cscd-02-07-u003-p001"></a>

옛날 마가다 나라 마짤라 마을에 마가라는 젊은이가 살았다. 마가는 마을 사람들이 일하는 곳에 가서 발끝으로 흙먼지를 쓸어내고 말끔해진 자리에 섰다. 한 사람이 팔로 마가를 밀치고 그 자리를 차지했다. 마가는 화내지 않고 다른 자리를 말끔하게 하여 섰다. 또 다른 사람이 마가를 다시 팔로 밀치고 그 자리를 차지했다. 마가는 그에게도 화내지 않고 또 다른 자리를 말끔히 했다. 사람들은 집을 나올 때마다 그렇게 마가를 팔로 밀치고 깨끗한 자리를 차지했다.

```original
Atīte magadharaṭṭhe macalagāme magho nāma māṇavo  gāmakammakaraṇaṭṭhānaṃ gantvā attano ṭhitaṭṭhānaṃ pādantena paṃsuṃ viyūhitvā ramaṇīyaṃ katvā aṭṭhāsi. Aparo taṃ bāhunā paharitvā tato apanetvā sayaṃ tattha aṭṭhāsi. So tassa akujjhitvāva aññaṃ ṭhānaṃ ramaṇīyaṃ katvā ṭhito. Tatopi naṃ añño āgantvā bāhunā paharitvā apanetvā sayaṃ aṭṭhāsi. So tassapi akujjhitvāva aññaṃ ṭhānaṃ ramaṇīyaṃ katvā ṭhito, iti taṃ gehato nikkhantā nikkhantā purisā bāhunā paharitvā ṭhitaṭhitaṭṭhānato apanesuṃ.
```

<a id="cscd-02-07-u003-p002"></a>

마가는 생각했다. ‘이 사람들은 모두 나 덕에 편안해졌다. 이 일은 내게도 행복을 가져올 공덕이 틀림없다.’ 이튿날 괭이를 가져와 타작마당만 한 곳을 말끔하게 닦았다. 그러자 사람들이 모두 그곳으로 왔다. 그는 추운 철에는 불을 피워 주고 더운 철에는 물을 주었다. 그러다 생각했다. ‘누구나 쾌적한 곳을 좋아하는구나. 이제부터 다니는 길을 평평하게 닦아야겠다.’ 아침 일찍 나가 길을 고르고, 걸리적거리는 나뭇가지를 잘라 길에서 치웠다.

```original
So ‘‘sabbepete maṃ nissāya sukhitā jātā, iminā kammena mayhaṃ sukhadāyakena puññakammena bhavitabba’’nti cintetvā, punadivase kudālaṃ ādāya khalamaṇḍalamattaṃ ṭhānaṃ ramaṇīyaṃ akāsi. Sabbe gantvā tattheva aṭṭhaṃsu. Atha nesaṃ sītasamaye aggiṃ katvā adāsi, gimhakāle udakaṃ. Tato ‘‘ramaṇīyaṃ ṭhānaṃ nāma sabbesaṃ piyaṃ, kassaci appiyaṃ nāma natthi, ito paṭṭhāya mayā maggaṃ samaṃ karontena vicarituṃ vaṭṭatī’’ti cintetvā, pātova nikkhamitvā, maggaṃ samaṃ karonto chinditvā, haritabbayuttakā rukkhasākhā haranto vicarati.
```

<a id="cscd-02-07-u003-p003"></a>

어떤 사람이 그를 보고 “벗이여, 무엇을 하는가?” 물었다. “벗이여, 내가 하늘에 태어날 길을 닦고 있네[^r3-03].” “그러면 나도 자네의 벗이 되겠네.” “함께하게. 하늘은 여럿이 가도 좋을 만큼 행복이 넘치는 곳이니.”

[^r3-03]: 마가는 마을 사람이 걷는 길을 실제로 고르며, 이 일을 하늘에 태어날 공덕을 쌓는 일로 여겼다.

```original
Atha naṃ aparo disvā āha – ‘‘samma, kiṃ karosī’’ti? ‘‘Mayhaṃ saggagāminaṃ maggaṃ karomi, sammā’’ti. ‘‘Tena hi ahampi te sahāyo homī’’ti. ‘‘Hohi, samma, saggo nāma bahūnampi manāpo sukhabahulo’’ti.
```

<a id="cscd-02-07-u003-p004"></a>

그때부터 두 사람이 함께 길을 닦았다. 그들을 보고 같은 질문을 했다가 답을 듣고 합류하는 이가 하나둘 늘었다. 그렇게 일행은 모두 서른세 사람이 되었다. 그들은 모두 괭이 등을 들고 길을 고르며 한두 요자나[^r3-04]쯤 나아갔다.

[^r3-04]: 옛 인도에서 쓰던 거리 단위다.

```original
Tato paṭṭhāya dve janā  ahesuṃ. Te disvā  tatheva pucchitvā ca sutvā ca aparopi  tesaṃ sahāyo jāto, evaṃ aparopi aparopīti sabbepi tettiṃsa janā jātā. Te sabbepi kudālādihatthā maggaṃ samaṃ karontā ekayojanadviyojanamattaṭṭhānaṃ gacchanti.
```

<a id="cscd-02-07-u003-p005"></a>

마을 우두머리가 그들을 보고 생각했다. ‘이 사람들이 엉뚱한 일에 매달리는구나. 숲에서 물고기나 고기 따위를 가져오거나 술을 빚어 마시거나 그와 비슷한 일을 하면 나도 얼마쯤 얻을 텐데.’ 그는 그들을 불러 “무엇을 하러 돌아다니는가?” 하고 물었다. “어른, 하늘로 가는 길을 만들고 있습니다.” “살림을 꾸리는 사람이 그럴 일이 아니다. 숲에서 물고기나 고기를 가져오고 술을 빚어 마시며 여러 가지 일을 해야 한다.”

```original
Te disvā gāmabhojako cintesi – ‘‘ime manussā ayoge yuttā, sace ime araññato macchamaṃsādīni vā āhareyyuṃ. Suraṃ vā katvā piveyyuṃ, aññaṃ vā tādisaṃ kammaṃ kareyyuṃ, ahampi kiñci kiñci labheyya’’nti. Atha ne pakkosāpetvā pucchi – ‘‘kiṃ karontā vicarathā’’ti? ‘‘Saggamaggaṃ, sāmī’’ti. ‘‘Gharāvāsaṃ vasantehi nāma evaṃ kātuṃ na vaṭṭati, araññato macchamaṃsādīni āharituṃ, suraṃ katvā pātuṃ, nānappakāre ca kammante kātuṃ vaṭṭatī’’ti.
```

<a id="cscd-02-07-u003-p006"></a>

그들은 그의 말을 거절했다. 거듭 권해도 거절하자 우두머리는 화를 내며 ‘저들을 없애 버리겠다’고 마음먹었다. 왕에게 가서 “전하, 도둑들이 떼를 지어 돌아다니는 것을 봤습니다”라고 했다. “가서 붙잡아 오너라.” 그는 그들을 모두 묶어 왕 앞에 데려왔다. 왕은 조사도 하지 않고 “코끼리로 짓밟게 하라” 하고 명령했다.

```original
Te tassa vacanaṃ paṭikkhipiṃsu, evaṃ punappunaṃ vuccamānāpi paṭikkhipiṃsuyeva. So kujjhitvā ‘‘nāsessāmi ne’’ti rañño santikaṃ gantvā, ‘‘core te, deva, vaggabandhanena vicarante passāmī’’ti vatvā, ‘‘gaccha, te gahetvā ānehī’’ti vutte tathā katvā sabbe te bandhitvā ānetvā rañño dassesi. Rājā avīmaṃsitvāva ‘‘hatthinā maddāpethā’’ti āṇāpesi.
```

<a id="cscd-02-07-u003-p007"></a>

마가가 벗들에게 일렀다. “벗들이여, 자애 외에는 우리에게 의지할 것이 없네. 아무에게도 성내지 말게. 왕과 마을 우두머리와 우리를 밟으러 오는 코끼리에게도, 우리 자신에게도 모두 똑같이 자애를 보내세.” 그들이 그대로 하자 자애의[^r3-05] 힘으로 코끼리는 가까이 다가가지도 못했다. 왕은 그 말을 듣고 “사람이 많아 보여 밟지 못하는 게냐? 가서 저들을 돗자리로 덮은 뒤 밟게 하라” 했다. 그들을 돗자리로 덮고 코끼리를 보내도 코끼리는 멀리서부터 물러났다.

[^r3-05]: 다른 존재가 안녕하고 행복하기를 바라는 마음이다. 마가는 그 마음을 자신들과 위협하는 이들 모두에게 내라고 했다.

```original
Magho sesānaṃ ovādamadāsi – ‘‘sammā, ṭhapetvā mettaṃ añño amhākaṃ avassayo natthi, tumhe katthaci kopaṃ akatvā raññe ca gāmabhojake ca maddanahatthimhi ca attani ca mettacittena samacittāva hothā’’ti. Te tathā kariṃsu. Atha nesaṃ mettānubhāvena hatthī uppasaṅkamitumpi na visahi. Rājā tamatthaṃ sutvā bahū  manusse disvā maddituṃ na visahissati? ‘‘Gacchatha, ne kilañjena paṭicchādetvā maddāpethā’’ti āha. Te kilañjena paṭicchādetvā maddituṃ pesiyamānopi hatthī dūratova paṭikkami.
```

<a id="cscd-02-07-u003-p008"></a>

왕은 사연을 듣고 ‘코끼리가 가까이 가지 않는 데 까닭이 있겠구나’ 하며 그들을 불러 물었다. “얘들아, 내가 너희에게 해 주지 않은 일이 있느냐?” “무슨 말씀이십니까, 전하?” “너희가 떼를 지어 숲을 돌아다니는 도둑이라더구나.” “누가 그렇게 말했습니까, 전하?” “마을의 우두머리가 그러더구나.” “전하, 저희는 도둑이 아닙니다. 저희가 한 일은 이러저러합니다. 그렇게 공덕을 쌓아 하늘에 태어날 길을 닦고 있습니다. 우두머리는 저희에게 나쁜 일을 시켰습니다. 저희가 말을 따르지 않자 화가 나서 저희를 없애려고 그렇게 말한 것입니다.”

```original
Rājā taṃ pavattiṃ sutvā ‘‘kāraṇenettha bhavitabba’’nti te pakkosāpetvā pucchi – ‘‘tātā, maṃ nissāya tumhe kiṃ na labhathā’’ti? ‘‘Kiṃ nāmetaṃ, devā’’ti? ‘‘Tumhe kira vaggabandhanena corā hutvā araññe vicarathā’’ti? ‘‘Ko evamāha, devā’’ti? ‘‘Gāmabhojako, tātā’’ti. ‘‘Na mayaṃ, deva, corā, mayaṃ pana attano saggamaggaṃ sodhentā idañcidañca karoma, gāmabhojako amhe akusalakiriyāya niyojetvā attano vacanaṃ akaronte nāsetukāmo kujjhitvā evamāhā’’ti.
```

<a id="cscd-02-07-u003-p009"></a>

왕은 그 말을 듣고 기뻐하며 말했다. “얘들아, 저 짐승도 너희의 덕을 아는데 나는 사람으로서 알지 못했구나. 나를 용서해 다오.” 왕은 우두머리와 그의 아내와 자식들을 그들의 종으로 삼게 했다. 타고 다닐 코끼리도 내주었고, 그 마을도 그들이 뜻대로 이용하게 했다.

```original
Atha rājā tesaṃ kathaṃ sutvā somanassappatto hutvā, ‘‘tātā, ayaṃ tiracchāno tumhākaṃ  guṇe jānāti, ahaṃ manussabhūto jānituṃ nāsakkhiṃ, khamatha me’’ti. Evañca pana vatvā saputtadāraṃ gāmabhojakaṃ tesaṃ dāsaṃ, hatthiṃ ārohaniyaṃ, tañca gāmaṃ yathāsukhaṃ paribhogaṃ katvā adāsi.
```

<a id="cscd-02-07-u003-p010"></a>

그들은 ‘우리가 지은 공덕이 어떤 이로움을 가져오는지 여기서 보았구나’ 하며 선한 일에 대한 믿음이 한층 깊어졌다. 코끼리를 번갈아 타고 가면서 의논했다. “이제 더 많은 공덕을 지어야겠네. 무엇을 할까? 큰길 네 갈래가 만나는 곳에 오래 쓸 쉼터를 지어 사람들이 쉬어 가게 하세.” 그들은 목수를 불러 쉼터를 짓기 시작했다. 그러나 여자들과 함께할 마음이 없어 쉼터를 짓는 공덕에 여자들을 참여시키지 않았다.

```original
Te ‘‘idheva no katapuññassānisaṃso diṭṭho’’ti bhiyyosomattāya pasannamānasā hutvā taṃ hatthiṃ vārena vārena abhiruyha gacchantā mantayiṃsu  ‘‘idāni amhehi  atirekataraṃ puññaṃ kātabbaṃ, kiṃ karoma? Catumahāpathe thāvaraṃ katvā mahājanassa vissamanasālaṃ karissāmā’’ti. Te vaḍḍhakiṃ pakkosāpetvā sālaṃ paṭṭhapesuṃ. Mātugāmesu pana vigatacchandatāya tassā sālāya mātugāmānaṃ pattiṃ nādaṃsu.
```

<a id="cscd-02-07-u004"></a>
## 쉼터를 짓고 공덕에 참여하다

<a id="cscd-02-07-u004-p001"></a>

마가의 집에는 난다, 찟따, 수담마, 수자라는 네 여인이 있었다. 수담마는 목수에게 뇌물을 주며 “이 쉼터를 지은 사람들 가운데 제 이름이 맨 앞에 오르게 해 주세요” 하고 부탁했다. 목수는 그러겠다고 했다. 먼저 지붕 꼭대기에 달 장식의 나무를 말리고 깎은 뒤 구멍을 뚫어 장식을 완성했다. 거기에 ‘이 쉼터는 수담마라 한다’라고 글자를 새기고 천에 싸 두었다.

```original
Maghassa pana gehe nandā, cittā, sudhammā, sujāti catasso itthiyo honti. Tāsu sudhammā vaḍḍhakinā saddhiṃ ekato hutvā, ‘‘bhātika, imissā sālāya maṃ jeṭṭhikaṃ karohī’’ti vatvā lañjaṃ adāsi. So ‘‘sādhū’’ti sampaṭicchitvā paṭhamameva kaṇṇikatthāya rukkhaṃ sukkhāpetvā tacchetvā vijjhitvā kaṇṇikaṃ niṭṭhāpetvā, ‘‘sudhammā nāma ayaṃ sālā’’ti akkharāni chinditvā vatthena paliveṭhetvā ṭhapesi.
```

<a id="cscd-02-07-u004-p002"></a>

목수가 쉼터를 다 짓고 장식을 올릴 날에 “어르신들, 할 일 하나를 잊었습니다”라고 했다. “무엇인가?” “지붕 꼭대기 장식입니다.” “그러면 이제 가져오게.” “이제 막 벤 나무로는 만들 수 없습니다. 미리 베고 깎고 구멍을 내어 둔 장식을 구해야 합니다.” “이제 어찌해야 하는가?” “이미 만들어 둔 장식을 파는 집을 찾아야 합니다.”

```original
Atha ne vaḍḍhakī sālaṃ niṭṭhāpetvā kaṇṇikāropanadivase ‘‘aho, ayyā, ekaṃ karaṇīyaṃ na sarimhā’’ti āha. ‘‘Kiṃ nāma, bho’’ti? ‘‘Kaṇṇika’’nti. ‘‘Hotu taṃ āharissāmā’’ti. ‘‘Idāni chinnarukkhena kātuṃ na sakkā, pubbeyeva taṃ chinditvā tacchetvā vijjhitvā ṭhapitakaṇṇikā laddhuṃ vaṭṭatī’’ti. ‘‘Idāni kiṃ kātabba’’nti? ‘‘Sace kassaci gehe niṭṭhāpetvā ṭhapitā vikkāyikakaṇṇikā  atthi, sā pariyesitabbā’’ti.
```

<a id="cscd-02-07-u004-p003"></a>

그들은 찾다가 수담마의 집에서 장식을 발견했다. 돈 천 닢을 주겠다고 해도 수담마는 팔지 않았다. 수담마가 “저를 쉼터를 짓는 일에 참여시켜 주면 드리겠습니다” 하자 그들은 “여자를 이 공덕에 참여시킬 수는 없소”라고 했다. 목수가 “어르신들, 무슨 말씀입니까? 범천 세계를 빼면 여자가 없는 곳이 어디 있습니까? 장식을 받으십시오. 그래야 일이 끝납니다”라고 했다.

```original
Te pariyesantā sudhammāya gehe disvā sahassaṃ datvāpi mūlena na labhiṃsu. ‘‘Sace maṃ sālāya pattiṃ karotha, dassāmī’’ti vutte pana ‘‘mayaṃ mātugāmānaṃ pattiṃ na dammā’’ti āhaṃsu.
Atha ne vaḍḍhakī āha – ‘‘ayyā, tumhe kiṃ kathetha, ṭhapetvā brahmalokaṃ aññaṃ mātugāmarahitaṭṭhānaṃ nāma natthi, gaṇhatha kaṇṇikaṃ. Evaṃ sante amhākaṃ kammaṃ niṭṭhaṃ gamissatī’’ti.
```

<a id="cscd-02-07-u004-p004"></a>

그들은 수담마의 장식을 받아 쉼터를 완성하고, 안을 세 구역으로 나누었다. 한 곳은 지위 높은 이들이, 한 곳은 가난한 이들이, 한 곳은 병든 이들이 머무는 곳으로 삼았다. 서른세 사람은 쉴 자리에 쓸 널판을 하나씩, 모두 서른세 개 놓고 코끼리에게 일러 두었다. “나그네가 어느 널판에 앉든 그 널판을 놓은 사람의 집으로 데려다주어라. 나그네의 발과 등을 돌봐 주고 물과 음식과 잠자리를 내주는 일은 모두 그 집 주인의 몫이다.” 코끼리는 나그네가 오면 자리에 맞는 집으로 데려갔다. 집주인은 그날 그 나그네를 돌봤다.

```original
Te ‘‘sādhū’’ti kaṇṇikaṃ gahetvā sālaṃ niṭṭhāpetvā tidhā vibhajiṃsu. Ekasmiṃ koṭṭhāse issarānaṃ vasanaṭṭhānaṃ kariṃsu, ekasmiṃ duggatānaṃ, ekasmiṃ gilānānaṃ. Tettiṃsa janā tettiṃsa phalakāni paññapetvā hatthissa saññaṃ adaṃsu – ‘‘āgantuko āgantvā yassa atthataphalake nisīdati, taṃ gahetvā phalakasāmikasseva  gehe patiṭṭhapehi, tassa pādaparikammapiṭṭhiparikammapānīyakhādanīyabhojanīyasayanāni sabbāni phalakasāmikasseva bhāro bhavissatī’’ti. Hatthī āgatāgataṃ gahetvā phalakasāmikasseva gharaṃ neti. So tassa taṃ divasaṃ kattabbaṃ karoti.
```

<a id="cscd-02-07-u004-p005"></a>

마가는 쉼터에서 멀지 않은 곳에 꼬윌라라 나무를 심고 그 밑에 돌판을 놓았다. 쉼터에 온 사람들은 지붕 장식에 새겨진 글을 보고 “이 쉼터는 수담마라 하는구나”라고 했다. 서른세 사람의 이름은 알려지지 않았다.

```original
Magho sālāya avidūre koviḷārarukkhaṃ ropetvā tassa mūle pāsāṇaphalakaṃ atthari. Sālaṃ paviṭṭhapaviṭṭhā janā kaṇṇikaṃ oloketvā akkharāni vācetvā, ‘‘sudhammā nāmesā sālā’’ti vadanti. Tettiṃsajanānaṃ nāmaṃ na paññāyati.
```

<a id="cscd-02-07-u004-p006"></a>

난다는 생각했다. ‘이들이 쉼터를 지을 때 우리를 빼놓았는데도 수담마는 꾀를 내어 장식을 바치고 참여했구나. 나도 무엇인가 해야겠다. 무엇을 할까?’ 난다는 쉼터에 오는 사람들이 물을 마시고 몸을 씻을 수 있도록 연못을 팠다.

```original
Nandā cintesi – ‘‘ime sālaṃ karontā amhe apattikā kariṃsu, sudhammā  pana attano byattatāya kaṇṇikaṃ katvā pattikā jātā, mayāpi kiñci kātuṃ vaṭṭati, kiṃ nu kho karissāmī’’ti? Athassā etadahosi  – ‘‘sālaṃ āgatāgatānaṃ pānīyañceva nhānodakañca laddhuṃ vaṭṭati, pokkharaṇiṃ khaṇāpessāmī’’ti. Sā pokkharaṇiṃ kāresi.
```

<a id="cscd-02-07-u004-p007"></a>

찟따는 생각했다. ‘수담마는 장식을 내놓고 난다는 연못을 만들었다. 나도 무엇인가 해야겠다. 무엇을 할까?’ 찟따는 ‘쉼터에 온 사람들이 물을 마시고 몸을 씻은 뒤 꽃다발을 걸고 떠날 수 있으면 좋겠다. 꽃동산을 만들어야겠다’ 하고 아름다운 꽃동산을 만들었다. 그 동산에는 꽃이 피거나 열매를 맺는 나무라면 거의 다 있었다.

```original
Cittā cintesi – ‘‘sudhammāya kaṇṇikā dinnā, nandāya pokkharaṇī kāritā, mayāpi kiñci kātuṃ vaṭṭati, kiṃ nu kho karissāmī’’ti? Athassā etadahosi – ‘‘sālaṃ āgatāgatehi pānīyaṃ pivitvā nhatvā gamanakālepi mālaṃ pilandhitvā gantuṃ vaṭṭati, pupphārāmaṃ kārāpessāmī’’ti. Sā ramaṇīyaṃ pupphārāmaṃ kāresi. Yebhuyyena tasmiṃ ārāme ‘‘asuko nāma pupphūpagaphalūpagarukkho natthī’’ti nāhosi.
```

<a id="cscd-02-07-u004-p008"></a>

수자는 생각했다. ‘나는 마가의 외삼촌 딸이자 그의 아내다. 그가 한 일은 곧 내가 한 일이고, 내가 한 일은 곧 그가 한 일이다.’ 수자는 아무 공덕도 쌓지 않고 몸을 꾸미며 지냈다.

```original
Sujā pana ‘‘ahaṃ maghassa mātuladhītā ceva pādaparicārikā ca, etena kataṃ kammaṃ mayhameva, mayā kataṃ etassevā’’ti cintetvā, kiñci akatvā attabhāvameva maṇḍayamānā kālaṃ vītināmesi.
```

<a id="cscd-02-07-u004-p009"></a>

마가는 부모를 모시고 집안 어른을 공경하며, 진실하게 말하고 부드럽게 말하고 이간질을 삼갔다. 인색함을 다스려 베풀고 성내지 않았다. 마가는 이렇게 일곱 서원을 모두 지켰다.

```original
Maghopi mātāpituupaṭṭhānaṃ kule jeṭṭhāpacāyanakammaṃ saccavācaṃ apharusavācaṃ api, suṇavācaṃ maccheravinayaṃ akkodhananti imāni satta vatapadāni pūretvā –
```

<a id="cscd-02-07-u005"></a>
## 삼십삼천에 태어난 마가와 벗들

<a id="cscd-02-07-u005-m001"></a>

<pali-poem>

> 부모를 봉양하고 집안 어른을 공경하며,  
> 온화하고 다정하게 말하며 이간질을 버리고,  
> 인색함을 다스리고 진실하게 말하며 성냄을 이긴 이,  
> 바로 그를 삼십삼천의 신들은 ‘어진 사람’이라 부른다.  
> — 원문 출전 표기 《상윳따 니까야》 1.257

```original
‘‘Mātāpettibharaṃ  jantuṃ, kule jeṭṭhāpacāyinaṃ;
Saṇhaṃ sakhilasambhāsaṃ, pesuṇeyyappahāyinaṃ.
‘‘Maccheravinaye yuttaṃ, saccaṃ kodhābhibhuṃ naraṃ;
Taṃ ve devā tāvatiṃsā, āhu ‘sappuriso’itī’’ti. (saṃ. ni. 1.257) –
```

</pali-poem>

<a id="cscd-02-07-u005-p001"></a>

이렇게 칭찬받을 일을 하며 산 마가는 죽어서 삼십삼천에 신들의 왕 삭까로 태어났다. 벗들도 그곳에 태어났고 목수는 신 위사깜마로 태어났다.

```original
Evaṃ pasaṃsiyabhāvaṃ āpajjitvā jīvitapariyosāne tāvatiṃsabhavane sakko devarājā hutvā nibbatti, tepissa sahāyakā tattheva  nibbattiṃsu, vaḍḍhakī vissakammadevaputto hutvā nibbatti.
```

<a id="cscd-02-07-u005-p002"></a>

당시 삼십삼천에는 아수라들이 살았다. 그들은 ‘새로운 신들이 태어났구나’ 하며 하늘의 술을 준비했다. 삭까는 함께 태어난 벗들에게 아무도 그 술을 마시지 말라고 일러 두었다. 아수라들은 하늘의 술을 마시고 취했다. 삭까는 ‘이들과 함께 다스려 무엇하랴?’ 하고 무리에게 신호하여 아수라들의 발을 잡아 큰 바다에 던지게 했다. 아수라들은 머리부터 바다에 떨어졌다. 아수라들이 지은 공덕으로 시네루산 아래에 그들의 궁전과 찟따빠딸리 나무가 생겨났다.

```original
Tadā tāvatiṃsabhavane asurā vasanti. Te ‘‘abhinavā devaputtā nibbattā’’ti dibbapānaṃ sajjayiṃsu. Sakko attano parisāya kassaci apivanatthāya saññamadāsi. Asurā dibbapānaṃ pivitvā majjiṃsu. Sakko ‘‘kiṃ me imehi sādhāraṇena rajjenā’’ti attano parisāya saññaṃ datvā te pādesu gāhāpetvā mahāsamudde khipāpesi. Te avaṃsirā samudde patiṃsu. Atha nesaṃ puññānubhāvena sineruno heṭṭhimatale asuravimānaṃ nāma nibbatti, cittapāṭali nāma nibbatti.
```

<a id="cscd-02-07-u005-p003"></a>

신들과 아수라들이 싸워 아수라들이 패하자 삼십삼천 신들의 도성이 생겨났다. 동문에서 서문까지도, 남문에서 북문까지도 일만 요자나였다. 성문이 천 개였고 동산과 연못으로 꾸며져 있었다. 그 한가운데 쉼터를 지은 과보로 일곱 보배로 된 웨자얀따 궁전이 솟아났다. 궁전은 높이가 칠백 요자나였고, 높이 삼백 요자나의 깃발들로 장식되어 있었다. 금 깃대에는 보석 깃발이, 보석 깃대에는 금 깃발이, 산호 깃대에는 진주 깃발이, 진주 깃대에는 산호 깃발이, 일곱 보배로 된 깃대에는 일곱 보배로 된 깃발이 걸려 있었다. 가운데 깃발은 높이가 삼백 요자나였다.

```original
Devāsurasaṅgāme pana asuresu parājitesu dasayojanasahassaṃ tāvatiṃsadevanagaraṃ nāma nibbatti. Tassa pana nagarassa pācīnapacchimadvārānaṃ antarā dasayojanasahassaṃ hoti, tathā dakkhiṇuttaradvārānaṃ. Taṃ kho pana nagaraṃ dvārasahassayuttaṃ ahosi ārāmapokkharaṇipaṭimaṇḍitaṃ. Tassa  majjhe sālāya  nissandena tiyojanasatubbedhehi dhajehi paṭimaṇḍito sattaratanamayo sattayojanasatubbedho vejayanto nāma pāsādo uggañchi. Suvaṇṇayaṭṭhīsu maṇidhajā ahesuṃ, maṇiyaṭṭhīsu suvaṇṇadhajā; pavāḷayaṭṭhīsu muttadhajā, muttayaṭṭhīsu pavāḷadhajā; sattaratanamayāsu yaṭṭhīsu sattaratanadhajā, majjhe ṭhito dhajo tiyojanasatubbedho ahosi.
```

<a id="cscd-02-07-u005-p004"></a>

이렇게 쉼터를 지은 과보로 깃발까지 높이가 천 요자나[^r3-06]에 이르는 궁전이 일곱 보배로 되어 생겨났다. 꼬윌라라 나무를 심은 과보로 둘레가 삼백 요자나인 빠릿찻따까 나무가 생겨났다. 돌판을 놓은 과보로 그 나무 밑에 길이 육십 요자나, 너비 오십 요자나, 두께 십오 요자나인 빤두깜발라 바위가 생겨났다. 빛깔은 자야수마나 꽃과 붉은 모직 같았다. 그 위에 앉으면 몸이 반쯤 들어가고, 일어나면 오목해진 곳이 다시 차올랐다.

[^r3-06]: 주석은 궁전 자체를 칠백 요자나, 가운데 깃발을 삼백 요자나라고 한 뒤 궁전의 전체 높이를 천 요자나로 적는다. 같은 이야기를 전하는 〈삭까의 질문 경〉 주석도 궁전과 깃발의 높이를 따로 제시한다. 그래서 여기서는 천 요자나를 가운데 깃발까지 합친 높이로 읽었다. [〈삭까의 질문 경〉 주석](https://epitaka.org/en/book/Sv-ii/magham%C4%81%E1%B9%87avavatthu-1260).


```original
Iti sālāya nissandena yojanasahassubbedho pāsādo sattaratanamayova hutvā nibbatti, koviḷārarukkhassa nissandena samantā tiyojanasataparimaṇḍalo pāricchattako nibbatti, pāsāṇaphalakassa nissandena pāricchattakamūle dīghato saṭṭhiyojanā puthulato paṇṇāsayojanā bahalato pañcadasayojanā jayasumanarattakambalavaṇṇā paṇḍukambalasilā nibbatti. Tattha nisinnakāle upaḍḍhakāyo pavisati, uṭṭhitakāle ūnaṃ paripūrati.
```
