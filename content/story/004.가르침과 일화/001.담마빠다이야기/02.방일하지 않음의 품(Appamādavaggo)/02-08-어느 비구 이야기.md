# 02-08 어느 비구 이야기
원문서명: 담마빠다 주석서(Dhammapada-aṭṭhakathā) | 저자: 미확정 | 출처: 《담마빠다 주석서》 제1부, VRI CSCD 로마자 XML 3313–3345행

- **품** · 제2품 방일하지 않음의 품(Appamādavaggo)
- **빨리어 표제** · Aññatarabhikkhuvatthu
- **게송** · 《담마빠다》 제31게
- **요약** · 어느 비구가 산불을 보고 지혜로 윤회의 결박을 끊는 수행을 떠올린다. 붓다께서는 그의 생각을 아시고 게송을 설하신다.
- **핵심어** · 방일하지 않음, 산불, 결(結), 지혜, 아라한과

<a id="cscd-02-08-u001"></a>
## 산불을 보고 수행을 떠올린 비구

<a id="cscd-02-08-u001-e001"></a>

```original
8. Aññatarabhikkhuvatthu
```

<a id="cscd-02-08-u001-p001"></a>

스승께서는 제따와나에 머무실 때 어느 비구를 두고 ‘방일하지 않음을 즐기는 비구’로 시작하는 이 법문을 설하셨다.

```original
Appamādarato bhikkhūti imaṃ dhammadesanaṃ satthā jetavane viharanto aññataraṃ bhikkhuṃ ārabbha kathesi.
```

<a id="cscd-02-08-u001-p002"></a>

그 비구는 아라한과에 이르는 수행법을 스승께 배워 숲으로 들어갔다. 열심히 수행했지만 아라한과를 얻지는 못했다. 그는 수행법을 더 자세히 가르쳐 달라고 청하려고 숲을 나섰다. 스승께 가는 길에 큰 산불을 보고 서둘러 나무 없는 산꼭대기에 올라앉았다. 숲을 태우는 불길을 지켜보며 이렇게 생각했다.

```original
So kira satthu santike yāva arahattā kammaṭṭhānaṃ kathāpetvā araññaṃ pavisitvā ghaṭento vāyamanto arahattaṃ pattuṃ nāsakkhi. So ‘‘visesetvā kammaṭṭhānaṃ kathāpessāmī’’ti tato nikkhamitvā satthu santikaṃ āgacchanto antarāmagge mahantaṃ dāvaggiṃ uṭṭhitaṃ disvā vegena ekaṃ muṇḍapabbatamatthakaṃ abhiruyha nisinno araññaṃ  ḍayhamānaṃ aggiṃ disvā ārammaṇaṃ gaṇhi –
```

<a id="cscd-02-08-u001-p003"></a>

“이 불이 크고 작은 땔감을 태우며 나아가듯, 나도 성스러운 길에서 얻는 지혜의 불로 크고 작은 결(結)[^r3-01]을 태우며 나아가야겠다.”

[^r3-01]: 중생을 윤회에 묶어 두는 마음의 결박이다. 《앙굿따라 니까야》는 감각에 대한 욕망, 성냄, 무지 등을 포함한 열 가지 결을 든다. [〈결 경〉](https://suttacentral.net/an10.13/en/sujato).

```original
‘‘yathā ayaṃ aggi mahantāni ca khuddakāni ca upādānāni ḍahanto gacchati, evaṃ ariyamaggañāṇaggināpi mahantāni ca khuddakāni ca saṃyojanāni ḍahantena gantabbaṃ bhavissatī’’ti.
```

<a id="cscd-02-08-u001-p004"></a>

스승께서는 향실에 앉으신 채 그의 생각을 아시고 말씀하셨다. “비구여, 바로 그렇다. 크고 작은 땔감과 같은 미세하고 거친 결이 중생들의 마음에서 일어난다. 지혜의 불로 그 결을 태워 다시 일어나지 않게 해야 한다.” 그리고 빛을 내어 비구 앞에 앉으신 듯 모습을 드러내고 이 게송을 설하셨다.

```original
Satthā gandhakuṭiyaṃ nisinnova tassa cittācāraṃ ñatvā, ‘‘evameva, bhikkhu, mahantānipi khuddakānipi upādānāni viya imesaṃ sattānaṃ abbhantare uppajjamānāni aṇuṃthūlāni saṃyojanāni, tāni  ñāṇagginā jhāpetvā abhabbuppattikāni kātuṃ vaṭṭatī’’ti vatvā obhāsaṃ vissajjetvā tassa bhikkhuno abhimukhe nisinno viya paññāyamāno imaṃ obhāsagāthamāha –
```

<a id="cscd-02-08-u002"></a>
## 제31게

<a id="cscd-02-08-u002-v001"></a>

<pali-poem>

> **제31게**  
> 방일하지 않음을 즐기거나  
> 방일의 위험을 아는 비구는  
> 미세하든 거칠든 온갖 결을  
> 불처럼 태우며 나아간다.

```original
31.
‘‘Appamādarato bhikkhu, pamāde bhayadassi vā;
Saṃyojanaṃ aṇuṃ thūlaṃ, ḍahaṃ aggīva gacchatī’’ti.
```

</pali-poem>

<a id="cscd-02-08-u003"></a>
## 게송의 어구 풀이와 비구의 아라한과

<a id="cscd-02-08-u003-p001"></a>

여기서 ‘방일하지 않음을 즐긴다’는 말은 마음챙김을 놓지 않는 것을 기뻐하며 그렇게 살아간다는 뜻이다. ‘방일의 위험을 안다’는 말은 지옥에 태어나는 일처럼 방일이 불러오는 결과가 얼마나 두려운지 안다는 뜻이다. 그런 결과를 부르는 방일 자체를 두렵게 여긴다는 뜻도 있다.

```original
Tattha appamādaratoti appamāde rato abhirato, appamādena vītināmentoti attho. Pamāde bhayadassi vāti nirayuppattiādikaṃ pamāde bhayaṃ bhayato passanto, tāsaṃ vā uppattīnaṃ mūlattā pamādaṃ bhayato passanto.
```

<a id="cscd-02-08-u003-p002"></a>

여기서 ‘결’은 중생을 윤회의 괴로움에 묶어 두는 열 가지 마음의 결박을 가리킨다. ‘미세하든 거칠든’이란 결박이 작든 크든 모두라는 뜻이다. 산불이 크고 작은 땔감을 태우며 번지듯, 방일하지 않는 비구는 그렇게 해서 얻은 지혜의 불로 온갖 결을 태우며 나아간다. 한 번 태운 결은 다시 일어나지 않는다.

```original
Saṃyojananti vaṭṭadukkhena saddhiṃ yojanaṃ bandhanaṃ pajānaṃ vaṭṭe osīdāpanasamatthaṃ dasavidhaṃ saṃyojanaṃ. Aṇuṃ thūlanti mahantañca khuddakañca. Ḍahaṃ aggīva gacchatīti yathā ayaṃ aggī etaṃ mahantañca  khuddakañca upādānaṃ ḍahantova gacchati. Evameso  appamādarato bhikkhu appamādādhigatena ñāṇagginā etaṃ saṃyojanaṃ ḍahanto abhabbuppattikaṃ karonto gacchatīti attho.
```

<a id="cscd-02-08-u003-p003"></a>

게송이 끝나자 그 비구는 앉은 자리에서 모든 결을 태우고 네 가지 무애해[^r3-02]를 갖추고 아라한과를 얻었다. 그는 허공을 날아 스승께 와서 여래의 황금빛 몸을 찬탄하고 예를 올린 뒤 떠났다.

[^r3-02]: 뜻과 가르침과 말, 그리고 앞의 세 가지를 풀이하는 데 막힘이 없는 네 가지 앎이다.

```original
Gāthāpariyosāne so bhikkhu yathānisinnova sabbasaṃyojanāni jhāpetvā saha paṭisambhidāhi arahattaṃ patvā ākāsenāgantvā tathāgatassa suvaṇṇavaṇṇaṃ sarīraṃ thometvā vaṇṇetvā vandamānova pakkāmīti.
```

<a id="cscd-02-08-u003-e001"></a>

```original

```
