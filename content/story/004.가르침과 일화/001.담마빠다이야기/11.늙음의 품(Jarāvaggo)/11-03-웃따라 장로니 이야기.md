# 11-03 웃따라 장로니 이야기
원문서명: 담마빠다 주석서(Dhammapada-aṭṭhakathā) | 저자: 미확정 | 출처: 《담마빠다 주석서》 제2부, VRI CSCD 로마자 XML 9601–9633행

- **품** · 제11품 늙음의 품(Jarāvaggo)
- **빨리어 표제** · Uttarātherīvatthu
- **게송** · 제148게
- **요약** · 백스무 살의 웃따라 장로니가 사흘 동안 탁발로 얻은 음식을 한 비구에게 모두 준다. 나흘째 길을 비키다 넘어지자 스승께서는 이 몸에 병이 깃들고 목숨은 죽음으로 끝난다고 설하신다.
- **핵심어** · 웃따라 장로니, 탁발, 늙음, 병, 죽음, 예류과
- **평행문헌** · [파뜨나 《법구경》 제259게](https://ancient-buddhist-texts.net/Texts-and-Translations/Patna-Dhammapada/14-Patience.htm), [간다리 《법구경》 제142게](https://dhammarain.github.io/canon/sutta/khuddaka/dhammapada/Dharmapada-Gandari.pdf), [《우다나바르가》 1.34](https://ancient-buddhist-texts.net/Texts-and-Translations/Udanavarga/01-Anitya.htm), [《수바르나바르나 아바다나》 제3게](https://gretil.sub.uni-goettingen.de/gretil/corpustei/transformations/html/sa_suvarNavarNAvadAna.htm)

<a id="cscd-11-03-u001"></a>
## 웃따라 장로니가 탁발 음식을 내어 주다

<a id="cscd-11-03-u001-e001"></a>

```original
3. Uttarātherīvatthu
```

<a id="cscd-11-03-u001-p001"></a>

스승께서는 제따와나에 머무실 때 비구니 웃따라 장로니를 두고 ‘이 몸은 늙을 대로 늙었다’로 시작하는 이 법문을 설하셨다.

```original
Parijiṇṇamidanti  imaṃ dhammadesanaṃ satthā jetavane viharanto uttarātheriṃ nāma bhikkhuniṃ ārabbha kathesi.
```

<a id="cscd-11-03-u001-p002"></a>

장로니는 백스무 살이었다고 한다. 탁발로 음식을 얻은 뒤 길에서 비구 한 사람을 만나 음식을 받겠느냐고 물었다. 비구가 사양하지 않자 장로니는 얻은 음식을 모두 내주고 자신은 끼니를 걸렀다. 둘째 날도 셋째 날도 같은 곳에서 같은 비구에게 음식을 주고 굶었다.

```original
Therī kira vīsavassasatikā jātiyā piṇḍāya caritvā laddhapiṇḍapātā antaravīthiyaṃ ekaṃ bhikkhuṃ disvā piṇḍapātena āpucchitvā tassa apaṭikkhipitvā gaṇhantassa sabbaṃ datvā nirāhārā ahosi. Evaṃ dutiyepi tatiyepi divase tasseva bhikkhuno tasmiṃyeva ṭhāne bhattaṃ datvā nirāhārā ahosi,
```

<a id="cscd-11-03-u001-p003"></a>

나흘째에도 탁발을 다니다가 좁은 길에서 스승을 뵈었다. 길을 비켜 드리려고 물러서다 늘어진 가사 자락을 밟았다. 몸을 가누지 못해 휘청 돌며 넘어졌다. 스승께서 다가가 “누이여, 그대의 몸은 늙을 대로 늙었다. 머지않아 무너질 것이다” 하고 이 게송을 읊으셨다.

```original
catutthe divase pana piṇḍāya carantī ekasmiṃ sambādhaṭṭhāne satthāraṃ disvā paṭikkamantī olambantaṃ attano cīvarakaṇṇaṃ akkamitvā saṇṭhātuṃ asakkontī parivattitvā pati. Satthā tassā santikaṃ gantvā, ‘‘bhagini, parijiṇṇo te attabhāvo na cirasseva bhijjissatī’’ti vatvā imaṃ gāthamāha –
```

<a id="cscd-11-03-u002"></a>
## 제148게와 병이 깃든 몸

<a id="cscd-11-03-u002-v001"></a>

<pali-poem>

> **제148게**  
> 이 몸은 늙을 대로 늙었다.  
> 병이 깃들고 쉬이 부서지는 몸이다.  
> 썩어 가는 이 덩어리는 무너진다.[^r3-01]  
> 목숨은 죽음으로 끝나기 때문이다.

[^r3-01]: 빨리어 본문은 ‘무너진다’(bhijjati)라고 하고 주석은 ‘머지않아 무너질 것이다’(na cirasseva bhijjissati)라고 풀었다. 파뜨나 제259게와 산스크리트 《우다나바르가》 1.34는 게송에서 바로 미래형을 쓴다. [파뜨나 제259게](https://ancient-buddhist-texts.net/Texts-and-Translations/Patna-Dhammapada/14-Patience.htm), [《우다나바르가》 1.34](https://ancient-buddhist-texts.net/Texts-and-Translations/Udanavarga/01-Anitya.htm)

```original
148.
‘‘Parijiṇṇamidaṃ rūpaṃ, roganīḷaṃ pabhaṅguraṃ;
Bhijjati pūtisandeho, maraṇantañhi jīvita’’nti.
```

</pali-poem>

<a id="cscd-11-03-u002-p001"></a>

뜻은 이러하다. 누이여, 그대의 몸은 나이가 들어 늙을 대로 늙었다. 몸은 온갖 병이 깃드는 곳이다. 어린 자칼도 ‘늙은 자칼’이라 부르고, 어린 갈로찌 덩굴도 ‘썩은 덩굴’이라 부른다.[^r3-02] 그처럼 그날 막 태어난 황금빛 몸도 분비물이 끊임없이 흘러나와 썩어 가고 쉬이 부서진다. 그대의 몸도 그렇게 썩어 머지않아 무너질 것임을 알아야 한다. ‘목숨은 죽음으로 끝나기 때문이다’라는 말은 모든 중생의 목숨이 죽음으로 끝난다는 뜻이다.

[^r3-02]: 주석은 어린 자칼과 어린 덩굴에도 ‘늙은’, ‘썩은’이라는 이름을 붙이는 예를 들었다. 두 예는 갓 태어난 몸에도 ‘썩을 몸’이라고 할 수 있다는 풀이로 이어진다.

```original
Tassattho – bhagini idaṃ tava sarīrasaṅkhātaṃ rūpaṃ mahallakabhāvena parijiṇṇaṃ, tañca kho sabbarogānaṃ nivāsaṭṭhānaṭṭhena roganīḷaṃ, yathā kho pana taruṇopi siṅgālo ‘‘jarasiṅgālo’’ti vuccati, taruṇāpi gaḷocīlatā ‘‘pūtilatā’’ti  vuccati, evaṃ tadahujātaṃ suvaṇṇavaṇṇampi samānaṃ niccaṃ paggharaṇaṭṭhena pūtitāya pabhaṅguraṃ, so esa pūtiko samāno tava deho bhijjati, na cirasseva bhijjissatīti veditabbo. Kiṃ kāraṇā? Maraṇantañhi jīvitaṃ yasmā sabbasattānaṃ jīvitaṃ maraṇapariyosānamevāti vuttaṃ hoti.
```

<a id="cscd-11-03-u002-p002"></a>

설법이 끝나자 장로니는 예류과를 얻었다. 이 법문은 다른 많은 사람에게도 이로웠다.

```original
Desanāvasāne sā therī sotāpattiphalaṃ pattā, mahājanassāpi sātthikā dhammadesanā ahosīti.
```

<a id="cscd-11-03-u002-e001"></a>

웃따라 장로니 이야기, 셋째.

```original
Uttarātherīvatthu tatiyaṃ.
```
