# 15-03 꼬살라 왕이 패한 이야기
원문서명: 담마빠다 주석서(Dhammapada-aṭṭhakathā) | 저자: 미확정 | 출처: 《담마빠다 주석서》 제2부, VRI CSCD 로마자 XML 12101–12133행

- **품** · 제15품 행복의 품(Sukhavaggo)
- **빨리어 표제** · Kosalarañño parājayavatthu
- **게송** · 제201게
- **요약** · 꼬살라 왕 빠세나디는 조카 아자따삿뚜에게 세 차례 패하고 음식을 끊는다. 스승께서는 이기면 원한이 생기고 지면 괴로우며, 승패를 내려놓아 마음이 고요한 이는 편히 지낸다고 가르치신다.
- **핵심어** · 꼬살라 왕, 빠세나디, 아자따삿뚜, 까시, 전쟁, 승패, 원한
- **평행문헌** · [《상윳따 니까야》 3.14 〈전쟁경 1〉](https://www.dhammatalks.org/suttas/SN/SN3_14.html)

<a id="cscd-15-03-u001"></a>
## 전쟁에 세 차례 패한 왕이 음식을 끊다

<a id="cscd-15-03-u001-e001"></a>

```original
3. Kosalarañño parājayavatthu
```

<a id="cscd-15-03-u001-p001"></a>

스승께서는 제따와나에 머무실 때 꼬살라 왕의 패배를 두고 ‘이기면 원한을 낳는다’로 시작하는 이 법문을 설하셨다.

```original
Jayaṃ  veranti imaṃ dhammadesanaṃ satthā jetavane viharanto kosalarañño parājayaṃ ārabbha kathesi.
```

<a id="cscd-15-03-u001-p002"></a>

꼬살라 왕 빠세나디는 까시의 한 마을[^r3-01]을 두고 누이의 아들 아자따삿뚜와 싸우다 세 차례 졌다고 한다.[^r3-02] 세 번째로 진 왕은 ‘입에서 젖내도 가시지 않은 아이 하나 못 이기니, 살아 무엇하랴?’ 하고 생각했다. 그는 음식을 끊고 침상에 누웠다. 그 소식이 온 도성에 퍼졌다.

[^r3-01]: 《자따까 주석》에 따르면 마하꼬살라 왕은 딸을 빔비사라 왕에게 시집보낼 때 이 마을의 수입을 딸의 목욕 비용에 쓰도록 주었다. 아자따삿뚜가 빔비사라를 죽이고 누이도 슬픔으로 세상을 떠나자 빠세나디는 아자따삿뚜에게 이 마을을 내주지 않으려 했다. [《자따까 주석》 제283화](https://epitaka.org/en/book/Ja-a-ii/283-3-va%E1%B8%8D%E1%B8%8Dhak%C4%ABs%C5%ABkaraj%C4%81takava%E1%B9%87%E1%B9%87an%C4%81-2595).
[^r3-02]: 〈전쟁경 1〉에서도 아자따삿뚜가 빠세나디를 이긴 전투 뒤에 이 게송이 나온다. 이어지는 〈전쟁경 2〉에서는 빠세나디가 아자따삿뚜를 사로잡지만 조카라는 이유로 살려 보낸다. 두 경은 판세가 뒤집히는 두 전투를 전하며, 《앙굿따라 니까야 주석》은 빠세나디가 두 번 지고 세 번째에 이겼다고 전한다. 이 편은 빠세나디의 패배를 세 차례로 전한다. [《상윳따 니까야》 3.14](https://www.dhammatalks.org/suttas/SN/SN3_14.html), [3.15](https://a-buddha-ujja.hu/sn-3.15/pli/tipitaka), [《앙굿따라 니까야 주석》 〈꼬살라경 2 풀이〉](https://epitaka.org/en/book/Mp-x/10-dutiyakosalasuttava%E1%B9%87%E1%B9%87an%C4%81-498).

```original
So kira kāsikagāmaṃ nissāya bhāgineyyena ajātasattunā saddhiṃ yujjhanto tena tayo vāre parājito tatiyavāre cintesi – ‘‘ahaṃ khīramukhampi dārakaṃ parājetuṃ nāsakkhiṃ, kiṃ me jīvitenā’’ti. So āhārūpacchedaṃ katvā mañcake nipajji. Athassa sā pavatti sakalanagaraṃ patthari.
```

<a id="cscd-15-03-u001-p003"></a>

비구들이 여래께 아뢰었다. “존자시여, 왕께서 까시의 한 마을을 두고 싸우다 세 차례 지셨다고 합니다. 이번에도 지고 돌아와 ‘입에서 젖내도 가시지 않은 아이 하나 못 이기니, 살아 무엇하랴?’ 하시며 음식을 끊고 자리에 누우셨답니다.” 그들의 말을 들으신 스승께서는 “비구들이여, 이긴 이도 원한을 사고, 진 이는 괴로이 눕는다” 하고 이 게송을 읊으셨다.

```original
Bhikkhū tathāgatassa ārocesuṃ – ‘‘bhante, rājā kira kāsikagāmakaṃ nissāya tayo vāre parājito, so idāni parājitvā āgato ‘khīramukhampi dārakaṃ parājetuṃ nāsakkhiṃ, kiṃ me jīvitenā’ti āhārūpacchedaṃ katvā mañcake nipanno’’ti. Satthā tesaṃ kathaṃ sutvā, ‘‘bhikkhave, jinantopi veraṃ pasavati, parājito pana dukkhaṃ setiyevā’’ti vatvā imaṃ gāthamāha –
```

<a id="cscd-15-03-u002"></a>
## 제201게와 승패를 내려놓은 이

<a id="cscd-15-03-u002-v001"></a>

<pali-poem>

> **제201게**  
> 이기면 원한을 낳고, 진 이는 괴로이 눕는다.  
> 마음이 고요한 이는 승패를 내려놓고 편히 눕는다.[^r3-03]

[^r3-03]: 산스크리트 《우다나바르가》에는 첫 구절이 ‘승리에서 원한이 생긴다’로 전한다. 나머지는 제201게와 같은 뜻이다. [《우다나바르가》 30.1](https://ancient-buddhist-texts.net/Texts-and-Translations/Udanavarga/30-Sukha.htm).

```original
201.
‘‘Jayaṃ veraṃ pasavati, dukkhaṃ seti parājito;
Upasanto sukhaṃ seti, hitvā jayaparājaya’’nti.
```

</pali-poem>

<a id="cscd-15-03-u002-p001"></a>

‘이기면 원한을 낳고’란 남을 이긴 이가 상대의 원한을 산다는 뜻이다. ‘진 이’는 ‘언제쯤 저 원수가 등을 돌려 달아나는 꼴을 보게 될까?’ 하며 괴로이 눕는다. 누워 있을 때나 다른 자세로 있을 때나 괴롭다는 뜻이다. ‘마음이 고요한 이’는 탐욕 같은 번뇌가 마음속에서 모두 가라앉은 사람이다. 그는 승패를 내려놓아 편히 눕는다. 어느 자세로 지내도 편안하다.

```original
Tattha jayanti paraṃ jinanto veraṃ paṭilabhati. Parājitoti parena parājito ‘‘kadā nu kho paccāmittassa piṭṭhiṃ daṭṭhuṃ sakkhissāmī’’ti dukkhaṃ seti sabbiriyāpathesu  dukkhameva viharatīti attho. Upasantoti abbhantare upasantarāgādikileso khīṇāsavo jayañca parājayañca hitvā sukhaṃ seti, sabbiriyāpathesu sukhameva viharatīti attho.
```

<a id="cscd-15-03-u002-p002"></a>

설법이 끝나자 많은 이가 예류과를 비롯한 성취를 얻었다.

```original
Desanāvasāne bahū sotāpattiphalādīni pāpuṇiṃsūti.
```

<a id="cscd-15-03-u002-e001"></a>

꼬살라 왕이 패한 이야기, 셋째.

```original
Kosalarañño parājayavatthu tatiyaṃ.
```
