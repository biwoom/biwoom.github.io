# 18-11 남의 흠을 찾던 장로 이야기
원문서명: 담마빠다 주석서(Dhammapada-aṭṭhakathā) | 저자: 미확정 | 출처: 《담마빠다 주석서》 제2부, VRI CSCD 로마자 XML 14105–14137행

- **품** · 제18품 때의 품(Malavaggo)
- **빨리어 표제** · Ujjhānasaññittheravatthu
- **게송** · 제253게
- **요약** · 한 장로가 비구들이 가사를 입는 모습을 보며 흠만 잡는다. 스승께서는 맡은 소임에 따라 잘못을 일러 주는 일은 나무랄 데가 없으며, 늘 흠잡을 궁리만 하면 번뇌가 늘어난다고 말씀하신다.
- **핵심어** · 장로, 흠, 허물, 훈계, 선정, 누, 아라한도

<a id="cscd-18-11-u001"></a>
## 비구들이 가사를 입는 모습을 흠잡는 장로

<a id="cscd-18-11-u001-e001"></a>

```original
11. Ujjhānasaññittheravatthu
```

<a id="cscd-18-11-u001-p001"></a>

스승께서는 제따와나에 머무실 때 흠을 찾기 좋아하는 한 장로를 두고 ‘남의 허물만 들여다보고’로 시작하는 이 법문을 설하셨다.

```original
Paravajjānupassissāti  imaṃ dhammadesanaṃ satthā jetavane viharanto ujjhānasaññiṃ nāma ekaṃ theraṃ ārabbha kathesi.
```

<a id="cscd-18-11-u001-p002"></a>

장로는 “저 비구는 아랫가사를 저렇게 입고 윗가사를 저렇게 걸치는군” 하며 비구들의 흠만 찾아다녔다고 한다. 비구들이 “존자시여, 아무개 장로가 이런 일을 합니다” 하고 아뢰었다. 스승께서는 “비구들이여, 맡은 소임을 다하려고 잘못을 일러 주는 이는 나무랄 데가 없다.[^r3-01] 늘 못마땅한 마음으로 남의 흠을 찾아 말하고 다니는 이에게는 선정 같은 성취가 하나도 일어나지 않는다. 누라는 번뇌[^r3-02]만 늘어난다” 하고 이 게송을 읊으셨다.

[^r3-01]: 비구가 지켜야 할 가사 예절은 율장에도 나온다. 사리뿟따는 다른 비구에게 잘못을 일러 주려면 때에 맞게, 사실대로, 부드럽게, 이롭게, 자애의 마음으로 말하라고 했다. [《율장》 비구 세키야 제1·2조](https://ancient-buddhist-texts.net/Buddhist-Texts/V6-Patimokkha-BJT/Patimokkha-07.htm), [《앙굿따라 니까야》 5.167](https://suttacentral.net/an5.167/pli/ms)
[^r3-02]: 누(漏, āsava)는 끊어야 할 번뇌를 가리킨다. 네 가지 누는 감각적 욕망, 존재에 대한 탐착, 그릇된 견해, 무명이다. [《위방가》의 네 가지 누](https://84000.org/tipitaka/read/roman_item_s.php?book=35&item=961&items=15)

```original
So kira ‘‘ayaṃ evaṃ nivāseti, evaṃ pārupatī’’ti bhikkhūnaṃ antarameva gavesanto vicarati. Bhikkhū ‘‘asuko nāma, bhante, thero evaṃ karotī’’ti satthu ārocesuṃ. Satthā, ‘‘bhikkhave, vattasīse ṭhatvā evaṃ ovadanto ananupavādo. Yo pana niccaṃ ujjhānasaññitāya paresaṃ antaraṃ pariyesamāno evaṃ vatvā vicarati, tassa jhānādīsu ekopi viseso nuppajjati, kevalaṃ āsavāyeva vaḍḍhantī’’ti vatvā imaṃ gāthamāha –
```

<a id="cscd-18-11-u002"></a>
## 제253게와 허물을 찾아다니는 마음

<a id="cscd-18-11-u002-v001"></a>

<pali-poem>

> **제253게**  
> 남의 허물만 들여다보고 늘 흠잡으려 하는 이,  
> 그에게는 누가 늘어나고, 그는 누를 끊는 길에서 멀어져 있다.[^r3-03]

[^r3-03]: 게송에서 “누를 끊는 길”로 옮긴 빨리어 āsavakkhaya는 누가 다한다는 뜻이다. 이 이야기의 주석은 이를 아라한에 이르러 누를 끊는 길로 풀이한다. 누가 늘고 누가 다하는 데서 멀다는 구절은 빠뜨나 《다르마빠다》 제268게에도 있다. [제253게와 평행 게송 대조](https://ancient-buddhist-texts.net/Buddhist-Texts/C3-Comparative-Dhammapada/CD-18-Mala.htm)

```original
253.
‘‘Paravajjānupassissa, niccaṃ ujjhānasaññino;
Āsavā tassa vaḍḍhanti, ārā so āsavakkhayā’’ti.
```

</pali-poem>

<a id="cscd-18-11-u002-p001"></a>

‘흠잡으려 하는 이’는 “아랫가사는 이렇게 입어야 하고 윗가사는 이렇게 걸쳐야 한다”며 걸핏하면 남의 흠을 찾아내는 이다. 그런 이에게는 선정 같은 성취가 자라지 않고 누만 늘어난다. 그래서 그는 누를 완전히 끊는 아라한의 길에서 멀어져 있다는 뜻이다.

```original
Tattha  ujjhānasaññinoti evaṃ nivāsetabbaṃ evaṃ pārupitabbanti paresaṃ antaragavesitāya ujjhānabahulassa puggalassa jhānādīsu ekadhammopi na vaḍḍhati, atha kho āsavāva tassa vaḍḍhanti. Teneva kāraṇena so arahattamaggasaṅkhātā āsavakkhayā ārā dūraṃ gatova hotīti.
```

<a id="cscd-18-11-u002-p002"></a>

설법이 끝나자 많은 이가 예류과를 비롯한 성취를 얻었다.

```original
Desanāvasāne bahū sotāpattiphalādīni pāpuṇiṃsūti.
```

<a id="cscd-18-11-u002-e001"></a>

흠을 찾기 좋아하는 장로 이야기, 열한째.

```original
Ujjhānasaññittheravatthu ekādasamaṃ.
```
