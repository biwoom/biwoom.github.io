# 18-07 다섯 가지 계를 두고 다툰 재가 신자들 이야기
원문서명: 담마빠다 주석서(Dhammapada-aṭṭhakathā) | 저자: 미확정 | 출처: 《담마빠다 주석서》 제2부, VRI CSCD 로마자 XML 13825–13881행

- **품** · 제18품 때의 품(Malavaggo)
- **빨리어 표제** · Pañcaupāsakavatthu
- **게송** · 제246–248게
- **요약** · 재가 신자 다섯이 저마다 자기가 지키는 계가 가장 어렵다고 다툰다. 스승께서는 어느 계든 지키기 어려우며 계를 어기는 일은 제 삶의 뿌리를 파헤치는 것과 같다고 말씀하신다.
- **핵심어** · 재가 신자, 다섯 가지 계, 살생, 거짓말, 도둑질, 그릇된 성행위, 음주, 탐욕

<a id="cscd-18-07-u001"></a>
## 어떤 계가 더 지키기 어려운가

<a id="cscd-18-07-u001-e001"></a>

```original
7. Pañcaupāsakavatthu
```

<a id="cscd-18-07-u001-p001"></a>

스승께서는 제따와나에 머무실 때 재가 신자 다섯의 일을 두고 ‘생명을 죽이고’로 시작하는 이 법문을 설하셨다.

```original
Yo pāṇanti imaṃ dhammadesanaṃ satthā jetavane viharanto pañca upāsake ārabbha kathesi.
```

<a id="cscd-18-07-u001-p002"></a>

다섯 가운데 한 사람은 생명을 죽이지 않는 계만 지켰고, 다른 이들도 나머지 계를 하나씩 지켰다. 어느 날 그들은 저마다 “내가 하는 일이 어렵고 내가 지키는 계가 어렵소” 하며 다투다가 스승을 찾아갔다. 예를 올리고 그 일을 말씀드리자 스승께서는 어느 한 계도 가벼이 여기지 않으시며 “어느 계든 지키기는 어렵다” 하고 이 게송들을 읊으셨다.

```original
Tesu hi eko pāṇātipātāveramaṇisikkhāpadameva rakkhati, itare itarāni. Te ekadivasaṃ ‘‘ahaṃ dukkaraṃ karomi, dukkaraṃ rakkhāmī’’ti vivādāpannā satthu santikaṃ gantvā vanditvā  tamatthaṃ ārocesuṃ. Satthā tesaṃ kathaṃ sutvā ekasīlampi kaniṭṭhakaṃ akatvā ‘‘sabbāneva durakkhānī’’ti vatvā imā gāthā abhāsi –
```

<a id="cscd-18-07-u002"></a>
## 제246–248게와 제 삶의 뿌리를 파헤치는 행실

<a id="cscd-18-07-u002-v001"></a>

<pali-poem>

> **제246게**  
> 생명을 죽이고 거짓말을 하며,  
> 세상에서 남이 주지 않은 것을 가져가고 남의 배우자와 관계를 맺으며,

```original
246.
‘‘Yo pāṇamatipāteti, musāvādañca bhāsati;
Loke adinnamādiyati, paradārañca gacchati.
```

</pali-poem>

<a id="cscd-18-07-u002-v002"></a>

<pali-poem>

> **제247게**  
> 곡주나 꽃·과일 따위로 빚은 술[^r3-01]을 즐겨 마시는 이는  
> 바로 이 세상에서 제 삶의 뿌리를 파헤친다.

[^r3-01]: 율장에서는 수라(surā)의 예로 곡물 가루나 밥으로 빚은 술을, 메라야(meraya)의 예로 꽃, 과일, 꿀 등으로 빚은 술을 든다. [《율장》 비구 바일제 제51조](https://suttacentral.net/pli-tv-bu-vb-pc51/pli/ms)

```original
247.
‘‘Surāmerayapānañca, yo naro anuyuñjati;
Idheva meso lokasmiṃ, mūlaṃ khaṇati attano.
```

</pali-poem>

<a id="cscd-18-07-u002-v003"></a>

<pali-poem>

> **제248게**  
> 그대여, 단속을 놓는 것이 나쁜 행실임을 알아라.[^r3-02]  
> 탐욕과 그릇된 마음에 짓눌려 오래 괴로워하지 마라.

[^r3-02]: “단속을 놓는다”는 CSCD 게송의 아산냐따(asaññatā)를 옮긴 말이다. 이 이야기의 주석은 이 자리를 아쩨따사(acetasā)로 읽는 전승도 전한다. 그 독법은 “분별할 마음이 없다”는 뜻으로 풀이한다.

```original
248.
‘‘Evaṃ bho purisa jānāhi, pāpadhammā asaññatā;
Mā taṃ lobho adhammo ca, ciraṃ dukkhāya randhayu’’nti.
```

</pali-poem>

<a id="cscd-18-07-u002-p001"></a>

‘생명을 죽인다’는 것은 직접 죽이는 일을 비롯한 여섯 방식[^r3-03] 가운데 어느 하나로라도 다른 생명의 목숨을 끊는다는 뜻이다. 여기서 ‘거짓말’은 남에게 해를 끼치는 거짓말이다. ‘남이 주지 않은 것을 가져간다’는 것은 훔치거나 그 밖의 방법으로 남의 것을 제 것으로 만든다는 말이다. ‘남의 배우자와 관계를 맺는다’는 구절을 주석은 다른 이가 보호하는 사람과 부당하게 관계를 맺는 일로 풀이한다.

[^r3-03]: 율장 주석은 직접 죽이는 일, 남에게 시키는 일, 물체를 던져 죽이는 일, 덫 같은 장치를 쓰는 일, 주문을 쓰는 일, 신통을 쓰는 일을 여섯 가지로 든다. [《율장》 주석의 분류](https://84000.org/tipitaka/atthapali/read_rm.php?A=11167&B=1)

```original
Tattha yo pāṇamatipātetīti yo sāhatthikādīsu chasu payogesu ekapayogenāpi parassa jīvitindriyaṃ upacchindati. Musāvādanti paresaṃ atthabhañjanakaṃ musāvādañca bhāsati. Loke adinnamādiyatīti imasmiṃ sattaloke theyyāvahārādīsu ekenapi avahārena parapariggahitaṃ ādiyati. Paradārañca gacchatīti parassa rakkhitagopitesu bhaṇḍesu aparajjhanto uppathacāraṃ carati.
```

<a id="cscd-18-07-u002-p002"></a>

‘술을 즐겨 마신다’는 것은 어느 부류에 들든 술을 즐겨 자주 마신다는 뜻이다. ‘제 삶의 뿌리를 파헤친다’는 것은 당장 이 세상에서 겪는 일을 말한다. 먹고사는 데 필요한 밭과 땅까지 팔거나 재산을 남김없이 써 버리며 술을 마신다. 그렇게 제 삶의 밑천을 없애고 나면 의지할 곳 없이 가난하게 떠돌게 된다.

```original
Surāmerayapānanti yassa kassaci surāya ceva merayassa ca pānaṃ. Anuyuñjatīti sevati bahulīkaroti. Mūlaṃ khaṇatīti tiṭṭhatu paraloko, so pana puggalo idha lokasmiṃyeva yena khettavatthuādinā mūlena patiṭṭhapeyya, tampi aṭṭhapetvā vā vissajjetvā vā suraṃ pivanto attano mūlaṃ khaṇati, anātho kapaṇo hutvā vicarati.
```

<a id="cscd-18-07-u002-p003"></a>

‘그대여’는 다섯 가지 계를 어기는 사람을 부르는 말이다. ‘단속을 놓는다’는 것은 몸가짐 따위를 단속하지 않는다는 뜻이다. ‘탐욕과 그릇된 마음’ 가운데 그릇된 마음은 성냄을 가리킨다. 탐욕과 성냄은 둘 다 해롭다. 이 두 가지에 짓눌려 지옥의 괴로움과 같은 고통을 오래 겪는 일이 없도록 하라는 뜻이다.

```original
Evaṃ, bhoti pañcadussīlyakammakārakaṃ puggalaṃ ālapati. Pāpadhammāti lāmakadhammā. Asaññatāti kāyasaññatādirahitā. Acetasātipi pāṭho, acittakāti attho. Lobho adhammo cāti lobho ceva doso ca. Ubhayampi hetaṃ akusalameva. Ciraṃ dukkhāya randhayunti cirakālaṃ nirayadukkhādīnaṃ atthāya  taṃ ete dhammā mā randhentu mā matthentūti attho.
```

<a id="cscd-18-07-u002-p004"></a>

설법이 끝나자 재가 신자 다섯은 예류과를 얻었다. 모인 이들도 법문에서 이로움을 얻었다.

```original
Desanāvasāne te pañca upāsakā sotāpattiphale patiṭṭhahiṃsu, sampattānampi sātthikā dhammadesanā ahosīti.
```

<a id="cscd-18-07-u002-e001"></a>

재가 신자 다섯 이야기, 일곱째.

```original
Pañcaupāsakavatthu sattamaṃ.
```
