# 18-02 가사를 입는 곳을 돌본 바라문 이야기
원문서명: 담마빠다 주석서(Dhammapada-aṭṭhakathā) | 저자: 미확정 | 출처: 《담마빠다 주석서》 제2부, VRI CSCD 로마자 XML 13541–13577행

- **품** · 제18품 때의 품(Malavaggo)
- **빨리어 표제** · Aññatarabrāhmaṇavatthu
- **게송** · 제239게
- **요약** · 바라문은 비구들이 가사를 입는 곳에서 풀이 옷에 닿고 먼지가 묻는 것을 보고 하나씩 손본다. 햇볕과 비를 피할 곳도 마련한다. 스승께서는 세공인이 불순물을 걷어 내듯 선한 일을 조금씩 하여 마음의 때를 씻어 내라고 가르치신다.
- **핵심어** · 바라문, 가사, 전각, 선한 행위, 때, 은세공

<a id="cscd-18-02-u001"></a>
## 바라문이 비구들이 가사를 입는 자리를 손보다

<a id="cscd-18-02-u001-e001"></a>

```original
2. Aññatarabrāhmaṇavatthu
```

<a id="cscd-18-02-u001-p001"></a>

스승께서는 제따와나에 머무실 때 어느 바라문을 두고 ‘지혜로운 이는 차츰차츰’으로 시작하는 이 법문을 설하셨다.

```original
Anupubbenāti  imaṃ dhammadesanaṃ satthā jetavane viharanto aññatarabrāhmaṇaṃ ārabbha kathesi.
```

<a id="cscd-18-02-u001-p002"></a>

어느 날 바라문이 아침 일찍 나갔다가 비구들이 풀밭에서 가사를 걸치는 모습을 지켜보았다고 한다. 한 비구의 가사 끝이 풀을 스치며 이슬에 젖었다. 바라문은 ‘이곳의 풀을 걷어 내야겠다’ 하고 생각했다. 이튿날 괭이를 가지고 가 땅을 고르니 타작마당처럼 평평해졌다. 그다음 날도 그곳을 찾아갔다. 비구 한 사람이 가사를 걸치다가 옷 끝이 흙바닥에 끌려 먼지가 묻는 모습이 보였다. ‘여기에는 모래를 깔아야겠구나.’ 바라문은 모래를 가져다 고루 뿌렸다.

```original
So kira ekadivasaṃ pātova nikkhamitvā bhikkhūnaṃ cīvarapārupanaṭṭhāne bhikkhū cīvaraṃ pārupante olokento aṭṭhāsi. Taṃ pana ṭhānaṃ virūḷhatiṇaṃ hoti. Athekassa bhikkhuno cīvaraṃ pārupantassa cīvarakaṇṇo tiṇesu pavaṭṭento ussāvabindūhi temi. Brāhmaṇo ‘‘imaṃ ṭhānaṃ  appaharitaṃ kātuṃ vaṭṭatī’’ti punadivase kuddālaṃ ādāya gantvā taṃ ṭhānaṃ tacchetvā khalamaṇḍalasadisaṃ akāsi. Punadivasepi taṃ ṭhānaṃ āgantvā bhikkhūsu cīvaraṃ pārupantesu ekassa  cīvarakaṇṇaṃ bhūmiyaṃ patitvā paṃsumhi pavaṭṭamānaṃ disvā ‘‘idha vālukaṃ okirituṃ vaṭṭatī’’ti cintetvā vālukaṃ āharitvā okiri.
```

<a id="cscd-18-02-u001-p003"></a>

어느 날 아침 공양을 하기 전부터 햇볕이 몹시 뜨거웠다. 바라문은 비구들이 가사를 걸치며 땀을 흘리는 것을 보았다. ‘여기 그늘을 마련해야겠구나.’ 바라문은 햇볕을 가릴 차양을 세우게 했다. 이튿날 이른 아침에는 비가 내리고 날씨가 궂었다. 바라문은 또 와서 비구들을 지켜보다 가사가 비에 젖는 것을 보았다. ‘이곳에 비를 피할 전각을 지어야겠구나.’ 그는 전각을 짓게 했다.

```original
Athekadivasaṃ purebhattaṃ caṇḍo ātapo ahosi, tadāpi bhikkhūnaṃ cīvaraṃ pārupantānaṃ gattato sede muccante disvā ‘‘idha mayā maṇḍapaṃ kāretuṃ vaṭṭatī’’ti cintetvā maṇḍapaṃ kāresi. Punadivase pātova vassaṃ vassi, vaddalikaṃ ahosi. Tadāpi brāhmaṇo bhikkhū olokentova ṭhito tintacīvarake bhikkhū disvā ‘‘ettha mayā sālaṃ kāretuṃ vaṭṭatī’’ti sālaṃ kāretvā
```

<a id="cscd-18-02-u001-p004"></a>

바라문은 ‘이제 전각을 지었으니 잔치를 열자’ 하고 붓다를 으뜸으로 모신 비구 승가를 초대했다. 비구들을 전각 안팎에 앉게 하고 공양을 올렸다. 공양이 끝나자 그는 감사의 법문을 청하려고 스승의 발우를 받아 들었다. “존자시여, 여기 서서 비구들이 가사를 입는 모습을 보았습니다. 그때마다 눈에 띈 것이 있어 이곳을 조금씩 손보았습니다.” 그는 처음부터 자초지종을 말씀드렸다. 스승께서는 그 말을 들으시고 “바라문이여, 지혜로운 이는 기회가 있을 때마다 선한 일을 조금씩 하며 마음의 때를 차츰 씻어 낸다” 하시고 이 게송을 읊으셨다.

```original
‘‘idāni sālamahaṃ karissāmī’’ti cintetvā buddhappamukhaṃ bhikkhusaṅghaṃ  nimantetvā anto ca bahi ca bhikkhū nisīdāpetvā bhattakiccāvasāne anumodanatthāya satthu pattaṃ gahetvā, ‘‘bhante, ahaṃ bhikkhūnaṃ cīvarapārupanakāle imasmiṃ ṭhāne olokento ṭhito idañcidañca disvā idañcidañca kāresi’’nti ādito paṭṭhāya sabbaṃ taṃ pavattiṃ ārocesi. Satthā tassa vacanaṃ sutvā, ‘‘brāhmaṇa, paṇḍitā nāma khaṇe khaṇe thokaṃ kusalaṃ karontā anupubbena attano akusalamalaṃ nīharantiyevā’’ti vatvā imaṃ gāthamāha –
```

<a id="cscd-18-02-u002"></a>
## 제239게와 때를 조금씩 씻어 내는 일

<a id="cscd-18-02-u002-v001"></a>

<pali-poem>

> **제239게**  
> 지혜로운 이는 차츰차츰, 기회가 있을 때마다 조금씩,  
> 세공인이 은에서 불순물을 걷어 내듯 마음의 때를 씻어 내야 한다.[^r3-01]

[^r3-01]: 빠뜨나 《다르마빠다》 제163게와 《우다나바르가》 2.10에도 은에서 불순물을 걷어 내듯 자기의 때를 조금씩 없애라는 같은 비유가 나온다. [빠뜨나 《다르마빠다》와 《우다나바르가》 원문 대조](https://ancient-buddhist-texts.net/Buddhist-Texts/C3-Comparative-Dhammapada/CD-18-Mala.htm).

```original
239.
‘‘Anupubbena medhāvī, thokaṃ thokaṃ khaṇe khaṇe;
Kammāro rajatasseva, niddhame malamattano’’ti.
```

</pali-poem>

<a id="cscd-18-02-u002-p001"></a>

‘차츰차츰’은 순서대로 한다는 뜻이다. ‘지혜로운 이’는 가르침의 핵심을 아는 이다. 그런 이는 기회가 올 때마다 선한 일을 한다. 금세공인[^r3-02]이 금을 한 번 달구고 두드리는 것으로는 불순물을 걷어 내고 장신구를 만들 수 없다. 여러 번 달구고 두드려 불순물을 걷어 내고 나서야 갖가지 장신구를 만든다. 이처럼 지혜로운 이도 선한 일을 거듭하여 탐욕과 같은 마음의 때를 씻어 내야 한다. 그렇게 때를 씻어 내면 번뇌에서 벗어난다는 뜻이다.

[^r3-02]: 게송은 은(rajata)에서 불순물을 걷어 내는 장면을, 주석은 금(suvaṇṇa)을 여러 번 달구고 두드리는 장면을 든다. 두 장면 모두 조금씩 거듭하여 때를 없애는 과정을 보여 준다. 《앙굿따라 니까야》 3.101에도 금에서 불순물을 단계마다 걷어 내는 일을 마음을 닦는 과정에 비긴다. [《담마빠다 주석》 빨리어](https://epitaka.org/hi/book/Dhp-a/2.-a%C3%B1%C3%B1atarabr%C4%81hma%E1%B9%87avatthu-3384) · [《앙굿따라 니까야》 3.101](https://epitaka.org/lo/book/A-iii/10-pa%E1%B9%83sudhovakasutta%E1%B9%83-1010).

```original
Tattha anupubbenāti anupaṭipāṭiyā. Medhāvīti dhammojapaññāya samannāgato. Khaṇe khaṇeti okāse okāse kusalaṃ karonto. Kammāro rajatassevāti yathā suvaṇṇakāro ekavārameva suvaṇṇaṃ tāpetvā koṭṭetvā malaṃ nīharitvā pilandhanavikatiṃ kātuṃ na sakkoti, punappunaṃ tāpento koṭṭento pana malaṃ nīharati, tato anekavidhaṃ pilandhanavikatiṃ karoti, evameva punappunaṃ kusalaṃ karonto paṇḍito attano rāgādimalaṃ niddhameyya, evaṃ niddhantamalo nikkilesova hotīti attho.
```

<a id="cscd-18-02-u002-p002"></a>

설법이 끝나자 바라문은 예류과를 얻었다. 모인 사람들도 법문에서 이로움을 얻었다.

```original
Desanāvasāne  brāhmaṇo sotāpattiphale patiṭṭhati, mahājanassāpi sātthikā dhammadesanā ahosīti.
```

어느 바라문 이야기, 둘째.

```original

```
