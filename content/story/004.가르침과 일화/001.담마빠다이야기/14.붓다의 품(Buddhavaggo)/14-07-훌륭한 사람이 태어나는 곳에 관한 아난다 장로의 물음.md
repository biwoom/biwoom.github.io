# 14-07 훌륭한 사람이 태어나는 곳에 관한 아난다 장로의 물음
원문서명: 담마빠다 주석서(Dhammapada-aṭṭhakathā) | 저자: 미확정 | 출처: 《담마빠다 주석서》 제2부, VRI CSCD 로마자 XML 11849–11881행

- **품** · 제14품 붓다의 품(Buddhavaggo)
- **빨리어 표제** · Ānandattherapañhavatthu
- **게송** · 제193게
- **요약** · 아난다는 훌륭한 코끼리와 말과 황소가 어디서 나는지 들은 일을 떠올리며, 훌륭한 사람은 어디에서 태어나는지 묻는다. 스승께서는 정등각자가 태어나는 곳과 그가 태어난 집안이 누리는 행복을 말씀하신다.
- **핵심어** · 아난다, 훌륭한 사람, 정등각자, 중부 지역

<a id="cscd-14-07-u001"></a>
## 아난다가 훌륭한 사람이 태어나는 곳을 묻다

<a id="cscd-14-07-u001-e001"></a>

```original
7. Ānandattherapañhavatthu
```

<a id="cscd-14-07-u001-p001"></a>

스승께서는 제따와나에 머무실 때 아난다 장로의 물음을 두고 ‘만나기 어렵다’로 시작하는 이 법문을 설하셨다.

```original
Dullabhoti  imaṃ dhammadesanaṃ satthā jetavane viharanto ānandattherassa pañhaṃ ārabbha kathesi.
```

<a id="cscd-14-07-u001-p002"></a>

어느 날 장로는 낮을 보내는 거처에 앉아 생각했다. ‘훌륭한 코끼리는 찻단따나 우뽀사타 혈통에서 나고, 훌륭한 말은 신다바나 말들의 왕 왈라하까의 혈통[^r3-01]에서 나며, 훌륭한 황소는 남쪽 지방에서 난다고 스승께서 말씀하셨다. 그렇게 훌륭한 코끼리와 말과 황소가 어디서 나는지는 들었는데, 훌륭한 사람은 어디에서 태어날까?’ 그는 스승께 다가가 예를 올리고 한쪽에 앉아 이 일을 여쭈었다.

[^r3-01]: 〈보배경〉의 주석은 찻단따나 우뽀사타 혈통의 코끼리와 왈라하까 혈통의 말을 전륜왕에게 나타나는 보배로도 설명한다. [《숫따니빠따 주석》 〈보배경 풀이〉](https://epitaka.org/en/book/Pj-ii/1-ratanasuttava%E1%B9%87%E1%B9%87an%C4%81-1002).

```original
Thero hi ekadivasaṃ divāṭṭhāne nisinno cintesi – ‘‘hatthājānīyo  chaddantakule vā uposathakule vā uppajjati, assājānīyo sindhavakule vā valāhakassarājakule vā, usabho goājanīyo dakkhiṇapathetiādīni vadantena satthārā hatthiājānīyādīnaṃ uppattiṭṭhānādīni kathitāni, purisājānīyo pana kahaṃ nu kho uppajjatī’’ti. So satthāraṃ upasaṅkamitvā vanditvā ekamantaṃ nisīditvā etamatthaṃ pucchi.
```

<a id="cscd-14-07-u001-p003"></a>

스승께서는 말씀하셨다. “아난다여, 훌륭한 사람은 아무 데서나 태어나지 않는다. 직선으로 잰 길이가 삼백 요자나, 너비가 이백오십 요자나, 둘레가 구백 요자나인 중부 지역[^r3-02]에서 태어난다. 그곳에서도 왕족이나 바라문의 부유한 집안[^r3-03]에서 태어난다.” 그러고 나서 이 게송을 읊으셨다.

[^r3-02]: 중부 지역은 옛 인도에서 불교 문헌이 변방과 구별하는 지역이다. 율장은 동쪽의 까장갈라 마을, 서쪽의 투나 마을 등 경계에 놓인 지명을 든다. 태국판 《담마빠다 주석서》는 이곳의 길이와 둘레를 전하고 너비 수치는 싣지 않는다. [《율장》 〈가죽의 장〉 제13절](https://www.dhammatalks.org/vinaya/Mv/MvV.html), [태국판 《담마빠다 주석서》](https://84000.org/tipitaka/atthapali/read_rm.php?A=1200&B=23).
[^r3-03]: 〈대본경〉에서는 위빳시·시키·웻사부와 고따마가 왕족 집안에서, 까꾸산다·꼬나가마나·깟사빠가 바라문 집안에서 태어났다고 전한다. [《디가 니까야》 14 〈대본경〉](https://dhammatalks.net/suttacentral/sc2016/sc/pi/dn14.html).

```original
Satthā, ‘‘ānanda, purisājānīyo nāma sabbattha nuppajjati, ujukato pana tiyojanasatāyāme vitthārato aḍḍhateyyasate āvaṭṭato navayojanasatappamāṇe majjhimapadesaṭṭhāne uppajjati. Uppajjanto ca pana na yasmiṃ vā tasmiṃ vā kule uppajjati, khattiyamahāsālabrāhmaṇamahāsālakulānaṃ pana aññatarasmiṃyeva uppajjatī’’ti vatvā imaṃ gāthamāha –
```

<a id="cscd-14-07-u002"></a>
## 제193게와 현자가 태어난 집안

<a id="cscd-14-07-u002-v001"></a>

<pali-poem>

> **제193게**  
> 훌륭한 사람은 만나기 어렵다. 아무 데서나 태어나지 않는다.  
> 그 현자가 태어나는 집안은 행복을 누린다.[^r3-04]

[^r3-04]: 산스크리트 《우다나바르가》에서는 ‘현자’ 자리에 ‘용맹한 이’(vīra)가 나온다. [《우다나바르가》 30.27](https://ancient-buddhist-texts.net/Texts-and-Translations/Udanavarga/30-Sukha.htm).

```original
193.
‘‘Dullabho purisājañño, na so sabbattha jāyati;
Yattha so jāyatī dhīro, taṃ kulaṃ sukhamedhatī’’ti.
```

</pali-poem>

<a id="cscd-14-07-u002-p001"></a>

‘만나기 어렵다’란 훌륭한 사람은 훌륭한 코끼리 같은 동물보다 만나기 어렵다는 말이다. 그는 변방이나 신분이 낮은 집안에서 태어나지 않는다. 중부 지역에서도 많은 사람이 예를 올리고 공경하는 곳에서 왕족이나 바라문의 집안에 태어난다. 그렇게 태어나는 현자는 지혜가 으뜸인 정등각자다.[^r3-05] ‘행복을 누린다’는 그가 태어나는 집안이 행복하게 된다는 뜻이다.

[^r3-05]: 코끼리·말·황소와 사람에 붙인 ‘훌륭한’은 같은 빨리어 낱말(ājānīya, 게송에서는 ājañña)이다. 이야기에서는 동물의 뛰어남에서 사람의 뛰어남으로 물음이 이어진다. 주석은 게송의 ‘훌륭한 사람’을 지혜가 으뜸인 정등각자로 풀이한다.

```original
Tattha dullabhoti purisājañño hi dullabho, na hatthiājānīyādayo viya sulabho, so sabbattha paccantadese vā nīcakule vā na jāyati, majjhimadesepi mahājanassa abhivādanādisakkārakaraṇaṭṭhāne khattiyabrāhmaṇakulānaṃ aññatarasmiṃ kule jāyati. Evaṃ jāyamāno yattha so jāyati dhīro uttamapañño sammāsambuddho, taṃ kulaṃ sukhamedhatīti sukhappattameva hotīti attho.
```

<a id="cscd-14-07-u002-p002"></a>

설법이 끝나자 많은 이가 예류과를 비롯한 성취를 얻었다.

```original
Desanāvasāne bahū sotāpattiphalādīni pāpuṇiṃsūti.
```

<a id="cscd-14-07-u002-e001"></a>

아난다 장로의 물음 이야기, 일곱째.

```original
Ānandattherapañhavatthu sattamaṃ.
```
