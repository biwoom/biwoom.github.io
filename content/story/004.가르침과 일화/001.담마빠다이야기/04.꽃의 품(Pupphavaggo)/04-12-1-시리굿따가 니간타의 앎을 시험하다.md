# 04-12-1 시리굿따가 니간타의 앎을 시험하다
원문서명: 담마빠다 주석서(Dhammapada-aṭṭhakathā) | 저자: 미확정 | 출처: 《담마빠다 주석서》 제1부, VRI CSCD 로마자 XML 4993–5089행

- **품** · 제4품 꽃의 품(Pupphavaggo)
- **빨리어 표제** · Garahadinnavatthu
- **게송** · 《담마빠다》 제58·59게
- **전체 이야기 요약** · 시리굿따는 니간타들의 앎을 시험하고, 가라하딘나는 보복하려고 붓다와 비구들을 초대한다. 숯불 구덩이에서 연꽃이 피어나고, 붓다께서는 쓰레기 더미에서 피어난 연꽃에 지혜로운 제자를 비유하신다. 두 벗은 예류과를 얻는다.
- **전체 이야기 핵심어** · 시리굿따, 가라하딘나, 니간타, 숯불 구덩이, 연꽃, 지혜의 눈, 예류과
- **평행문헌** · 제58·59게에 대응하는 구절은 파트나 《다르마파다》 135–136, 간다라 《다르마파다》 303–304, 《우다나바르가》 18.12–13에 있다. <a id="cscd-04-12-u001"></a>
## 두 벗과 니간타들의 초대

<a id="cscd-04-12-u001-e001"></a>

```original
12. Garahadinnavatthu
```

<a id="cscd-04-12-u001-p001"></a>

스승께서 제따와나에 머무실 때 니간타[^r3-01]의 제자 가라하딘나를 두고 “큰길에 내버린 쓰레기 더미에서도”로 시작하는 이 법을 설하셨다.

[^r3-01]: 니간타는 당시 인도의 자이나교 수행자들을 가리키는 명칭이다.

```original
Yathā saṅkāraṭṭhānasminti imaṃ dhammadesanaṃ satthā jetavane viharanto garahadinnaṃ nāma nigaṇṭhasāvakaṃ ārabbha kathesi.
```

<a id="cscd-04-12-u001-p002"></a>

사왓티에는 시리굿따와 가라하딘나라는 두 벗이 있었다. 시리굿따는 붓다의 제자인 우바새였고 가라하딘나는 니간타의 제자였다. 니간타들은 가라하딘나에게 자주 말했다.

```original
Sāvatthiyañhi sirigutto ca garahadinno cāti dve sahāyakā ahesuṃ. Tesu sirigutto upāsako buddhasāvako, garahadinno nigaṇṭhasāvako. Taṃ nigaṇṭhā abhikkhaṇaṃ evaṃ vadanti –
```

<a id="cscd-04-12-u001-p003"></a>

“그대 벗 시리굿따에게 ‘왜 사문 고따마를 찾아가는가? 거기서 무엇을 얻겠는가?’ 하고 말해 보게. 그에게 우리를 찾아와 우리에게도 보시하라고 권하는 게 어떻겠나?”

```original
‘‘tava sahāyakaṃ siriguttaṃ ‘kiṃ tvaṃ samaṇaṃ gotamaṃ upasaṅkamasi, tassa santike kiṃ labhissasī’ti vatvā yathā amhe upasaṅkamitvā amhākañca deyyadhammaṃ dassati, kiṃ evaṃ ovadituṃ na vaṭṭatī’’ti.
```

<a id="cscd-04-12-u001-p004"></a>

그 말을 들은 가라하딘나는 시리굿따를 볼 때마다 이렇게 권했다. “벗이여, 사문 고따마가 자네에게 무슨 소용인가? 그를 찾아가 무엇을 얻겠는가? 내 스승님들을 찾아가 보시하는 것이 좋지 않겠는가?”

```original
Garahadinno tesaṃ vacanaṃ sutvā abhikkhaṇaṃ gantvā ṭhitanisinnaṭṭhānādīsu siriguttaṃ evaṃ ovadati – ‘‘samma, kiṃ te samaṇena gotamena, taṃ upasaṅkamitvā kiṃ labhissasi, kiṃ te mama, ayye, upasaṅkamitvā tesaṃ dānaṃ dātuṃ na vaṭṭatī’’ti?
```

<a id="cscd-04-12-u001-p005"></a>

시리굿따는 여러 날 그 말을 듣고도 잠자코 있다가, 마침내 싫증이 나 어느 날 입을 열었다. “벗이여, 자네는 걸핏하면 내가 있는 곳으로 찾아와 ‘사문 고따마를 찾아가 무엇을 얻겠는가? 내 스승님들을 찾아가 보시하게’라고 말하네. 그럼 자네 스승님들은 무엇을 아시는지 말해 보게.”

```original
Sirigutto tassa kathaṃ sutvāpi bahū divase tuṇhī hutvā nibbijjitvā ekadivasaṃ, ‘‘samma, tvaṃ abhikkhaṇaṃ āgantvā maṃ ṭhitaṭṭhānādīsu evaṃ vadesi, ‘samaṇaṃ gotamaṃ upasaṅkamitvā kiṃ labhissasi, mama, ayye, upasaṅkamitvā tesaṃ dānaṃ dehī’ti, kathehi tāva me, tava, ayyā, kiṃ jānantī’’ti?
```

<a id="cscd-04-12-u001-p006"></a>

“아, 벗이여. 그런 말 말게. 내 스승님들이 모르시는 것은 없네. 과거와 미래와 현재의 모든 일, 몸과 말과 마음으로 짓는 모든 업, 무엇이 일어나고 무엇이 일어나지 않을지, 어떤 일이 가능하고 어떤 일이 불가능한지 모두 아시네.”

```original
‘‘‘Aho, sāmi, mā evaṃ vada, mama ayyānaṃ aññātaṃ nāma natthi, sabbaṃ atītānāgatapaccuppannaṃ sabbaṃ kāyavacīmanokammaṃ idaṃ bhavissati, idaṃ na bhavissatī’ti sabbaṃ bhabbābhabbaṃ jānantī’’ti?
```

<a id="cscd-04-12-u001-p007"></a>

“정말 그렇게 말하는가?”

```original
‘‘Evaṃ vadesī’’ti.
```

<a id="cscd-04-12-u001-p008"></a>

“그렇네.”

```original
‘‘Āma, vademī’’ti.
```

<a id="cscd-04-12-u001-p009"></a>

“그렇다면 그런 걸 여태 내게 알려 주지 않다니, 자네가 크게 잘못했네. 오늘에야 그분들의 앎이 얼마나 대단한지 알았네. 가서 내 말이라고 하고 그분들을 초대해 주게.”

```original
‘‘Yadi evaṃ, atibhāriyaṃ te kataṃ, ettakaṃ kālaṃ mayhaṃ etamatthaṃ anācikkhantena, ajja mayā ayyānaṃ ñāṇānubhāvo ñāto, gaccha, samma, ayye, mama vacanena nimantehī’’ti.
```

<a id="cscd-04-12-u001-p010"></a>

가라하딘나는 니간타들을 찾아가 예를 올리고 말했다. “제 벗 시리굿따가 스승님들을 내일 초대합니다.”

```original
So nigaṇṭhānaṃ santikaṃ gantvā te vanditvā ‘‘mayhaṃ sahāyako sirigutto svātanāya tumhe nimantetī’’ti āha.
```

<a id="cscd-04-12-u001-p011"></a>

“시리굿따가 자네에게 직접 그렇게 말했나?”

```original
‘‘Siriguttena sāmaṃ tvaṃ vutto’’ti?
```

<a id="cscd-04-12-u001-p012"></a>

“그렇습니다, 스승님들.”

```original
‘‘Āma, ayyā’’ti.
```

<a id="cscd-04-12-u001-p013"></a>

그들은 기뻐하며 말했다. “이제 일이 다 풀렸군. 시리굿따가 우리를 믿게 되면 우리가 누리지 못할 것이 어디 있겠나?”

```original
Te haṭṭhatuṭṭhā hutvā ‘‘nipphannaṃ no kiccaṃ, siriguttassa amhesu pasannakālato paṭṭhāya kā nāma sampatti amhākaṃ na bhavissatī’’ti vadiṃsu.
```

<a id="cscd-04-12-u002"></a>
## 시리굿따의 시험과 니간타들의 수난

<a id="cscd-04-12-u002-p001"></a>

시리굿따에게도 큰 저택이 있었다. 그는 저택의 두 건물 사이에 길쭉한 구덩이를 파게 하고 똥이 섞인 진흙으로 채우게 했다. 구덩이 양 끝 바깥에 말뚝을 박아 밧줄을 매게 했다. 걸상의 앞다리는 구덩이 앞쪽에, 뒷다리는 밧줄 위에 올려놓게 했다. ‘이렇게 앉으면 거꾸로 떨어지겠지.’ 그는 구덩이가 보이지 않도록 걸상마다 덮개를 씌우게 했다. 큰 항아리를 여러 개 가져오게 해 아가리를 바나나 잎과 흰 천으로 덮고 묶었다. 항아리 속은 비워 둔 채 겉에 죽, 밥알, 정제 버터, 기름, 꿀, 당밀, 과자 부스러기를 묻혀 집 뒤쪽에 놓게 했다.

```original
Siriguttassāpi mahantaṃ nivesanaṃ. So tasmiṃ dvinnaṃ gehānaṃ antare ubhato dīghaṃ āvāṭaṃ khaṇāpetvā gūthakalalassa pūrāpesi. Bahiāvāṭe dvīsu pariyantesu khāṇuke koṭṭāpetvā tesu rajjuyo bandhāpetvā āsanānaṃ purimapāde āvāṭassa purimapasse ṭhapāpetvā pacchimapāde rajjukesu ṭhapāpesi. ‘‘Evaṃ nisinnakāle evaṃ avaṃsirā patissantī’’ti maññamāno yathā āvāṭo na paññāyati, evaṃ āsanānaṃ upari paccattharaṇāni dāpesi. Mahantā mahantā cāṭiyo ṭhapāpetvā kadalipaṇṇehi ca setapilotikāhi ca mukhāni bandhāpetvā tā tucchā eva gehassa pacchimabhāge bahi yāgubhattasitthasappitelamadhuphāṇitapūvacuṇṇamakkhitā katvā ṭhapāpesi.
```

<a id="cscd-04-12-u002-p002"></a>

가라하딘나는 아침 일찍 그 집에 달려와 물었다. “스승님들을 대접할 준비는 했나?”

```original
Garahadinno pātova tassa gharaṃ vegena gantvā, ‘‘ayyānaṃ sakkāro sajjito’’ti pucchi.
```

<a id="cscd-04-12-u002-p003"></a>

“그렇네, 벗이여.”

```original
‘‘Āma, samma, sajjito’’ti.
```

<a id="cscd-04-12-u002-p004"></a>

“어디에 있나?”

```original
‘‘Kahaṃ pana eso’’ti.
```

<a id="cscd-04-12-u002-p005"></a>

“여기 있는 항아리에는 죽을, 저쪽 것에는 밥을, 그 옆에는 정제 버터며 당밀이며 과자를 채웠네. 자리도 마련했네.”

```original
‘‘Etāsu ettikāsu cāṭīsu yāgu, ettikāsu bhattaṃ, ettikāsu sappiphāṇitapūvādīni pūritāni, āsanāni paññattānī’’ti.
```

<a id="cscd-04-12-u002-p006"></a>

가라하딘나가 “좋네” 하고 떠나자 니간타 오백 명이 왔다. 시리굿따는 집에서 나와 오체투지[^r3-02]로 절했다. 그들 앞에 서서 합장한 채 생각했다.

[^r3-02]: 두 무릎과 두 팔꿈치, 이마를 땅에 대는 절이다.

```original
So ‘‘sādhū’’ti vatvā gato tassa gatakāle pañcasatā nigaṇṭhā āgamiṃsu. Sirigutto gehā nikkhamitvā pañcapatiṭṭhitena nigaṇṭhe vanditvā tesaṃ purato añjaliṃ paggayha ṭhito evaṃ cintesi –
```

<a id="cscd-04-12-u002-p007"></a>

‘여러분은 과거와 미래와 현재를 다 아신다고 후원자가 내게 말했습니다. 정말 다 아신다면 제 집에 들어오지 마십시오. 들어오셔도 죽이며 밥이며 아무것도 없습니다. 모르고 들어오시면 똥 구덩이에 빠뜨리고 때리겠습니다.’

```original
‘‘tumhe kira atītādibhedaṃ sabbaṃ jānātha, evaṃ tumhākaṃ upaṭṭhākena mayhaṃ kathitaṃ. Sace sabbaṃ tumhe jānātha, mayhaṃ gehaṃ mā pavisittha. Mama gehaṃ paviṭṭhānañhi vo neva yāgu atthi, na bhattādīni. Sace ajānitvā pavisissatha, gūthaāvāṭe vo pātetvā pothessāmī’’ti
```

<a id="cscd-04-12-u002-p008"></a>

그렇게 생각한 그는 사람들에게 신호했다. “걸상 뒤에 서 있다가 그들이 앉거든 덮개를 걷게. 덮개에 오물이 묻지 않게 하려는 걸세.”

```original
evaṃ cintetvā purisānaṃ saññaṃ adāsi. Evaṃ tesaṃ nisīdanabhāvaṃ ñatvā pacchimapasse ṭhatvā āsanānaṃ upari paccattharaṇāni apaneyyātha, mā tāni asucinā makkhayiṃsūti.
```

<a id="cscd-04-12-u002-p009"></a>

그런 다음 니간타들에게 “스승님들, 이리 오십시오”라고 했다. 니간타들이 들어와 마련된 자리에 앉으려 하자 사람들이 말했다.

```original
Atha nigaṇṭhe ‘‘ito etha, bhante’’ti āha. Nigaṇṭhā pavisitvā paññattāsanesu nisīdituṃ ārabhiṃsu. Atha ne manussā vadiṃsu –
```

<a id="cscd-04-12-u002-p010"></a>

“잠시 기다려 주십시오, 스승님들. 아직 앉지 마십시오.”

```original
‘‘āgametha, bhante, mā tāva nisīdathā’’ti.
```

<a id="cscd-04-12-u002-p011"></a>

“무슨 까닭인가?”

```original
‘‘Kiṃ kāraṇā’’ti?
```

<a id="cscd-04-12-u002-p012"></a>

“이 집에 오셨으니 저희 집의 예법에 따라 앉으셔야 합니다.”

```original
‘‘Amhākaṃ gehaṃ paviṭṭhānaṃ ayyānaṃ vattaṃ ñatvā nisīdituṃ vaṭṭatī’’ti.
```

<a id="cscd-04-12-u002-p013"></a>

“어떻게 해야 하는가, 벗들이여?”

```original
‘‘Kiṃ kātuṃ vaṭṭati, āvuso’’ti?
```

<a id="cscd-04-12-u002-p014"></a>

“각자 자기 자리 앞에 서서 모두 한꺼번에 앉으셔야 합니다.”

```original
‘‘Attano attano pattāsanamūlesu ṭhatvā sabbepi ekappahāreneva nisīdituṃ vaṭṭatī’’ti.
```

<a id="cscd-04-12-u002-p015"></a>

시리굿따의 속셈은 이러했다. ‘한 사람이 먼저 빠져서 다른 사람들에게 앉지 말라고 외칠 틈을 주면 안 되지.’ 니간타들은 “좋소” 하고는 ‘이 사람들이 말하는 대로 해야겠다’고 생각했다. 모두 차례로 자기 자리 앞에 섰다. 사람들은 “스승님들, 어서 한꺼번에 앉으십시오” 하고는 니간타들이 앉자 덮개를 걷었다. 그들이 한꺼번에 앉으니 걸상 뒷다리가 밧줄에서 미끄러져 니간타들은 머리부터 구덩이에 떨어졌다.

```original
Idaṃ kirassa adhippāyo – ‘‘ekasmiṃ āvāṭe patite ‘mā, āvuso, avasesā āsane nisīdantū’ti vattuṃ mā labhatū’’ti. Te ‘‘sādhū’’ti vatvā ‘‘imehi kathitakathaṃ amhehi kātuṃ vaṭṭatī’’ti cintayiṃsu. Atha sabbe attano attano pattāsanamūle paṭipāṭiyā aṭṭhaṃsu. Atha ne, ‘‘bhante, khippaṃ ekappahāreneva nisīdathā’’ti vatvā tesaṃ nisinnabhāvaṃ ñatvā āsanānaṃ upari paccattharaṇāni nīhariṃsu. Nigaṇṭhā ekappahāreneva nisinnā, rajjūnaṃ upari ṭhapitā āsanapādā bhaṭṭhā, nigaṇṭhā avaṃsirā āvāṭe patiṃsu.
```

<a id="cscd-04-12-u002-p016"></a>

시리굿따는 그들이 떨어지자 문을 닫았다. 한 사람씩 올라올 때마다 “과거와 미래와 현재를 어째서 몰랐는가?” 하고 몽둥이로 때렸다. 그는 “이 정도면 됐다” 하고 문을 열게 했다. 니간타들은 밖으로 달아났다. 그런데 시리굿따는 그들이 지나갈 길의 회칠한 바닥을 미끄럽게 해 놓았다. 그들이 발을 헛디뎌 넘어질 때마다 다시 때리게 하고 “이만하면 됐다” 하며 내보냈다. 그들은 “네가 우리를 망쳤다! 네가 우리를 망쳤다!” 하고 울부짖으며 후원자의 집 문 앞에 이르렀다.

```original
Sirigutto tesu patitesu dvāraṃ pidahitvā te uttiṇṇuttiṇṇe ‘‘atītānāgatapaccuppannaṃ kasmā na jānāthā’’ti daṇḍehi pāthetvā ‘‘ettakaṃ etesaṃ vaṭṭissatī’’ti dvāraṃ vivarāpesi. Te nikkhamitvā palāyituṃ ārabhiṃsu. Gamanamagge pana tesaṃ sudhāparikammakataṃ bhūmiṃ picchilaṃ kārāpesi. Te tattha asaṇṭhahitvā patite patite puna pothāpetvā ‘‘alaṃ ettakaṃ tumhāka’’nti uyyojesi. Te ‘‘nāsitamhā tayā, nāsitamhā tayā’’ti kandantā upaṭṭhākassa gehadvāraṃ agamaṃsu.
```

<a id="cscd-04-12-u003"></a>
## 왕의 심문과 벌금

<a id="cscd-04-12-u003-p001"></a>

가라하딘나는 그 참상을 보고 화가 났다. ‘시리굿따가 나를 망쳤다. 내 스승님들은 손을 모아 예를 올리는 이들에게 하늘과 세상에서 바라는 것을 주실 만큼 훌륭한 공덕밭[^r3-03]이다. 그런데 시리굿따가 그분들을 매질해 이 지경에 이르게 했다.’ 그는 왕궁에 가서 시리굿따에게 벌금으로 까하빠나 천 닢을 물리게 했다.

[^r3-03]: 보시가 좋은 결실을 맺도록 하는 대상을 밭에 비유한 말이다.

```original
Garahadinno taṃ vippakāraṃ disvā kuddho ‘‘nāsitamhi siriguttena, hatthaṃ pasāretvā vandantānaṃ sadevake loke yathāruciyā dātuṃ samatthe nāma puññakkhettabhūte mama, ayye, pothāpetvā byasanaṃ pāpesī’’ti rājakulaṃ gantvā tassa kahāpaṇasahassaṃ daṇḍaṃ kāresi.
```

<a id="cscd-04-12-u003-p002"></a>

왕이 시리굿따에게 전갈을 보냈다. 시리굿따는 가서 왕에게 예를 올리고 말했다. “대왕이시여, 사정을 살피신 뒤에 벌금을 거두십시오. 살피지 않고 거두지는 마십시오.”

```original
Athassa rājā sāsanaṃ pesesi. So gantvā rājānaṃ vanditvā, ‘‘deva, upaparikkhitvā daṇḍaṃ gaṇhatha, mā anupaparikkhitvā’’ti āha.
```

<a id="cscd-04-12-u003-p003"></a>

“살펴보고 거두겠다.”

```original
‘‘Upaparikkhitvā gaṇhissāmī’’ti.
```

<a id="cscd-04-12-u003-p004"></a>

“좋습니다, 대왕이시여.”

```original
‘‘Sādhu, devā’’ti.
```

<a id="cscd-04-12-u003-p005"></a>

시리굿따가 “그렇다면 거두십시오”라고 하자, 왕이 “그럼 경위를 말해 보아라[^r3-04]”라고 했다.

[^r3-04]: 벌금을 거둔다는 말은 시리굿따의 응답이다. 태국 빨리어판에는 그 뒤에 경위를 말하라는 왕의 대사가 따로 이어진다. [태국 빨리어판 93쪽](https://84000.org/tipitaka/atthapali/read_rm.php?A=500&B=20&modeTY=2&pagebreak=1)

```original
‘‘Tena hi gaṇhāhī’’ti.
```

<a id="cscd-04-12-u003-p006"></a>

시리굿따는 “대왕이시여, 제 벗은 니간타의 제자입니다. 저를 볼 때마다 ‘벗이여, 사문 고따마가 자네에게 무슨 소용인가? 찾아가서 무엇을 얻겠는가?’ 하고 말했습니다”라는 말로 시작하여 일의 전말을 아뢰고 말했다. “대왕이시여, 이 일에 벌금을 매기는 것이 마땅하다면 거두십시오.”

```original
Deva, mayhaṃ sahāyako nigaṇṭhasāvako maṃ upasaṅkamitvā ṭhitanisinnaṭṭhānādīsu abhiṇhaṃ evaṃ vadesi – ‘‘samma, kiṃ te samaṇena gotamena, taṃ upasaṅkamitvā kiṃ labhissasī’’ti idaṃ ādiṃ katvā sirigutto sabbaṃ taṃ pavattiṃ ārocetvā ‘‘deva, sace imasmiṃ kāraṇe daṇḍaṃ gahetuṃ yuttaṃ, gaṇhathā’’ti.
```

<a id="cscd-04-12-u003-p007"></a>

왕은 가라하딘나를 보며 물었다. “그대가 그렇게 말한 것이 사실인가?”

```original
Rājā garahadinnaṃ oloketvā ‘‘saccaṃ kira te evaṃ vutta’’nti āha.
```

<a id="cscd-04-12-u003-p008"></a>

“사실입니다, 대왕이시여.”

```original
‘‘Saccaṃ, devā’’ti.
```

<a id="cscd-04-12-u003-p009"></a>

“이 정도도 모르는 자들을 스승으로 받들며 어찌 여래의 제자에게 그들이 모든 것을 안다고 말하였느냐? 그대가 청한 벌금은 그대가 내도록 하라.”

```original
Tvaṃ ettakampi ajānante satthāroti gahetvā vicaranto ‘‘sabbaṃ jānantī’’ti kiṃ kāraṇā tathāgatasāvakassa kathesi. ‘‘Tayā āropitadaṇḍo tuyhameva hotū’’ti
```

<a id="cscd-04-12-u003-p010"></a>

그리하여 벌금은 가라하딘나 자신에게 돌아갔고, 매를 맞고 쫓겨난 이들도 그의 집을 드나들던 수행자들이었다.


```original
evaṃ sveva daṇḍaṃ pāpito, tasseva kulūpakā pothetvā nīhaṭā.
```
