# 06-11 찾아온 비구 오백 명 이야기
원문서명: 담마빠다 주석서(Dhammapada-aṭṭhakathā) | 저자: 미확정 | 출처: 《담마빠다 주석서》 제1부, VRI CSCD 로마자 XML 6833–6901행

- **품** · 제6품 지혜로운 이의 품(Paṇḍitavaggo)
- **빨리어 표제** · Pañcasataāgantukabhikkhuvatthu
- **게송** · 제87–89게
- **요약** · 꼬살라에서 안거를 마친 비구 오백 명이 스승을 찾아온다. 스승께서는 그릇된 행실을 버리고 바른 행실을 닦으며, 붙들던 것을 놓아 열반에 이르는 길을 설하신다.
- **핵심어** · 안거, 검은 법과 밝은 법, 멀리 여읨, 장애, 깨달음의 요소, 취착, 두 열반
- **평행문헌** · 《상윳따 니까야》 46.17 〈저 언덕으로 건너가는 경〉은 앞 이야기(06-10)의 제85·86게에 이어 제87–89게를 전한다. [《상윳따 니까야》 46.17 빨리어](https://www.dhammatalks.net/suttacentral/sc2016/sc/pi/sn46.17.html)

<a id="cscd-06-11-u001"></a>
## 안거를 마치고 스승을 찾아온 비구들

<a id="cscd-06-11-u001-e001"></a>

```original
11. Pañcasataāgantukabhikkhuvatthu
```

<a id="cscd-06-11-u001-p001"></a>

스승께서는 제따와나에 머무실 때 찾아온 비구 오백 명을 두고 ‘검은 법을 버리고’로 시작하는 이 법문을 설하셨다.

```original
Kaṇhaṃ dhammaṃ vippahāyāti imaṃ dhammadesanaṃ satthā jetavane viharanto pañcasate āgantuke bhikkhū ārabbha kathesi.
```

<a id="cscd-06-11-u001-p002"></a>

비구 오백 명은 꼬살라 나라에서 안거를 지냈다고 한다. 안거를 마치자 “스승을 뵈러 가자” 하고 제따와나로 갔다. 그들은 스승께 예배하고 한쪽에 앉았다. 스승께서는 그들의 성향에 맞게 번뇌를 다스릴 방도를 살피고 법을 설하시며 이 게송들을 말씀하셨다.

```original
Kosalaraṭṭhe  kira pañcasatā bhikkhū vassaṃ vasitvā vuṭṭhavassā ‘‘satthāraṃ passissāmā’’ti jetavanaṃ gantvā satthāraṃ vanditvā ekamantaṃ nisīdiṃsu. Satthā tesaṃ cariyapaṭipakkhaṃ nisāmetvā dhammaṃ desento imā gāthā abhāsi –
```

<a id="cscd-06-11-u002"></a>
## 제87–89게와 놓아 버림의 뜻

<a id="cscd-06-11-u002-v001"></a>

<pali-poem>

> **제87게**  
> 지혜로운 이는 검은 법을 버리고 밝은 법을 닦아야 한다.  
> 의지해 붙들던 곳을 떠나 붙들 것 없는 데 이르러, 즐기기 어려운 그 여읨에서

```original
87.
‘‘Kaṇhaṃ dhammaṃ vippahāya, sukkaṃ bhāvetha paṇḍito;
Okā anokamāgamma, viveke yattha dūramaṃ.
```

</pali-poem>

<a id="cscd-06-11-u002-v002"></a>

<pali-poem>

> **제88게**  
> 기쁨을 찾아야 한다. 감각적 욕망을 버려 얽매임이 없는  
> 지혜로운 이는 제 마음을 흐리는 것을 씻어 내야 한다.

```original
88.
‘‘Tatrābhiratimiccheyya, hitvā kāme akiñcano;
Pariyodapeyya attānaṃ, cittaklesehi paṇḍito.
```

</pali-poem>

<a id="cscd-06-11-u002-v003"></a>

<pali-poem>

> **제89게**  
> 깨달음의 요소들[^r3-01]로 마음을 바르게 닦고,  
> 아무것도 움켜쥐지 않고 붙들었던 것을 놓아 버리기를 즐기는 이들,  
> 그 빛나는 이들은 번뇌가 다하여 이 세상에서 완전히 열반에 들었다.

[^r3-01]: 깨달음의 일곱 요소는 마음챙김, 법의 탐구, 정진, 희열, 몸과 마음의 고요함, 삼매, 평정이다. 《상윳따 니까야》 46.17은 이 일곱을 길러 저 언덕에 이른다고 하고, 46.3은 각 요소를 어떤 경험으로 기르는지 설명한다. [《상윳따 니까야》 46.17](https://www.dhammatalks.net/suttacentral/sc2016/sc/pi/sn46.17.html) · [《상윳따 니까야》 46.3](https://dhammatalks.net/suttacentral/sc2016/sc/pi/sn46.3.html).

```original
89.
‘‘Yesaṃ sambodhiyaṅgesu, sammā cittaṃ subhāvitaṃ;
Ādānapaṭinissagge, anupādāya ye ratā;
Khīṇāsavā jutimanto, te loke parinibbutā’’ti.
```

</pali-poem>

<a id="cscd-06-11-u002-p001"></a>

‘검은 법을 버리고’는 몸으로 짓는 그릇된 행실을 비롯한 해로운 법을 버리라는 뜻이다. ‘밝은 법을 닦아야 한다’는 지혜로운 비구가 집을 떠나 출가한 때부터 아라한도에 이르기까지 몸의 바른 행실을 비롯한 선한 법을 닦으라는 뜻이다.

```original
Tattha kaṇhaṃ dhammanti kāyaducaritādibhedaṃ akusalaṃ dhammaṃ vippahāya jahitvā. Sukkaṃ bhāvethāti paṇḍito bhikkhu abhinikkhamanato paṭṭhāya yāva arahattamaggā kāyasucaritādibhedaṃ sukkaṃ dhammaṃ bhāveyya.
```

<a id="cscd-06-11-u002-p002"></a>

어떻게 닦는가? ‘의지해 붙들던 곳을 떠나 붙들 것 없는 데 이르러’는 마음이 매인 곳을 떠나 아무것도 붙들지 않는 열반을 향한다는 말이다. 열반을 바라고 그것을 수행의 목표로 삼아 닦으라는 뜻이다.

```original
Kathaṃ? Okā  anokamāgammāti okaṃ vuccati ālayo, anokaṃ vuccati anālayo, ālayato nikkhamitvā anālayasaṅkhātaṃ nibbānaṃ paṭicca ārabbha taṃ patthayamāno bhāveyyāti attho.
```

<a id="cscd-06-11-u002-p003"></a>

‘즐기기 어려운 그 여읨’은 아무것에도 매이지 않는 열반이다. 중생은 거기에서 좀처럼 기쁨을 느끼지 못한다. 수행자는 감각적 즐거움의 대상과 그것을 탐하는 번뇌를 버리고, 그 여읨에서 기쁨을 찾아야 한다. ‘제 마음을 흐리는 것’은 마음을 맑게 닦는 일을 가로막는 다섯 가지 장애[^r3-02]를 가리킨다.

[^r3-02]: 감각적 욕망, 악의, 해태와 혼침, 들뜸과 후회, 의심이다. 《상윳따 니까야》에서는 이 다섯이 마음을 흐리고 지혜를 약하게 한다고 한다. [《상윳따 니까야》 46.38](https://a-buddha-ujja.hu/sn-46.38/pli/tipitaka).

```original
Tatrābhiratimiccheyyāti yasmiṃ anālayasaṅkhāte viveke nibbāne imehi sattehi durabhiramaṃ, tatra abhiratiṃ iccheyya. Hitvā kāmeti vatthukāmakilesakāme hitvā akiñcano hutvā viveke abhiratiṃ iccheyyāti attho. Cittaklesehīti pañcahi nīvaraṇehi, attānaṃ pariyodapeyya vodāpeyya, parisodheyyāti attho.
```

<a id="cscd-06-11-u002-p004"></a>

‘깨달음의 요소들로 마음을 바르게 닦고’는 깨달음에 이바지하는 요소를 갖추어 알맞은 방법으로 마음을 길렀다는 뜻이다. ‘붙들었던 것을 놓아 버리기를 즐기는 이들’은 네 가지 취착[^r3-03]으로 어떤 것도 붙들지 않고, 그렇게 놓아 버리는 데서 즐거움을 얻는 사람들이다.

[^r3-03]: 감각적 즐거움, 견해, 계율과 의례, 자아를 내세우는 주장에 대한 취착이다. [《상윳따 니까야》 12.2](https://study.jhana.info/suttas/sn12.2).

```original
Sambodhiyaṅgesūti sambojjhaṅgesu. Sammā cittaṃ subhāvitanti hetunā nayena cittaṃ suṭṭhu bhāvitaṃ vaḍḍhitaṃ. Ādānapaṭinissaggeti  ādānaṃ vuccati gahaṇaṃ, tassa paṭinissaggasaṅkhāte aggahaṇe catūhi upādānehi kiñci anupādiyitvā ye ratāti attho.
```

<a id="cscd-06-11-u002-p005"></a>

‘빛나는 이들’은 아라한도의 지혜가 지닌 힘을 갖춘 이들이다. 그 지혜의 빛으로 오온을 비롯한 여러 법을 밝게 본다는 뜻이다.

```original
Jutimantoti ānubhāvavanto, arahattamaggañāṇajutiyā khandhādibhede dhamme jotetvā ṭhitāti attho.
```

<a id="cscd-06-11-u002-p006"></a>

주석은 ‘이 세상’을 오온 등으로 이루어진 세계라고 하고, ‘완전히 열반에 들었다’를 두 가지 열반으로 풀이한다. 아라한과를 얻을 때 번뇌가 되풀이되는 흐름이 끝난 것이 유여의열반이다. 생의 마지막 마음이 사라져 오온의 흐름마저 다한 것이 무여의열반[^r3-04]이다. 더는 기름을 받지 못해 등불이 꺼지듯, 몸과 마음의 흐름이 다하여 어떤 존재라고 이름 붙일 수 없게 되었다는 뜻이다.

[^r3-04]: 《이띠붓따까》 44에서 열반의 두 요소를 설명한다. 유여의열반의 ‘남아 있는 것’은 아라한이 살아 있는 동안의 몸과 마음이다. 경은 그때 감각 기능이 계속 작용하여 즐겁거나 괴로운 느낌도 경험한다고 설명한다. 그때 이미 탐욕·성냄·어리석음은 다했다. 무여의열반에서는 그러한 느낌도 모두 가라앉는다. [《이띠붓따까》 제44경](https://dhammatalks.net/suttacentral/sc2016/sc/pi/iti44.html).

```original
Te loketi imasmiṃ khandhādiloke parinibbutā nāma arahattapattito paṭṭhāya kilesavaṭṭassa khepitattā saupādisesena, carimacittanirodhena khandhavaṭṭassa khepitattā anupādisesena cāti dvīhi parinibbānehi parinibbutā, anupādāno viya padīpo apaṇṇattikabhāvaṃ gatāti attho.
```

<a id="cscd-06-11-u003"></a>
## 설법의 결실과 지혜로운 이의 품 맺음

<a id="cscd-06-11-u003-p001"></a>

설법이 끝나자 많은 이가 예류과를 비롯한 성취를 얻었다.

```original
Desanāvasāne  bahū sotāpattiphalādīni pāpuṇiṃsūti.
```

<a id="cscd-06-11-u003-e001"></a>

찾아온 비구 오백 명 이야기, 열한째.

```original
Pañcasataāgantukabhikkhuvatthu ekādasamaṃ.
```

<a id="cscd-06-11-u003-e002"></a>

지혜로운 이의 품 주석을 마쳤다.

```original
Paṇḍitavaggavaṇṇanā niṭṭhitā.
```

<a id="cscd-06-11-u003-e003"></a>

여섯째 품.

```original
Chaṭṭho vaggo.
```
