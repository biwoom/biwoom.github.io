# 25-08 수마나 꽃이 지는 것을 본 오백 비구 이야기
원문서명: 담마빠다 주석서(Dhammapada-aṭṭhakathā) | 저자: 미확정 | 출처: 《담마빠다 주석서》 제2부, VRI CSCD 로마자 XML 18661–18693행

- **품** · 제25품 비구의 품(Bhikkhuvaggo)
- **빨리어 표제** · Pañcasatabhikkhuvatthu
- **게송** · 제377게
- **요약** · 숲에서 수행하던 오백 비구가 아침에 핀 꽃이 저녁에 지는 것을 본다. 스승께서는 나무가 시든 꽃을 떨구듯 탐욕과 성냄을 떨쳐 버리라고 가르치신다.
- **핵심어** · 오백 비구, 수마나 꽃, 수행 주제, 광명, 탐욕, 성냄, 아라한과
- **평행문헌** · 20-09 〈황금 연꽃으로 수행한 금세공인의 아들 이야기〉

<a id="cscd-25-08-u001"></a>
## 꽃이 지는 모습에서 수행의 뜻을 새기다

<a id="cscd-25-08-u001-e001"></a>

```original
8. Pañcasatabhikkhuvatthu
```

<a id="cscd-25-08-u001-p001"></a>

스승께서는 제따와나에 머무실 때 오백 비구를 두고 ‘수마나 꽃나무가’로 시작하는 이 법문을 설하셨다.

```original
Vassikā  viya pupphānīti imaṃ dhammadesanaṃ satthā jetavane viharanto pañcasate bhikkhū ārabbha kathesi.
```

<a id="cscd-25-08-u001-p002"></a>

비구들은 스승께 수행 주제를 받아 숲에서 닦고 있었다고 한다. 아침에 핀 수마나 꽃[^r3-01]이 저녁에 꽃자루에서 떨어지는 것을 보았다. ‘꽃이 떨어지는 것보다 먼저 우리도 탐욕 따위를 떨쳐 내리라’고 다짐하고 힘써 수행했다.

[^r3-01]: 수마나(sumanā)는 재스민류의 향기로운 꽃이다. 이 게송은 꽃나무를 왓시까(vassikā)라 부른다. [《빨리어·미얀마어 대사전》 수마나 항목](https://abhidhana.buddha-dhamma.net/w/sumana)

```original
Te kira satthu santike kammaṭṭhānaṃ gahetvā araññe samaṇadhammaṃ karontā pātova pupphitāni vassikapupphāni sāyaṃ vaṇṭato muccantāni disvā ‘‘pupphānaṃ vaṇṭehi muccanato mayaṃ paṭhamataraṃ rāgādīhi muccissāmā’’ti vāyamiṃsu.
```

<a id="cscd-25-08-u001-p003"></a>

스승께서는 비구들을 살펴보시고 “비구들이여, 시든 꽃이 꽃자루에서 떨어지듯 괴로움에서 벗어나도록 힘써야 한다”라고 말씀하셨다. 향실에 앉으신 채 빛을 비추어 이 게송을 읊으셨다.

```original
Satthā te bhikkhū oloketvā, ‘‘bhikkhave, bhikkhunā nāma vaṇṭato muccanapupphena viya dukkhato muccituṃ vāyamitabbamevā’’ti vatvā gandhakuṭiyaṃ nisinnova ālokaṃ pharitvā imaṃ gāthamāha –
```

<a id="cscd-25-08-u002"></a>
## 제377게와 시든 꽃을 떨구는 수마나

<a id="cscd-25-08-u002-v001"></a>

<pali-poem>

> **제377게**  
> 수마나 꽃나무가 시든 꽃을 떨구듯,  
> 비구들이여, 너희도 탐욕과 성냄을 그렇게 떨쳐 버려라[^r3-02].

[^r3-02]: 《우다나바르가》의 대응 게송도 비구들에게 탐욕과 성냄을 떨치라고 한다. 그 첫 구절은 우기에 나무가 꽃을 떨구는 모습으로 비유한다. [《우다나바르가》 18.11](https://ancient-buddhist-texts.net/Texts-and-Translations/Udanavarga/18-Puspa.htm)

```original
377.
‘‘Vassikā viya pupphāni, maddavāni pamuñcati;
Evaṃ rāgañca dosañca, vippamuñcetha bhikkhavo’’ti.
```

</pali-poem>

<a id="cscd-25-08-u002-p001"></a>

여기서 ‘왓시까’는 수마나 꽃나무를 가리킨다. 수마나 꽃나무는 어느 날 핀 꽃이 이튿날 시들면 꽃자루에서 떨군다.[^r3-03] 비구들도 그처럼 탐욕 등의 허물을 떨쳐 버리라는 말이다.

[^r3-03]: 이야기에서는 비구들이 아침에 핀 꽃이 저녁에 지는 것을 본다. 게송 풀이는 전날 핀 꽃이 이튿날 진다는 예를 든다. 두 대목의 비유는 모두 꽃이 꽃자루에서 떨어지는 모습에 놓여 있다. [《담마빠다 주석서》 〈오백 비구 이야기〉](https://epitaka.org/ru/book/Dhp-a/8.-pa%C3%B1casatabhikkhuvatthu-4664)

```original
Tattha vassikāti sumanā. Maddavānīti milātāni. Idaṃ vuttaṃ hoti – yathā vassikā hiyyo pupphitapupphāni  punadivase purāṇabhūtāni muñcati, vaṇṭato vissajjeti, evaṃ tumhepi rāgādayo dose vippamuñcethāti.
```

<a id="cscd-25-08-u002-p002"></a>

설법이 끝나자 비구들은 모두 아라한과를 얻었다.

```original
Desanāvasāne sabbepi te bhikkhū arahatte patiṭṭhahiṃsūti.
```

<a id="cscd-25-08-u002-e001"></a>

수마나 꽃이 지는 것을 본 오백 비구 이야기, 여덟째.

```original
Pañcasatabhikkhuvatthu aṭṭhamaṃ.
```
