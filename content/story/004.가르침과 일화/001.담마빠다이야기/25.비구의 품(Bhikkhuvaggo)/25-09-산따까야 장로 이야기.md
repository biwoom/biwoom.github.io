# 25-09 산따까야 장로 이야기
원문서명: 담마빠다 주석서(Dhammapada-aṭṭhakathā) | 저자: 미확정 | 출처: 《담마빠다 주석서》 제2부, VRI CSCD 로마자 XML 18697–18729행

- **품** · 제25품 비구의 품(Bhikkhuvaggo)
- **빨리어 표제** · Santakāyattheravatthu
- **게송** · 제378게
- **요약** · 산따까야 장로의 몸가짐은 고요하다. 스승께서는 몸과 말과 마음이 고요하고 세상의 미끼를 뱉어 버린 비구를 평온한 이라 부르신다.
- **핵심어** · 산따까야, 사자, 몸가짐, 고요, 네 가지 도, 아라한과

<a id="cscd-25-09-u001"></a>
## 전생에 사자였던 장로의 고요한 몸가짐

<a id="cscd-25-09-u001-e001"></a>

```original
9. Santakāyattheravatthu
```

<a id="cscd-25-09-u001-p001"></a>

스승께서는 제따와나에 머무실 때 산따까야라는 장로를 두고 ‘몸이 고요하고’로 시작하는 이 법문을 설하셨다.

```original
Santakāyoti imaṃ dhammadesanaṃ satthā jetavane viharanto santakāyattheraṃ nāma ārabbha kathesi.
```

<a id="cscd-25-09-u001-p002"></a>

장로는 손발을 꼼지락거리거나 기지개를 켜는 일이 없이 몸가짐이 고요했다고 한다. 지난 생에는 사자였다.

```original
Tassa kira hatthapādakukkuccaṃ nāma nāhosi, kāyavijambhanarahito santaattabhāvova ahosi. So kira sīhayonito āgato thero.
```

<a id="cscd-25-09-u001-p003"></a>

사자들은 먹이를 잡은 날이면 은, 금, 보석, 산호로 된 굴 가운데 하나에 들어간다고 한다. 붉은 광물 바닥에 깔린 노란 광물 가루 위에서 이레 동안 누워 지낸다. 이레째 되는 날에는 일어나 누웠던 자리를 살핀다. 꼬리나 귀나 앞발이나 뒷발이 움직여 붉고 노란 가루가 흩어졌으면 ‘이런 몸가짐은 우리 혈통에 걸맞지 않아’ 하고 먹지도 않은 채 다시 이레 동안 눕는다. 가루가 흩어지지 않았으면 ‘우리 혈통에 걸맞아’ 하고 굴에서 나온다. 기지개를 켜고 사방을 둘러본 뒤 세 번 포효하고 먹이를 찾아 떠난다. 이 비구는 지난 생에 이런 사자였다.

```original
Sīhā kira ekadivasaṃ gocaraṃ gahetvā rajatasuvaṇṇamaṇipavāḷaguhānaṃ aññataraṃ pavisitvā manosilātale haritālacuṇṇesu sattāhaṃ nipajjitvā  sattame divase uṭṭhāya nipannaṭṭhānaṃ oloketvā sace naṅguṭṭhassa vā kaṇṇānaṃ vā hatthapādānaṃ vā calitattā manosilāharitālacuṇṇānaṃ vippakiṇṇataṃ passanti, ‘‘na te idaṃ jātiyā vā gottassa vā patirūpa’’nti  puna sattāhaṃ nirāhārā nipajjanti, cuṇṇānaṃ pana vippakiṇṇabhāve asati ‘‘idaṃ  te jātigottānaṃ anucchavika’’nti āsayā nikkhamitvā vijambhitvā disā anuviloketvā tikkhattuṃ sīhanādaṃ naditvā gocarāya pakkamanti. Evarūpāya sīhayoniyā āgato ayaṃ bhikkhu.
```

<a id="cscd-25-09-u001-p004"></a>

비구들은 장로의 몸가짐을 보고 스승께 말씀드렸다. “존자시여, 저희는 산따까야 장로 같은 비구를 본 적이 없습니다. 그는 한 번 앉으면 손발을 꼼지락거리지도, 기지개를 켜지도 않습니다.” 스승께서는 그 말을 듣고 “비구들이여, 비구는 산따까야 장로처럼 몸과 말과 마음을 가라앉혀야 한다”라고 하시고 이 게송을 읊으셨다.

```original
Tassa kāyasamācāraṃ disvā bhikkhū satthu ārocesuṃ – ‘‘na no, bhante, santakāyattherasadiso bhikkhu diṭṭhapubbo. Imassa hi nisinnaṭṭhāne hatthacalanaṃ vā pādacalanaṃ vā kāyavijambhitā vā natthī’’ti. Taṃ sutvā satthā, ‘‘bhikkhave, bhikkhunā nāma santakāyattherena viya kāyādīhi upasanteneva bhavitabba’’nti vatvā imaṃ gāthamāha –
```

<a id="cscd-25-09-u002"></a>
## 제378게와 몸과 말과 마음의 고요

<a id="cscd-25-09-u002-v001"></a>

<pali-poem>

> **제378게**  
> 몸이 고요하고 말이 고요하며,  
> 마음이 고요하고[^r3-01] 스스로 잘 가다듬어,  
> 세상의 미끼를 뱉어 버린[^r3-02] 비구를  
> 평온한 이라 부른다.

[^r3-02]: 세상의 즐거움에 끌려 집착하게 하는 것을 미끼에 빗댄 말이다. 〈위깐나까 본생담〉 주석도 감각적 즐거움에 끌리는 것을 악어가 미끼를 쫓는 모습에 빗댄다. [《자따까》 제233편](https://www.palikanon.com/pali/khuddaka/jataka/jat233.htm)
[^r3-01]: CSCD는 이 자리에 산따와(santavā)를 두고, 주석은 탐내는 마음 등이 없다는 뜻으로 풀이한다. 태국판은 마음의 고요를 명시하는 산따마노(santamano)로 읽는다. 《빠뜨나 담마빠다》 제53게는 몸과 마음의 고요를 함께 든다. [《담마빠다》 판본 대조 제378게](https://ancient-buddhist-texts.net/Buddhist-Texts/K2-Dhammapada-New/25-Bhikkhu.htm) · [《빠뜨나 담마빠다》 제53게](https://ancient-buddhist-texts.net/Texts-and-Translations/Patna-Dhammapada/04-Monastics.htm)

```original
378.
‘‘Santakāyo santavāco, santavā susamāhito;
Vantalokāmiso bhikkhu, upasantoti vuccatī’’ti.
```

</pali-poem>

<a id="cscd-25-09-u002-p001"></a>

‘몸이 고요하고’는 살생 등을 삼가 몸이 고요하다는 뜻이다. 거짓말 등을 삼가 말이 고요하고, 탐내는 마음 등이 없어 마음이 고요하다.  몸과 말과 마음을 모두 잘 가다듬었다는 말이 ‘스스로 잘 가다듬어’다. 네 가지 도[^r3-03]를 닦아 세상의 미끼를 뱉어 버리면 마음속의 탐욕 등이 가라앉으므로 그 비구를 ‘평온한 이’라 부른다.

[^r3-03]: 깨달음으로 차례로 나아가는 예류·일래·불환·아라한의 길을 가리킨다.

```original
Tattha santakāyoti pāṇātipātādīnaṃ abhāvena santakāyo, musāvādādīnaṃ abhāvena santavāco, abhijjhādīnaṃ abhāvena santavā, kāyādīnaṃ tiṇṇampi suṭṭhu samāhitattā susamāhito, catūhi maggehi lokāmisassa vantatāya vantalokāmiso bhikkhu abbhantare rāgādīnaṃ upasantatāya upasantoti vuccatīti attho.
```

<a id="cscd-25-09-u002-p002"></a>

설법이 끝나자 장로는 아라한과를 얻었고, 모인 이들도 법문에서 이로움을 얻었다.

```original
Desanāvasāne so thero arahatte patiṭṭhahi, sampattānampi sātthikā dhammadesanā ahosīti.
```

<a id="cscd-25-09-u002-e001"></a>

산따까야 장로 이야기, 아홉째.

```original
Santakāyattheravatthu navamaṃ.
```
