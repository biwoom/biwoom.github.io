# 26-36 곡예를 하던 장로의 또 다른 이야기
원문서명: 담마빠다 주석서(Dhammapada-aṭṭhakathā) | 저자: 미확정 | 출처: 《담마빠다 주석서》 제2부, VRI CSCD 로마자 XML 20625–20653행

- **품** · 제26품 바라문의 품(Brāhmaṇavaggo)
- **빨리어 표제** · Naṭaputtakattheravatthu
- **게송** · 제418게
- **요약** · 앞 편과 같은 사연을 두고 스승께서는 장로가 감각의 즐거움에 빠지는 마음과 숲 생활에 싫증을 내는 마음을 버렸다고 말씀하셨다.
- **핵심어** · 곡예, 즐김, 싫증, 평온, 오온, 바라문
- **평행문헌** · 26-35 〈곡예를 하던 장로 이야기〉 · [《숫따니빠따》 3.9 〈와셋타 경〉](https://dhammatalks.net/suttacentral/sc2016/sc/pi/snp3.9.html)

<a id="cscd-26-36-u001"></a>
## 스승께서 장로가 탐닉과 싫증을 버렸다고 하시다

<a id="cscd-26-36-u001-e001"></a>

```original
36. Naṭaputtakattheravatthu
```

<a id="cscd-26-36-u001-p001"></a>

스승께서는 웰루와나에 머무실 때 이번에도 곡예사의 아들이었던 한 장로를 두고 ‘탐닉과 싫증을 버려’로 시작하는 이 법문을 설하셨다. 사연은 26-35 〈곡예를 하던 장로 이야기〉와 같다. 여기서 스승께서는 “비구들이여, 내 아들은 이미 탐닉과 싫증을 버렸다”라고 하시며 이 게송을 읊으셨다.

```original
Hitvā ratiñcāti imaṃ dhammadesanaṃ satthā veḷuvane viharanto ekaṃ naṭaputtakaṃyeva ārabbha kathesi. Vatthu purimasadisameva. Idha pana satthā, ‘‘bhikkhave, mama putto ratiñca aratiñca pahāya ṭhito’’ti vatvā imaṃ gāthamāha –
```

<a id="cscd-26-36-u002"></a>
## 제418게와 온 세상을 이겨 낸 이

<a id="cscd-26-36-u002-v001"></a>

<pali-poem>

> **제418게**  
> 탐닉과 싫증을 버려 평온하고 번뇌에서 벗어난 이,  
> 온 세상을 이겨 낸 힘찬 이,  
> 나는 그를 바라문이라 부른다.[^r3-01]

[^r3-01]: [《숫따니빠따》 3.9 〈와셋타 경〉](https://dhammatalks.net/suttacentral/sc2016/sc/pi/snp3.9.html)에도 이 게송이 나온다.

```original
418.
‘‘Hitvā ratiñca aratiñca, sītibhūtaṃ nirūpadhiṃ;
Sabbalokābhibhuṃ vīraṃ, tamahaṃ brūmi brāhmaṇa’’nti.
```

</pali-poem>

<a id="cscd-26-36-u002-p001"></a>

‘탐닉’은 다섯 감각의 즐거움에 빠지는 마음이고, ‘싫증’은 숲에서 수행하는 생활에 싫증을 내는 마음이다. ‘평온하고’는 마음이 가라앉아 고요하다는 뜻이며, ‘번뇌에서 벗어난 이’는 마음을 흐리는 번뇌가 없다는 뜻이다. 오온으로 이루어진 세상[^r3-02]을 온전히 이겨 내고 정진의 힘을 갖춘 이를 나는 바라문이라 부른다.

[^r3-02]: 오온은 몸과 마음을 이루는 물질적 형상, 느낌, 지각, 의지적 형성, 의식이라는 다섯 무더기다.

```original
Tattha  ratinti pañcakāmaguṇaratiṃ. Aratinti araññavāse ukkaṇṭhitattaṃ. Sītibhūtanti nibbutaṃ. Nirūpadhinti nirupakkilesaṃ. Vīranti taṃ evarūpaṃ sabbaṃ khandhalokaṃ abhibhavitvā ṭhitaṃ vīriyavantaṃ ahaṃ brāhmaṇaṃ vadāmīti attho.
```

<a id="cscd-26-36-u002-p002"></a>

설법이 끝나자 많은 이가 예류과 등의 과를 얻었다.

```original
Desanāvasāne bahū sotāpattiphalādīni pāpuṇiṃsūti.
```

<a id="cscd-26-36-u002-e001"></a>

곡예를 하던 장로의 또 다른 이야기, 서른여섯째.

```original
Naṭaputtakattheravatthu chattiṃsatimaṃ.
```
