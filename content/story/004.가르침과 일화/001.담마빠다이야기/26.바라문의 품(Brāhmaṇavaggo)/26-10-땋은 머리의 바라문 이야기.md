# 26-10 땋은 머리의 바라문 이야기
원문서명: 담마빠다 주석서(Dhammapada-aṭṭhakathā) | 저자: 미확정 | 출처: 《담마빠다 주석서》 제2부, VRI CSCD 로마자 XML 19413–19445행

- **품** · 제26품 바라문의 품(Brāhmaṇavaggo)
- **빨리어 표제** · Jaṭilabrāhmaṇavatthu
- **게송** · 제393게
- **요약** · 머리를 땋은 한 바라문이 어머니와 아버지 양쪽의 혈통을 들어 자신도 바라문이라 불러야 한다고 물었다. 스승께서는 진리를 꿰뚫고 법을 갖춘 이를 바라문이라 부르셨다.
- **핵심어** · 바라문, 땋은 머리, 혈통, 네 가지 진리, 출세간의 법
- **평행문헌** · 26-04 태생이 바라문인 이가 한 질문

<a id="cscd-26-10-u001"></a>
## 양쪽 혈통을 내세우는 바라문

<a id="cscd-26-10-u001-e001"></a>

```original
10. Jaṭilabrāhmaṇavatthu
```

<a id="cscd-26-10-u001-p001"></a>

스승께서는 제따와나에 머무실 때 땋은 머리의 한 바라문을 두고 ‘땋은 머리로도’로 시작하는 이 법문을 설하셨다.

```original
Na jaṭāhīti imaṃ dhammadesanaṃ satthā jetavane viharanto ekaṃ jaṭilabrāhmaṇaṃ ārabbha kathesi.
```

<a id="cscd-26-10-u001-p002"></a>

그 바라문은 생각했다. ‘나는 어머니 쪽과 아버지 쪽이 모두 좋은 혈통인 바라문 집안에서 태어났다. 사문 고따마가 제자들을 바라문이라 부르니 나도 그렇게 부를 만하다.’ 그는 스승께 가서 그렇게 여쭈었다. 스승께서는 “바라문이여, 머리를 땋았거나 좋은 집안에서 태어났다고 해서 바라문이라 부르지는 않는다. 나는 진리를 꿰뚫은 이를 바라문이라 부른다”라고 말씀하시고 법을 설하며 이 게송을 읊으셨다.

```original
So  kira ‘‘ahaṃ mātito ca pitito ca sujāto brāhmaṇakule nibbatto. Sace samaṇo gotamo attano sāvake brāhmaṇāti vadati, mampi nu kho tathā vattuṃ vaṭṭatī’’ti satthu santikaṃ gantvā tamatthaṃ pucchi. Atha naṃ satthā ‘‘nāhaṃ, brāhmaṇa, jaṭāmattena, na jātigottamattena brāhmaṇaṃ vadāmi, paṭividdhasaccameva panāhaṃ brāhmaṇoti vadāmī’’ti vatvā dhammaṃ desento imaṃ gāthamāha –
```

<a id="cscd-26-10-u002"></a>
## 제393게와 진리와 법을 갖춘 이

<a id="cscd-26-10-u002-v001"></a>

<pali-poem>

> **제393게**  
> 땋은 머리로도, 혈통으로도, 태생으로도 바라문이 되지 않는다.[^r3-01]  
> 진리와 법을 갖춘 이, 그가 청정한 이요 바라문이다.

[^r3-01]: 《빠뜨나 담마빠다》 제37게도 머리 모양과 혈통과 태생을 든 뒤, 작은 악이든 큰 악이든 남김없이 물리치는 이를 바라문이라 한다. 《우다나바르가》 33.7은 CSCD처럼 진리와 법을 갖춘 이를 든다. [《빠뜨나 담마빠다》 제37게](https://ancient-buddhist-texts.net/Texts-and-Translations/Patna-Dhammapada/03-Brahmins.htm) · [《우다나바르가》 33.7–8](https://ancient-buddhist-texts.net/Texts-and-Translations/Udanavarga/33-Brahmana.htm)

```original
393.
‘‘Na jaṭāhi na gottena, na jaccā hoti brāhmaṇo;
Yamhi saccañca dhammo ca, so sucī so ca brāhmaṇo’’ti.
```

</pali-poem>

<a id="cscd-26-10-u002-p001"></a>

여기서 ‘진리’는 네 가지 성스러운 진리를 열여섯 가지 측면[^r3-02]에서 꿰뚫어 얻은 앎이다. 그 앎과 아홉 가지 출세간법[^r3-03]을 갖춘 이가 청정한 이요 바라문이라는 뜻이다.

[^r3-03]: 예류·일래·불환·아라한의 네 도와 각각의 결실인 네 과, 그리고 열반이다. [《빠띠삼비다막가 주석》 〈출세간법 논의 풀이〉](https://epitaka.org/lo/book/Pa%E1%B9%ADis-a/lokuttarakath%C4%81va%E1%B9%87%E1%B9%87an%C4%81-2185)
[^r3-02]: 네 진리마다 네 측면씩 살피므로 열여섯 가지다. 예를 들어 괴로움에는 압박, 조건에 따른 형성, 타오름, 변화의 네 측면이 있다. 19-04의 제261게 풀이도 이 열여섯 가지를 든다. [《빠띠삼비다막가》 〈첫 경 풀이〉](https://epitaka.org/en/book/Pa%E1%B9%ADis/1-pa%E1%B9%ADhamasuttantaniddeso-1420)

```original
Tattha  saccanti yasmiṃ puggale cattāri saccāni soḷasahākārehi paṭivijjhitvā ṭhitaṃ saccañāṇañceva navavidho ca lokuttaradhammo atthi, so suci, so brāhmaṇo cāti attho.
```

<a id="cscd-26-10-u002-p002"></a>

설법이 끝나자 많은 이가 예류과를 비롯한 성취를 얻었다.

```original
Desanāvasāne bahū sotāpattiphalādīni pāpuṇiṃsūti.
```

<a id="cscd-26-10-u002-e001"></a>

땋은 머리의 바라문 이야기, 열째.

```original
Jaṭilabrāhmaṇavatthu dasamaṃ.
```
