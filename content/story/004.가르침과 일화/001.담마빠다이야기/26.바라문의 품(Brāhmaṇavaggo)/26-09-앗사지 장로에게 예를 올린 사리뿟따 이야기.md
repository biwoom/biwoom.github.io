# 26-09 앗사지 장로에게 예를 올린 사리뿟따 이야기
원문서명: 담마빠다 주석서(Dhammapada-aṭṭhakathā) | 저자: 미확정 | 출처: 《담마빠다 주석서》 제2부, VRI CSCD 로마자 XML 19377–19409행

- **품** · 제26품 바라문의 품(Brāhmaṇavaggo)
- **빨리어 표제** · Sāriputtattheravatthu
- **게송** · 제392게
- **요약** · 사리뿟따는 처음 법을 들려준 앗사지 장로가 있는 쪽을 향해 합장하고 그쪽으로 머리를 두고 누웠다. 스승께서는 그가 법을 가르친 스승을 공경한다고 설명하셨다.
- **핵심어** · 사리뿟따, 앗사지, 스승, 합장, 예류과, 불의 제사
- **평행문헌** · 01-08 앗사지에게 법을 듣는 우빠띳사

<a id="cscd-26-09-u001"></a>
## 사리뿟따가 앗사지가 있는 방향으로 예를 올리다

<a id="cscd-26-09-u001-e001"></a>

```original
9. Sāriputtattheravatthu
```

<a id="cscd-26-09-u001-p001"></a>

스승께서는 제따와나에 머무실 때 사리뿟따 장로를 두고 ‘정등각자께서 설하신 법을’로 시작하는 이 법문을 설하셨다.

```original
Yamhāti  imaṃ dhammadesanaṃ satthā jetavane viharanto sāriputtattheraṃ ārabbha kathesi.
```

<a id="cscd-26-09-u001-p002"></a>

사리뿟따는 앗사지 장로에게서 법을 듣고 예류과를 얻었다.[^r3-01] 그때부터 앗사지 장로가 어디에 머무는지 들으면 그쪽을 향해 합장하고, 그쪽으로 머리를 두고 누웠다고 한다. 비구들은 “사리뿟따는 그릇된 견해를 지녔습니다. 아직도 여러 방위를 향해 절하고 다닙니다[^r3-02]”라고 여래께 아뢰었다.

[^r3-02]: 〈싱갈라 경〉에는 아버지의 유언을 따라 동서남북과 위아래 여섯 방위에 합장하는 재가자가 나온다. 여기서 비구들은 사리뿟따의 합장을 그런 방위 예배로 오해했다. [《디가 니까야》 31](https://dhammatalks.net/suttacentral/sc2016/sc/pi/dn31.html)
[^r3-01]: 01-08 〈앗사지의 게송과 우빠띳사의 예류〉에서 사리뿟따는 출가 전 이름인 우빠띳사로 나온다. 《율장》은 그가 앗사지에게 원인에서 생기는 법의 원인과 소멸을 담은 게송을 듣고 법의 눈을 얻었다고 전한다. [《율장》 〈대품〉 1.23](https://epitaka.org/en/book/Vin-iii/14.-s%C4%81riputtamoggall%C4%81napabbajj%C4%81kath%C4%81-304)

```original
So kirāyasmā assajittherassa santike dhammaṃ sutvā sotāpattiphalaṃ pattakālato paṭṭhāya ‘‘yassaṃ disāyaṃ thero vasatī’’ti suṇāti, tato añjaliṃ paggayha tatova sīsaṃ katvā nipajjati. Bhikkhū ‘‘micchādiṭṭhiko sāriputto, ajjāpi disā namassamāno vicaratī’’ti tamatthaṃ tathāgatassa ārocesuṃ.
```

<a id="cscd-26-09-u001-p003"></a>

스승께서는 장로를 불러 “사리뿟따여, 그대가 여러 방위에 절하고 다닌다는 말이 참인가?” 하고 물으셨다. “존자시여, 제가 방위에 절하는 것인지는 세존께서 아십니다.” 스승께서는 말씀하셨다. “비구들이여, 사리뿟따는 방위에 절하는 것이 아니다. 자신에게 법을 들려주어 예류과에 이르게 한 스승 앗사지에게 예를 올리는 것이다. 비구라면 자신을 가르쳐 법을 알게 해 준 스승을, 바라문이 제사의 불을 섬기듯 정성껏 공경해야 한다.” 이렇게 말씀하시고 법을 설하며 이 게송을 읊으셨다.

```original
Satthā theraṃ pakkosāpetvā ‘‘saccaṃ kira tvaṃ, sāriputta, disā namassanto vicarasī’’ti pucchitvā, ‘‘bhante, mama disā namassanabhāvaṃ vā anamassanabhāvaṃ vā  tumheva jānāthā’’ti vutte ‘‘na, bhikkhave, sāriputto disā namassati, assajittherassa pana santikā dhammaṃ sutvā sotāpattiphalaṃ pattatāya attano ācariyaṃ namassati. Yañhi ācariyaṃ nissāya bhikkhu dhammaṃ vijānāti, tena so brāhmaṇena aggi viya sakkaccaṃ namassitabboyevā’’ti vatvā dhammaṃ desento imaṃ gāthamāha –
```

<a id="cscd-26-09-u002"></a>
## 제392게와 법을 가르친 스승을 공경하는 일

<a id="cscd-26-09-u002-v001"></a>

<pali-poem>

> **제392게**  
> 정등각자께서 설하신 법을 누구에게서 알게 되었거든,  
> 바라문이 제사의 불을 섬기듯[^r3-03] 그를 정성껏 공경하라.

[^r3-03]: 제사의 불은 바라문이 제사에 피워 돌보고 공경하는 불이다. 《빠뜨나 담마빠다》 제35게도 이 비유를 쓰고, 법을 알게 해 준 이가 나이 들었든 젊든 공경하라고 한다. 같은 책 제36게에는 ‘바르게 깨달은 분이 설한 법’과 ‘그를 공경하라’는 두 구절이 나온다. 《우다나바르가》에는 정등각자께서 설하신 법을 알게 해 준 이를 공경하라는 같은 구조가 나온다. [《빠뜨나 담마빠다》 제35·36게](https://ancient-buddhist-texts.net/Texts-and-Translations/Patna-Dhammapada/03-Brahmins.htm) · [《우다나바르가》 33.66](https://ancient-buddhist-texts.net/Texts-and-Translations/Udanavarga/33-Brahmana.htm)

```original
392.
‘‘Yamhā dhammaṃ vijāneyya, sammāsambuddhadesitaṃ;
Sakkaccaṃ taṃ namasseyya, aggihuttaṃva brāhmaṇo’’ti.
```

</pali-poem>

<a id="cscd-26-09-u002-p001"></a>

바라문이 제사의 불을 정성껏 보살피고 합장하여 예를 올리듯, 여래께서 밝혀 주신 법을 알게 해 준 스승에게도 정성껏 예를 올려야 한다는 뜻이다.

```original
Tattha aggihuttaṃvāti yathā brāhmaṇo aggihuttaṃ sammā paricaraṇena ceva añjalikammādīhi ca sakkaccaṃ namassati, evaṃ yamhā ācariyā tathāgatapaveditaṃ dhammaṃ vijāneyya, taṃ sakkaccaṃ namasseyyāti attho.
```

<a id="cscd-26-09-u002-p002"></a>

설법이 끝나자 많은 이가 예류과를 비롯한 성취를 얻었다.

```original
Desanāvasāne bahū sotāpattiphalādīni pāpuṇiṃsūti.
```

<a id="cscd-26-09-u002-e001"></a>

앗사지 장로에게 예를 올린 사리뿟따 이야기, 아홉째.

```original
Sāriputtattheravatthu navamaṃ.
```
