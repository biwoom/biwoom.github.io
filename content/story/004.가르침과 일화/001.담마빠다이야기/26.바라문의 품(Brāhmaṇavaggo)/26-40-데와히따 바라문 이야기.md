# 26-40 데와히따 바라문 이야기
원문서명: 담마빠다 주석서(Dhammapada-aṭṭhakathā) | 저자: 미확정 | 출처: 《담마빠다 주석서》 제2부, VRI CSCD 로마자 XML 20785–20841행

- **품** · 제26품 바라문의 품(Brāhmaṇavaggo)
- **빨리어 표제** · Devahitabrāhmaṇavatthu
- **게송** · 제423게
- **요약** · 데와히따는 병든 스승께 따뜻한 물과 당밀을 보내 드렸다. 뒤에 스승을 찾아가 누구에게 보시해야 큰 결실을 맺는지 여쭈었다. 스승께서는 지난 생을 알고 다시 태어남이 끝난 이를 바라문이라 부르셨다.
- **핵심어** · 데와히따, 우빠와나, 보시, 지난 생, 천상과 악처, 태어남의 소멸, 바라문
- **평행문헌** · [《상윳따 니까야》 7.13 〈데와히따 경〉](https://dhammatalks.net/suttacentral/sc2016/sc/pi/sn7.13.html) · [《숫따니빠따》 3.9 〈와셋타 경〉 제652게](https://epitaka.org/en/book/Sn/9-v%C4%81se%E1%B9%AD%E1%B9%ADhasutta%E1%B9%83-2059)

<a id="cscd-26-40-u001"></a>
## 데와히따가 병든 스승께 따뜻한 물을 보내다

<a id="cscd-26-40-u001-e001"></a>

```original
40. Devahitabrāhmaṇavatthu
```

<a id="cscd-26-40-u001-p001"></a>

스승께서는 제따와나에 머무실 때 데와히따 바라문의 질문을 두고 ‘지난 생을 알고’로 시작하는 이 법문을 설하셨다.

```original
Pubbenivāsanti imaṃ dhammadesanaṃ satthā jetavane viharanto devahitabrāhmaṇassa pañhaṃ ārabbha kathesi.
```

<a id="cscd-26-40-u001-p002"></a>

어느 때 세존께서 바람 기운으로 생긴 병[^r3-01]을 앓으셨다. 세존께서는 우빠와나 장로를 데와히따 바라문에게 보내 따뜻한 물을 구하게 하셨다. 장로는 스승께서 편찮으시다고 알리고 따뜻한 물을 청했다. 데와히따는 그 말을 듣고 기뻐했다. ‘정등각자께서 따뜻한 물을 구하러 내게 제자를 보내시다니, 내게 참으로 다행이다.’ 데와히따는 사람을 시켜 따뜻한 물을 멜대로 나르게 하고, 우빠와나 장로에게 당밀 한 꾸러미를 주었다.

[^r3-01]: 빨리어 와따로가(vātaroga)다. 이 편과 〈데와히따 경〉은 병을 바람 기운(vāta)과 관련지어 말하며 따뜻한 물과 당밀을 드린 일을 전한다. [《상윳따 니까야》 7.13](https://dhammatalks.net/suttacentral/sc2016/sc/pi/sn7.13.html)

```original
Ekasmiñhi samaye bhagavā vātarogena ābādhiko hutvā upavāṇattheraṃ uṇhodakatthāya devahitabrāhmaṇassa santikaṃ pahiṇi. So gantvā satthu ābādhikabhāvaṃ ācikkhitvā uṇhodakaṃ yāci, taṃ sutvā brāhmaṇo tuṭṭhamānaso hutvā ‘‘lābhā vata me, yaṃ mama santikaṃ sammāsambuddho uṇhodakassatthāya sāvakaṃ pahiṇī’’ti uṇhodakassa kājaṃ purisena gāhāpetvā phāṇitassa ca puṭaṃ upavāṇattherassa pādāsi.
```

<a id="cscd-26-40-u001-p003"></a>

장로는 따뜻한 물과 당밀을 가지고 사원으로 돌아갔다. 스승께 따뜻한 물로 목욕을 시켜 드리고, 따뜻한 물에 당밀을 풀어 드렸다. 그 순간 세존의 병이 가라앉았다. 바라문은 ‘누구에게 베풀어야 큰 결실을 맺을까? 스승께 여쭈어야겠다’고 생각했다. 데와히따는 스승을 찾아가 이 게송으로 여쭈었다.

```original
Thero taṃ gāhāpetvā vihāraṃ gantvā satthāraṃ uṇhodakena nhāpetvā uṇhodakena phāṇitaṃ āloḷetvā bhagavato pādāsi, tassa taṅkhaṇeyeva so ābādho paṭipassambhi. Brāhmaṇo cintesi  – ‘‘kassa nu kho deyyadhammo dinno mahapphalo hoti, satthāraṃ pucchissāmī’’ti so satthu santikaṃ gantvā tamatthaṃ pucchanto imaṃ gāthamāha –
```

<a id="cscd-26-40-u002"></a>
## 어디에 보시해야 큰 결실을 맺는지 묻다

<a id="cscd-26-40-u002-v001"></a>

<pali-poem>

> 누구에게 보시해야 합니까? 누구에게 드려야 큰 결실을 맺습니까?  
> 보시하는 이의 공양은 어떻게 결실을 맺습니까?[^r3-02]

[^r3-02]: 데와히따가 보시할 대상을 묻는 이 게송은 [《상윳따 니까야》 7.13 〈데와히따 경〉](https://dhammatalks.net/suttacentral/sc2016/sc/pi/sn7.13.html)에도 나온다.


```original
‘‘Kattha dajjā deyyadhammaṃ, kattha dinnaṃ mahapphalaṃ;
Kathañhi yajamānassa, kathaṃ ijjhati dakkhiṇā’’ti. (saṃ. ni. 1.199);
```

</pali-poem>

<a id="cscd-26-40-u002-p001"></a>

스승께서는 “이런 바라문에게 보시하면 큰 결실을 맺는다”라고 답하시고, 어떤 이를 바라문이라 하는지 이 게송으로 밝히셨다.

```original
Athassa satthā ‘‘evarūpassa brāhmaṇassa dinnaṃ mahapphalaṃ hotī’’ti vatvā brāhmaṇaṃ pakāsento imaṃ gāthamāha –
```

<a id="cscd-26-40-u003"></a>
## 제423게와 이루어야 할 일을 모두 마친 이

<a id="cscd-26-40-u003-v001"></a>

<pali-poem>

> **제423게**  
> 지난 생을 알고 천상과 악처를 보며,  
> 다시 태어남이 끝나고 몸소 알아 수행을 마친 성자,  
> 이루어야 할 일을 모두 마친 이,  
> 나는 그를 바라문이라 부른다.[^r3-03]

[^r3-03]: [《상윳따 니까야》 7.13 〈데와히따 경〉](https://dhammatalks.net/suttacentral/sc2016/sc/pi/sn7.13.html)의 답에는 지난 생을 알고 태어남이 끝나 수행을 마친 성자까지 같은 구절이 나온다. 이어 그런 이에게 보시하면 큰 결실을 맺는다고 답한다. [《숫따니빠따》 3.9 〈와셋타 경〉 제652게](https://epitaka.org/en/book/Sn/9-v%C4%81se%E1%B9%AD%E1%B9%ADhasutta%E1%B9%83-2059)는 지난 생과 천상·악처, 태어남의 끝을 말한 뒤 그런 이를 바라문이라 부른다.


```original
423.
‘‘Pubbenivāsaṃ  yo vedi, saggāpāyañca passati;
Atho jātikkhayaṃ patto, abhiññāvosito muni; (Saṃ. ni. 1.199);
Sabbavositavosānaṃ, tamahaṃ brūmi brāhmaṇa’’nti.
```

</pali-poem>

<a id="cscd-26-40-u003-p001"></a>

이 사람은 지난 생을 분명히 알고, 천안으로[^r3-04] 스물여섯 갈래 천상과 네 가지 악처[^r3-05]를 본다. 다시 태어남이 끝나는 아라한과에 이르렀다. 직접 알아야 할 법을 알고, 두루 알아야 할 것을 두루 알고, 버려야 할 것을 버리고, 몸소 이루어야 할 것을 이루어 수행을 마쳤다. 주석은 이를 살아야 할 수행의 삶을 다 살았다는 뜻으로도 풀이한다. 깊이 밴 번뇌를 다하는 지혜로 고요함에 이르렀기에 성자다. 모든 번뇌를 끝내는 아라한도의 앎을 얻고 청정한 삶을 다 살아, 이루어야 할 일을 모두 마친 이를 나는 바라문이라 부른다.

[^r3-05]: 스물여섯 갈래 천상은 욕계의 여섯 하늘, 색계의 열여섯 세계, 무색계의 네 세계다. 네 악처는 지옥, 짐승의 세계, 아귀 세계, 아수라 세계다. [《아비담맛타상가하》 제5장 〈네 가지 세계〉](https://epitaka.org/en/book/Abhidh-s/bh%C5%ABmicatukka%E1%B9%83-381)
[^r3-04]: 천안은 맨눈으로 볼 수 없는 중생의 죽음과 다시 태어남을 보는 앎이다.

```original
Tassattho – yo pubbenivāsaṃ pākaṭaṃ katvā jānāti, chabbīsatidevalokabhedaṃ saggañca catubbidhaṃ apāyañca dibbacakkhunā passati, atho jātikkhayasaṅkhātaṃ arahattaṃ patto, abhiññeyyaṃ  dhammaṃ abhijānitvā pariññeyyaṃ parijānitvā pahātabbaṃ pahāya sacchikātabbaṃ sacchikatvā vosiko niṭṭhānaṃ patto, vusitavosānaṃ vā patto, āsavakkhayapaññāya monabhāvaṃ pattattā muni, tamahaṃ sabbesaṃ kilesānaṃ vosānaṃ arahattamaggañāṇaṃ brahmacariyavāsaṃ vutthabhāvena sabbavositavosānaṃ brāhmaṇaṃ vadāmīti.
```

<a id="cscd-26-40-u003-p002"></a>

설법이 끝나자 많은 이가 예류과 등의 과를 얻었다. 데와히따도 맑은 믿음이 일어나 귀의하고 재가 신자가 되겠다고 밝혔다.

```original
Desanāvasāne  bahū sotāpattiphalādīni pāpuṇiṃsu. Brāhmaṇopi pasannamānaso saraṇesu patiṭṭhāya upāsakattaṃ pavedesīti.
```

<a id="cscd-26-40-u003-e001"></a>

데와히따 바라문 이야기, 마흔째.

```original
Devahitabrāhmaṇavatthu cattālīsaṃ.
```

<a id="cscd-26-40-u003-e002"></a>

바라문의 품에 대한 풀이가 끝났다.

```original
Brāhmaṇavaggavaṇṇanā niṭṭhitā.
```

<a id="cscd-26-40-u003-e003"></a>

제26품.

```original
Chabbīsatimo vaggo.
```
