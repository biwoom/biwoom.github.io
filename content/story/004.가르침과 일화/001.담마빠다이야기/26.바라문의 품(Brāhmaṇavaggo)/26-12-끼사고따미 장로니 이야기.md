# 26-12 끼사고따미 장로니 이야기
원문서명: 담마빠다 주석서(Dhammapada-aṭṭhakathā) | 저자: 미확정 | 출처: 《담마빠다 주석서》 제2부, VRI CSCD 로마자 XML 19533–19565행

- **품** · 제26품 바라문의 품(Brāhmaṇavaggo)
- **빨리어 표제** · Kisāgotamīvatthu
- **게송** · 제395게
- **요약** · 끼사고따미가 영축산에서 스승께 예를 올리고 돌아서자 삭까가 그가 누구인지 물었다. 스승께서는 그가 버려진 천으로 지은 가사를 입는 장로니 가운데 으뜸이라고 말씀하셨다.
- **핵심어** · 끼사고따미, 삭까, 영축산, 분소의, 선정
- **평행문헌** · 08-13 끼사고따미 이야기

<a id="cscd-26-12-u001"></a>
## 삭까가 스승께 예를 올리고 돌아서는 장로니를 보다

<a id="cscd-26-12-u001-e001"></a>

```original
12. Kisāgotamīvatthu
```

<a id="cscd-26-12-u001-p001"></a>

스승께서는 영축산에 머무실 때 끼사고따미를 두고 ‘분소의를 입고’[^r3-01]로 시작하는 이 법문을 설하셨다.

[^r3-01]: 분소의는 버려진 천을 거두어 씻고 지은 가사다. 《청정도론》은 길에 떨어진 천 조각 등을 거두어 헤진 부분을 떼고 가사를 짓는다고 설명한다. [《청정도론》 제2장](https://epitaka.org/en/book/Vism-i/1.-pa%E1%B9%83suk%C5%ABlika%E1%B9%85gakath%C4%81-438)

```original
Paṃsukūladharanti imaṃ dhammadesanaṃ satthā gijjhakūṭe pabbate viharanto kisāgotamiṃ ārabbha kathesi.
```

<a id="cscd-26-12-u001-p002"></a>

그날 밤 초야가 끝날 무렵, 삭까는 천신들을 거느리고 스승께 와서 예를 올렸다. 그는 한쪽에 앉아 기억에 새길 만한 법 이야기를 듣고 있었다고 한다. 그때 끼사고따미가 스승을 뵈려고 허공을 가로질러 왔다. 삭까를 발견한 그는 스승께 예를 올리고 돌아섰다. 이를 본 삭까가 “존자시여, 다가와 세존을 뵙고 돌아서는 저분은 누구입니까?” 하고 여쭈었다. 스승께서는 “대왕이여, 내 딸 끼사고따미다. 분소의를 입는 장로니들 가운데 으뜸이다[^r3-02]”라고 하시고 이 게송을 읊으셨다.

[^r3-02]: 《앙굿따라 니까야》 1.246은 끼사고따미를 ‘거친 가사를 입는 이들’ 가운데 으뜸으로 든다. 그 경의 주석은 ‘거친 가사’를 분소의로 풀어 이 이야기의 표현과 이어 준다. [《앙굿따라 니까야》 1.246](https://epitaka.org/en/book/A-i/5-pa%C3%B1camavaggo-218) · [《앙굿따라 니까야 주석》 〈끼사고따미 장로니〉](https://epitaka.org/lo/book/Mp-i/kis%C4%81gotam%C4%ABther%C4%ABvatthu-1156)

```original
Tadā  kira sakko paṭhamayāmāvasāne devaparisāya saddhiṃ satthāraṃ upasaṅkamitvā vanditvā ekamante sāraṇīyadhammakathaṃ suṇanto nisīdi. Tasmiṃ khaṇe kisāgotamī ‘‘satthāraṃ passissāmī’’ti ākāsenāgantvā sakkaṃ disvā nivatti. So taṃ vanditvā nivattantiṃ disvā satthāraṃ pucchi – ‘‘kā nāmesā, bhante, āgacchamānāva tumhe disvā nivattatī’’ti? Satthā ‘‘kisāgotamī nāmesā, mahārāja, mama dhītā paṃsukūlikattherīnaṃ aggā’’ti vatvā imaṃ gāthamāha –
```

<a id="cscd-26-12-u002"></a>
## 제395게와 분소의를 입고 숲에 홀로 앉는 이

<a id="cscd-26-12-u002-v001"></a>

<pali-poem>

> **제395게**  
> 분소의를 입고, 몸이 여위어 핏줄이 드러나며,[^r3-03]  
> 한적한 숲에서 홀로 선정에 드는 이,[^r3-04]  
> 나는 그를 바라문이라 부른다.

[^r3-04]: 《간다라 담마빠다》 제38게도 분소의를 입어 몸이 여위고 핏줄이 드러난 이를 들며, 그가 나무 아래서 선정에 든다고 한다. [《간다라 담마빠다》 제38게](https://ancient-buddhist-texts.net/Buddhist-Texts/C3-Comparative-Dhammapada/CD-26-Brahmana.htm)
[^r3-03]: 끼사(kisā)는 ‘여윈’이라는 뜻이다. 《앙굿따라 니까야 주석》도 몸이 여위어서 고따미에게 ‘끼사’가 붙었다고 풀이한다. [《앙굿따라 니까야 주석》 〈끼사고따미 장로니〉](https://epitaka.org/lo/book/Mp-i/kis%C4%81gotam%C4%ABther%C4%ABvatthu-1156)

```original
395.
‘‘Paṃsukūladharaṃ jantuṃ, kisaṃ dhamanisanthataṃ;
Ekaṃ vanasmiṃ jhāyantaṃ, tamahaṃ brūmi brāhmaṇa’’nti.
```

</pali-poem>

<a id="cscd-26-12-u002-p001"></a>

분소의를 입는 이들은 자신에게 알맞은 수행을 온전히 닦으며 살과 피가 적어지고 몸에 핏줄이 드러난다. 그래서 ‘여위어 핏줄이 드러나며’라고 했다. 그런 몸으로 한적한 숲에서 홀로 선정에 드는 이를 나는 바라문이라 부른다.

```original
Tattha kisanti paṃsukūlikā hi attano anurūpaṃ paṭipadaṃ pūrentā appamaṃsalohitā ceva honti  dhamanisanthatagattā ca, tasmā evamāha. Ekaṃ vanasminti vivittaṭṭhāne ekakaṃ vanasmiṃ jhāyantaṃ tamahaṃ brāhmaṇaṃ vadāmīti attho.
```

<a id="cscd-26-12-u002-p002"></a>

설법이 끝나자 많은 이가 예류과를 비롯한 성취를 얻었다.

```original
Desanāvasāne bahū sotāpattiphalādīni pāpuṇiṃsūti.
```

<a id="cscd-26-12-u002-e001"></a>

끼사고따미 장로니 이야기, 열두째.

```original
Kisāgotamīvatthu dvādasamaṃ.
```
