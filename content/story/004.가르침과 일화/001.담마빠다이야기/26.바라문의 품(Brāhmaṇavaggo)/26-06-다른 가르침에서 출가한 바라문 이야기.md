# 26-06 다른 가르침에서 출가한 바라문 이야기
원문서명: 담마빠다 주석서(Dhammapada-aṭṭhakathā) | 저자: 미확정 | 출처: 《담마빠다 주석서》 제2부, VRI CSCD 로마자 XML 19249–19281행

- **품** · 제26품 바라문의 품(Brāhmaṇavaggo)
- **빨리어 표제** · Aññatarabrāhmaṇapabbajitavatthu
- **게송** · 제388게
- **요약** · 다른 가르침에서 출가한 바라문이 자신도 출가자라 불릴 수 있는지 여쭈었다. 스승께서는 악을 물리치는 일과 가라앉히는 일, 자기 안의 때를 내보내는 일을 들어 바라문·사문·출가자의 뜻을 풀이하셨다.
- **핵심어** · 바라문, 사문, 출가자, 번뇌의 때, 예류과

<a id="cscd-26-06-u001"></a>
## 바라문이 출가자의 뜻을 묻다

<a id="cscd-26-06-u001-e001"></a>

```original
6. Aññatarabrāhmaṇapabbajitavatthu
```

<a id="cscd-26-06-u001-p001"></a>

스승께서는 제따와나에 머무실 때 출가한 한 바라문을 두고 ‘악을 물리쳤으므로’로 시작하는 이 법문을 설하셨다.

```original
Bāhitapāpoti imaṃ dhammadesanaṃ satthā jetavane viharanto aññataraṃ brāhmaṇapabbajitaṃ ārabbha kathesi.
```

<a id="cscd-26-06-u001-p002"></a>

한 바라문은 다른 가르침을 따라 출가한 뒤 생각했다. ‘사문 고따마는 제자들을 출가자라 부른다. 나도 출가했으니 나도 그렇게 부를 만하지 않은가.’ 그는 스승께 다가가 그렇게 여쭈었다. 스승께서는 “나는 집을 떠난 것만으로 출가자라 부르지 않는다. 번뇌의 때를 내보낸 이를 출가자라 부른다”라고 말씀하시고 이 게송을 읊으셨다.

```original
Eko kira brāhmaṇo bāhirakapabbajjāya pabbajitvā ‘‘samaṇo gotamo attano sāvake ‘pabbajitā’ti vadati, ahañcamhi  pabbajito, mampi kho evaṃ vattuṃ vaṭṭatī’’ti cintetvā satthāraṃ upasaṅkamitvā etamatthaṃ pucchi. Satthā ‘‘nāhaṃ ettakena ‘pabbajito’ti vadāmi, kilesamalānaṃ pana pabbājitattā pabbajito nāma hotī’’ti vatvā imaṃ gāthamāha –
```

<a id="cscd-26-06-u002"></a>
## 제388게와 악과 때를 몰아내는 일

<a id="cscd-26-06-u002-v001"></a>

<pali-poem>

> **제388게**  
> 악을 물리쳤으므로 바라문이라 부르고,  
> 악을 가라앉혀 살아가므로 사문이라 부른다.[^r3-01]  
> 자기 안의 때를 내보내므로  
> 그를 출가자라 부른다.[^r3-02]

[^r3-01]: 〈큰 앗사뿌라 경〉에서도 악하고 불선한 것을 물리쳤기에 바라문, 가라앉혔기에 사문이라고 한다. [《맛지마 니까야》 39](https://dhammatalks.net/suttacentral/sc2016/sc/pi/mn39.html)
[^r3-02]: 게송은 ‘악을 물리친 이’(bāhitapāpa)를 바라문(brāhmaṇa), ‘악을 가라앉혀 살아감’(samacariyā)을 사문(samaṇa), ‘때를 내보냄’(pabbājaya)을 출가자(pabbajita)와 짝지어 풀이한다. 10-09의 제142게와 19-06의 제265게 풀이에도 앞의 두 연결이 각각 나온다. 《우다나바르가》에도 세 호칭과 같은 풀이를 짝짓는 게송이 있다. [《우다나바르가》 11.15](https://ancient-buddhist-texts.net/Buddhist-Texts/C3-Comparative-Dhammapada/CD-26-Brahmana.htm)

```original
388.
‘‘Bāhitapāpoti brāhmaṇo, samacariyā samaṇoti vuccati;
Pabbājayamattano malaṃ, tasmā pabbajitoti vuccatī’’ti.
```

</pali-poem>

<a id="cscd-26-06-u002-p001"></a>

‘악을 가라앉혀 살아가므로’는 모든 불선을 가라앉히고 살아간다는 뜻이다. 악을 물리쳤기에 바라문이라 부르고, 불선을 가라앉혀 살아가기에 사문이라 부른다. 그와 같이 자기 안의 탐욕 따위의 때를 없애며 살아가는 사람을, 그 때를 내보냈다는 뜻에서 출가자라고 부른다.

```original
Tattha samacariyāti sabbākusalāni sametvā caraṇena. Tasmāti yasmā bāhitapāpatāya brāhmaṇo, akusalāni sametvā caraṇena samaṇoti vuccati, tasmā yo attano rāgādimalaṃ pabbājayanto vinodento carati, sopi tena pabbājanena pabbajitoti vuccatīti attho.
```

<a id="cscd-26-06-u002-p002"></a>

설법이 끝나자 출가한 바라문은 예류과를 얻었고, 모인 이들도 법문에서 이로움을 얻었다.

```original
Desanāvasāne so brāhmaṇapabbajito sotāpattiphale patiṭṭhahi, sampattānampi sātthikā dhammadesanā ahosīti.
```

<a id="cscd-26-06-u002-e001"></a>

다른 가르침에서 출가한 바라문 이야기, 여섯째.

```original
Aññatarabrāhmaṇapabbajitavatthu chaṭṭhaṃ.
```
