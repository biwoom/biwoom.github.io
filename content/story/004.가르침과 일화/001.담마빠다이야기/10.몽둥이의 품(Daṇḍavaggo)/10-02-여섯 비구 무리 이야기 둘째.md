# 10-02 여섯 비구 무리 이야기 둘째
원문서명: 담마빠다 주석서(Dhammapada-aṭṭhakathā) | 저자: 미확정 | 출처: 《담마빠다 주석서》 제2부, VRI CSCD 로마자 XML 8881–8913행

- **품** · 제10품 몽둥이의 품(Daṇḍavaggo)
- **빨리어 표제** · Chabbaggiyabhikkhuvatthu
- **게송** · 제130게
- **요약** · 앞서 열일곱 비구를 때렸던 여섯 비구는 같은 거처 문제로 이번에는 손을 들어 위협한다. 스승께서는 때리려는 몸짓으로 위협하는 일을 금하시고, 남도 자기처럼 목숨을 소중히 여긴다고 설하신다.
- **핵심어** · 여섯 비구 무리, 열일곱 비구 무리, 학습계목, 바일제, 위협, 생명, 평정
- **평행문헌** · [《율장》 비구 바일제 제75조](https://thebuddhaswords.net/vi/bu-vb-pc75.html) · [빠뜨나 《다르마빠다》 제202게](https://ancient-buddhist-texts.net/Buddhist-Texts/C5-Patna/12-Danda.htm) · [《우다나바르가》 5.19](https://ancient-buddhist-texts.net/Buddhist-Texts/S1-Udanavarga/05-Priya.htm)

<a id="cscd-10-02-u001"></a>
## 때리려는 몸짓으로 위협하다

<a id="cscd-10-02-u001-e001"></a>

```original
2. Chabbaggiyabhikkhuvatthu
```

<a id="cscd-10-02-u001-p001"></a>

스승께서는 제따와나에 머무실 때 여섯 비구 무리를 두고 ‘모두 몽둥이 앞에서 떤다’로 시작하는 이 법문을 설하셨다.

```original
Sabbe tasantīti imaṃ dhammadesanaṃ satthā jetavane viharanto chabbaggiye bhikkhū ārabbha kathesi.
```

<a id="cscd-10-02-u001-p002"></a>

여섯 비구는 앞서 거처를 두고 다투다가 열일곱 비구 무리를 때렸다. 그 일로 때리는 행위를 금하는 학습계목이 제정되었다. 이번에는 같은 거처 문제로 열일곱 비구를 때릴 듯 손을 들어 위협했다.

```original
Teyeva  ekasmiñhi samaye teneva kāraṇena purimasikkhāpade sattarasavaggiye pahariṃsu. Teneva kāraṇena tesaṃ talasattikaṃ uggiriṃsu.
```

<a id="cscd-10-02-u001-p003"></a>

이번에도 스승께서는 열일곱 비구가 소리치는 것을 듣고 “무슨 일이냐?”라고 물으셨다. 비구들이 무슨 일이 있었는지 아뢰자 스승께서는 “비구들이여, 이제부터 비구는 그렇게 해서는 안 된다. 그렇게 하면 그에 해당하는 허물을 범한다”라고 하시며, 때리려는 몸짓으로 위협하는 일을 금하는 학습계목을 제정하셨다[^r3-01]. (원문 출전 CSCD 《율장》 〈바일제〉 454 이하)

[^r3-01]: 비구 바일제 제75조는 성이 나서 다른 비구를 위협하려고 몸의 일부나 몸에 지니거나 손에 든 물건을 치켜드는 경우에 적용된다. 율장은 손에 든 것이 연잎 한 장인 경우까지 예로 들고, 괴롭힘에서 벗어나려고 방어하는 몸짓은 예외로 둔다. [《율장》 비구 바일제 제75조](https://thebuddhaswords.net/vi/bu-vb-pc75.html)

```original
Idhāpi satthā tesaṃ saddaṃ sutvā ‘‘kiṃ ida’’nti pucchitvā ‘‘idaṃ nāmā’’ti ārocite ‘‘na, bhikkhave, ito paṭṭhāya bhikkhunā nāma evaṃ kattabbaṃ, yo karoti, so imaṃ nāma āpattiṃ āpajjatī’’ti talasattikasikkhāpadaṃ (pāci. 454 ādayo) paññāpetvā,
```

<a id="cscd-10-02-u001-p004"></a>

스승께서는 “비구들이여, 비구는 ‘나처럼 다른 이들도 몽둥이 앞에서 떨고, 그들에게도 자기 목숨은 소중하다’고 헤아려 남을 때리거나 죽여서는 안 된다”라고 하셨다. 이렇게 이야기를 이어 법을 설하시며 이 게송을 말씀하셨다.

```original
‘‘bhikkhave, bhikkhunā nāma ‘yathā ahaṃ, tatheva aññepi daṇḍassa tasanti, yathā ca mayhaṃ, tatheva nesaṃ jīvitaṃ piya’nti ñatvā paro na paharitabbo na ghāṭetabbo’’ti vatvā anusandhiṃ ghaṭetvā dhammaṃ desento imaṃ gāthamāha –
```

<a id="cscd-10-02-u002"></a>
## 제130게와 모두에게 소중한 생명

<a id="cscd-10-02-u002-v001"></a>

<pali-poem>

> **제130게**  
> 모두 몽둥이 앞에서 떨고,  
> 모두에게 목숨은 소중하다.  
> 다른 이도 나와 같음을 헤아려  
> 해치지도, 남을 시켜 해치지도 마라.

```original
130.
‘‘Sabbe tasanti daṇḍassa, sabbesaṃ jīvitaṃ piyaṃ;
Attānaṃ upamaṃ katvā, na haneyya na ghātaye’’ti.
```

</pali-poem>

<a id="cscd-10-02-u002-p001"></a>

‘모두에게 목숨은 소중하다’는 것은 번뇌가 다한 이를 제외한 나머지 중생이 저마다 자기 목숨을 소중히 여기고 삶을 달게 느낀다는 뜻이다. 번뇌가 다한 이는 삶에도 죽음에도 마음이 기울지 않는다.[^r3-02] 나머지는 앞의 제129게 풀이와 같다.

[^r3-02]: 주석에서 말하는 평정(upekkhā)은 삶이나 죽음 어느 한쪽에도 집착하지 않는 태도다. 《테라가타》에서 사리뿟따 장로는 삶도 죽음도 반기지 않고 때를 기다린다고 노래한다. [《테라가타》 17.2](https://dhammatalks.net/suttacentral/sc2016/sc/pi/thag17.2.html)

```original
Tattha sabbesaṃ jīvitaṃ piyanti khīṇāsavaṃ ṭhapetvā sesasattānaṃ jīvitaṃ piyaṃ madhuraṃ, khīṇāsavo pana jīvite vā maraṇe vā upekkhakova hoti. Sesaṃ purimasadisamevāti.
```

<a id="cscd-10-02-u002-p002"></a>

설법이 끝나자 많은 사람이 예류과를 비롯한 성취를 얻었다.

```original
Desanāvasāne bahū sotāpattiphalādīni pāpuṇiṃsūti.
```

<a id="cscd-10-02-u002-e001"></a>

