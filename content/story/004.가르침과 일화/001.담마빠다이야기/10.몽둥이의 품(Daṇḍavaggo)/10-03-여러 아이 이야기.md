# 10-03 여러 아이 이야기
원문서명: 담마빠다 주석서(Dhammapada-aṭṭhakathā) | 저자: 미확정 | 출처: 《담마빠다 주석서》 제2부, VRI CSCD 로마자 XML 8917–8961행

- **품** · 제10품 몽둥이의 품(Daṇḍavaggo)
- **빨리어 표제** · Sabbahulakumārakavatthu
- **게송** · 제131–132게
- **요약** · 아이들이 물릴까 두려워 뱀을 막대기로 때린다. 스승께서는 다른 중생도 행복을 바란다고 일러 주시고, 제 행복을 위해 남을 괴롭히는 일과 괴롭히지 않는 일이 가져올 결과를 설하신다.
- **핵심어** · 아이들, 뱀, 막대기, 행복, 내생, 예류과
- **평행문헌** · [《우다나》 2.3 〈몽둥이 경〉](https://www.dhammatalks.net/suttacentral/sc2016/sc/pi/ud2.3.html) · [빠뜨나 《다르마빠다》 제203–204게](https://ancient-buddhist-texts.net/Buddhist-Texts/C5-Patna/12-Danda.htm) · [《우다나바르가》 30.3–4](https://ancient-buddhist-texts.net/Buddhist-Texts/S1-Udanavarga/30-Sukha.htm)

<a id="cscd-10-03-u001"></a>
## 아이들이 두려움에 뱀을 때리다

<a id="cscd-10-03-u001-e001"></a>

```original
3. Sabbahulakumārakavatthu
```

<a id="cscd-10-03-u001-p001"></a>

스승께서는 제따와나에 머무실 때 여러 아이를 두고 ‘행복을 바라는 중생을’로 시작하는 이 법문을 설하셨다.

```original
Sukhakāmāni  bhūtānīti imaṃ dhammadesanaṃ satthā jetavane viharanto sambahule kumārake ārabbha kathesi.
```

<a id="cscd-10-03-u001-p002"></a>

어느 날 스승께서 탁발하러 사왓티로 가시는 길에 아이들이 집 주변에 사는 뱀 한 마리를 막대기로 때리는 모습[^r3-01]을 보셨다. “아이들아, 무엇을 하느냐?”라고 물으시니 “존자시여, 뱀을 막대기로 때리고 있습니다”라고 답했다. “무슨 까닭이냐?”라고 다시 물으시니 “존자시여, 물릴까 봐 무섭습니다”라고 했다.

[^r3-01]: 〈몽둥이 경〉에는 아이들이 사왓티와 제따와나 사이에서 뱀을 때리는 모습과 제131·132게가 나온다. 아이들이 물릴까 두려웠다고 대답한 일은 《담마빠다 주석서》와 《우다나》 주석이 전한다. [《우다나》 2.3](https://www.dhammatalks.net/suttacentral/sc2016/sc/pi/ud2.3.html) · [《우다나》 2.3 주석](https://epitaka.org/en/book/Ud-a/3.-da%E1%B9%87%E1%B8%8Dasuttava%E1%B9%87%E1%B9%87an%C4%81-382)

```original
Ekasmiñhi  samaye satthā sāvatthiyaṃ piṇḍāya pavisanto antarāmagge sambahule kumārake ekaṃ gharasappajātikaṃ ahiṃ daṇḍakena paharante disvā ‘‘kumārakā kiṃ karothā’’ti pucchitvā ‘‘ahiṃ, bhante, daṇḍakena paharāmā’’ti vutte ‘‘kiṃ kāraṇā’’ti puna pucchitvā ‘‘ḍaṃsanabhayena, bhante’’ti vutte
```

<a id="cscd-10-03-u001-p003"></a>

스승께서 말씀하셨다. “너희가 편안해지려고 이 뱀을 때린다면, 어디에 다시 태어나든 행복을 얻지 못할 것이다. 자기 행복을 바라는 이는 다른 중생을 때려서는 안 된다.” 스승께서는 이렇게 이야기를 이어 법을 설하시며 이 게송들을 읊으셨다.

```original
‘‘tumhe ‘attano sukhaṃ karissāmā’ti imaṃ paharantā nibbattanibbattaṭṭhāne sukhalābhino na bhavissatha. Attano sukhaṃ patthentena hi paraṃ paharituṃ na vaṭṭatī’’ti vatvā anusandhiṃ ghaṭetvā dhammaṃ desento imā gāthā abhāsi –
```

<a id="cscd-10-03-u002"></a>
## 제131·132게와 행복을 바라는 중생

<a id="cscd-10-03-u002-v001"></a>

<pali-poem>

> **제131게**  
> 행복을 바라는 중생을  
> 제 행복을 바라며 몽둥이로 괴롭히는 이는  
> 죽은 뒤  
> 행복을 얻지 못한다.

```original
131.
‘‘Sukhakāmāni bhūtāni, yo daṇḍena vihiṃsati;
Attano sukhamesāno, pecca so na labhate sukhaṃ.
```

</pali-poem>

<a id="cscd-10-03-u002-v002"></a>

<pali-poem>

> **제132게**  
> 행복을 바라는 중생을  
> 제 행복을 바라며 몽둥이로 괴롭히지 않는 이는  
> 죽은 뒤  
> 행복을 얻는다.

```original
132.
‘‘Sukhakāmāni bhūtāni, yo daṇḍena na hiṃsati;
Attano sukhamesāno, pecca so labhate sukha’’nti.
```

</pali-poem>

<a id="cscd-10-03-u002-p001"></a>

‘몽둥이로 괴롭히는 이’는 몽둥이나 흙덩이 따위로 남을 괴롭히는 사람이다. ‘죽은 뒤 행복을 얻지 못한다’는 것은 다음 생에 사람으로서의 행복도, 천상의 행복도, 궁극의 행복인 열반[^r3-02]도 얻지 못한다는 뜻이다. 둘째 게송의 ‘죽은 뒤 행복을 얻는다’도 같은 세 가지 행복을 두고 한 말이다.

[^r3-02]: 《우다나》 주석도 사람으로서의 행복, 천상의 행복, 열반의 행복을 함께 든다. 앞의 두 가지는 각각의 삶에서 누리는 행복을 가리킨다. 열반의 행복은 괴로움의 소멸을 가리킨다. 〈열반의 행복 경〉에서 사리뿟따는 느껴지는 것이 없다는 바로 그 점에서 열반이 행복하다고 설명한다. [《우다나》 2.3 주석](https://epitaka.org/en/book/Ud-a/3.-da%E1%B9%87%E1%B8%8Dasuttava%E1%B9%87%E1%B9%87an%C4%81-382) · [《앙굿따라 니까야》 9.34](https://dhammatalks.net/suttacentral/sc2016/sc/pi/an9.34.html)

```original
Tattha yo daṇḍenāti yo puggalo daṇḍena vā leḍḍuādīhi vā viheṭheti. Pecca so na labhate sukhanti so puggalo paraloke manussasukhaṃ vā dibbasukhaṃ vā paramatthabhūtaṃ vā nibbānasukhaṃ na labhati. Dutiyagāthāya pecca so labhateti so puggalo paraloke vuttappakāraṃ tividhampi sukhaṃ labhatīti attho.
```

<a id="cscd-10-03-u002-p002"></a>

설법이 끝나자 아이들은 오백 명 모두 예류과를 얻었다.

```original
Desanāvasāne pañcasatāpi te kumārakā sotāpattiphale patiṭṭhahiṃsūti.
```

<a id="cscd-10-03-u002-e001"></a>

여러 아이 이야기, 셋째.

```original
Sambahulakumārakavatthu tatiyaṃ.
```
