# 19-06 논쟁에서 이겼다고 떠벌린 핫타까 이야기
원문서명: 담마빠다 주석서(Dhammapada-aṭṭhakathā) | 저자: 미확정 | 출처: 《담마빠다 주석서》 제2부, VRI CSCD 로마자 XML 14449–14493행

- **품** · 제19품 법에 따라 사는 이의 품(Dhammaṭṭhavaggo)
- **빨리어 표제** · Hatthakavatthu
- **게송** · 제264·265게
- **요약** · 핫타까는 다른 교단 사람들과 논쟁을 약속한 뒤 먼저 가서, 상대가 겁을 먹고 오지 않았다고 거짓말한다. 스승께서는 크고 작은 악을 가라앉힌 사람을 사문이라 부르신다.
- **핵심어** · 핫타까, 논쟁, 거짓말, 사문, 계행, 두타행, 탐욕

<a id="cscd-19-06-u001"></a>
## 핫타까가 상대를 만나기도 전에 이겼다고 말하다

<a id="cscd-19-06-u001-e001"></a>

```original
6. Hatthakavatthu
```

<a id="cscd-19-06-u001-p001"></a>

스승께서는 사왓티에 머무실 때 핫타까를 두고 ‘머리를 깎았다고 해서’로 시작하는 이 법문을 설하셨다.

```original
Na  muṇḍakena samaṇoti imaṃ dhammadesanaṃ satthā sāvatthiyaṃ viharanto hatthakaṃ ārabbha kathesi.
```

<a id="cscd-19-06-u001-p002"></a>

논쟁에 빠진 핫타까는 다른 교단 수행자들에게 “정한 시각에 정한 곳으로 오시오. 거기서 논쟁합시다” 하고 약속을 잡곤 했다. 그러고는 약속 시각보다 먼저 가서 “보시오. 다른 교단 사람들은 내가 무서워서 오지 않았소. 이것만 봐도 진 건 그들이오”라고 말했다. 그는 이처럼 논쟁에 매달려 말을 이리저리 바꾸며 둘러댔다.

```original
So kira vādakkhitto ‘‘tumhe asukavelāya asukaṭṭhānaṃ nāma āgaccheyyātha, vādaṃ karissāmā’’ti vatvā puretarameva tattha gantvā ‘‘passatha, titthiyā mama bhayena nāgatā, esova pana nesaṃ parājayo’’tiādīni vatvā vādakkhitto aññenaññaṃ paṭicaranto vicarati.
```

<a id="cscd-19-06-u001-p003"></a>

스승께서는 이 일을 들으시고 핫타까를 불러 물으셨다. “핫타까여, 그대가 그렇게 한다는 말이 사실이냐?” 핫타까가 그렇다고 하자 스승께서 말씀하셨다. “어찌 그렇게 하느냐? 그런 거짓말을 하는 사람[^r3-01]이 머리를 깎았다고 해서 사문이 되는 것은 아니다. 작든 크든 온갖 악을 가라앉히고 사는 이가 사문이다.” 그러고는 이 게송들을 읊으셨다.

[^r3-01]: 《율장》의 인연담은 핫타까를 사끼야족 출신 비구로 소개한다. 거기에서도 그는 다른 교단 수행자들과 논쟁하다 말을 뒤집거나 다른 말로 둘러대고, 알고도 거짓말하며 약속을 어긴다. 이 일을 계기로 비구가 알고도 거짓말하면 바일제에 해당한다는 학습계목이 정해진다. [《율장》 비구 바일제 제1조](https://dhammatalks.net/suttacentral/sc2016/sc/pi/pi-tv-bu-vb-pc1.html)

```original
Satthā ‘‘hatthako kira evaṃ karotī’’ti sutvā taṃ pakkosāpetvā ‘‘saccaṃ  kira tvaṃ, hatthaka, evaṃ karosī’’ti pucchitvā ‘‘sacca’’nti vutte, ‘‘kasmā evaṃ karosi? Evarūpañhi musāvādaṃ karonto sīsamuṇḍanādimatteneva samaṇo nāma na hoti. Yo pana aṇūni vā thūlāni vā pāpāni sametvā ṭhito, ayameva samaṇo’’ti vatvā imā gāthā abhāsi –
```

<a id="cscd-19-06-u002"></a>
## 제264·265게와 악을 가라앉힌 사문

<a id="cscd-19-06-u002-v001"></a>

<pali-poem>

> **제264게**  
> 머리를 깎았다고 해서 사문이 되는 것은 아니다.  
> 지키는 규율도 없이 거짓말하며 욕구와 탐욕에 빠진 이가 어찌 사문이겠는가?

```original
264.
‘‘Na muṇḍakena samaṇo, abbato alikaṃ bhaṇaṃ;
Icchālobhasamāpanno, samaṇo kiṃ bhavissati.
```

</pali-poem>

<a id="cscd-19-06-u002-v002"></a>

<pali-poem>

> **제265게**  
> 크고 작은 악을 남김없이 가라앉히는 이,  
> 그렇게 악을 가라앉혔기에 사문이라 불린다.[^r3-02]

[^r3-02]: 게송은 “가라앉히다”(sameti)와 “사문”(samaṇa)의 비슷한 소리를 이어 사문이라는 이름의 뜻을 풀이한다. 빠뜨나 《다르마빠다》 제236게에도 같은 풀이가 나온다. [제265게와 평행 게송 대조](https://ancient-buddhist-texts.net/Buddhist-Texts/C3-Comparative-Dhammapada/CD-19-Dhammattha.htm)

```original
265.
‘‘Yo ca sameti pāpāni, aṇuṃ thūlāni sabbaso;
Samitattā hi pāpānaṃ, samaṇoti pavuccatī’’ti.
```

</pali-poem>

<a id="cscd-19-06-u002-p001"></a>

머리를 깎았다는 것만으로 사문이 되지는 않는다. ‘지키는 규율도 없이’는 계행과 두타행의 실천[^r3-03]을 갖추지 못했다는 뜻이다. 거짓말을 하고, 아직 얻지 못한 것은 바라며 이미 얻은 것에는 탐욕을 품는 이를 어찌 사문이라 하겠는가? 작든 크든 악을 모두 가라앉힌 이를 사문이라 부른다.

[^r3-03]: 두타행은 생활을 간소하게 하여 번뇌를 덜어 내는 수행이다. 《청정도론》 제2장은 버려진 천으로 만든 가사만 입기, 탁발 음식으로 지내기, 숲에 머물기 등을 포함해 열세 가지를 든다. [《청정도론》의 두타행 빨리어 원문](https://gretil.sub.uni-goettingen.de/gretil/2_pali/4_comm/buvismpu.htm)

```original
Tattha muṇḍakenāti sīsamuṇḍanamattena. Abbatoti sīlavatena ca dhutaṅgavatena ca virahito. Alikaṃ bhaṇanti musāvādaṃ bhaṇanto asampattesu ārammaṇesu icchāya pattesu ca lobhena samannāgato samaṇo nāma kiṃ bhavissati? Sametīti yo ca parittāni vā  mahantāni vā pāpāni vūpasameti, so tesaṃ samitattā samaṇoti pavuccatīti attho.
```

<a id="cscd-19-06-u002-p002"></a>

설법이 끝나자 많은 이가 예류과를 비롯한 성취를 얻었다.

```original
Desanāvasāne bahū sotāpattiphalādīni pāpuṇiṃsūti.
```

<a id="cscd-19-06-u002-e001"></a>

핫타까 이야기, 여섯째.

```original
Hatthakavatthu chaṭṭhaṃ.
```
