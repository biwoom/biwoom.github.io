# 19-09 낚시꾼 아리야 이야기
원문서명: 담마빠다 주석서(Dhammapada-aṭṭhakathā) | 저자: 미확정 | 출처: 《담마빠다 주석서》 제2부, VRI CSCD 로마자 XML 14597–14629행

- **품** · 제19품 법에 따라 사는 이의 품(Dhammaṭṭhavaggo)
- **빨리어 표제** · Bālisikavatthu
- **게송** · 제270게
- **요약** · 스승께서 제자들의 이름을 차례로 물으신 뒤 한 낚시꾼에게도 이름을 물으신다. 낚시꾼이 ‘성스러운 이’를 뜻하는 아리야라고 답하자, 스승께서는 어떤 생명도 해치지 않는 이를 성스러운 이라 부르신다.
- **핵심어** · 아리야, 낚시, 사왓티, 해치지 않음, 자애, 성스러운 이

<a id="cscd-19-09-u001"></a>
## 낚시꾼이 스승께 자기 이름을 말하다

<a id="cscd-19-09-u001-e001"></a>

```original
9. Bālisikavatthu
```

<a id="cscd-19-09-u001-p001"></a>

스승께서는 제따와나에 머무실 때 아리야라는 낚시꾼을 두고 ‘생명을 해치는 이를’로 시작하는 이 법문을 설하셨다.

```original
Na tena ariyo hotīti imaṃ dhammadesanaṃ satthā jetavane viharanto ekaṃ ariyaṃ nāma bālisikaṃ ārabbha kathesi.
```

<a id="cscd-19-09-u001-p002"></a>

어느 날 스승께서는 낚시꾼에게 예류의 길에 이를 조건이 갖추어졌음을 보셨다. 사왓티 북문 마을에서 탁발하신 뒤 비구들과 함께 돌아오셨다. 물고기를 낚던 아리야는 붓다께서 이끄시는 비구 승가를 보고 낚싯대를 던져 놓고 서 있었다. 스승께서는 낚시꾼 가까이에서 돌아서서 사리뿟따 장로 등에게 “그대의 이름이 무엇인가?” 하고 물으셨다. 그들은 “저는 사리뿟따입니다”, “저는 목갈라나입니다” 하며 저마다 이름을 말씀드렸다.

```original
Ekadivasañhi  satthā tassa sotāpattimaggassūpanissayaṃ disvā sāvatthiyā uttaradvāragāme piṇḍāya caritvā bhikkhusaṅghaparivuto tato āgacchati. Tasmiṃ khaṇe so bālisiko balisena macche gaṇhanto buddhappamukhaṃ bhikkhusaṅghaṃ disvā balisayaṭṭhiṃ chaḍḍetvā aṭṭhāsi. Satthā tassa avidūre  ṭhāne nivattitvā ṭhito ‘‘tvaṃ kiṃ nāmosī’’ti sāriputtattherādīnaṃ nāmāni pucchi. Tepi ‘‘ahaṃ sāriputto ahaṃ moggallāno’’ti attano attano nāmāni kathayiṃsu.
```

<a id="cscd-19-09-u001-p003"></a>

낚시꾼은 생각했다. ‘스승께서 모두에게 이름을 물으시니 내 이름도 물으시겠구나.’ 스승께서는 그의 바람을 아시고 물으셨다. “재가 신자여, 그대 이름이 무엇인가?” “존자시여, 제 이름은 아리야입니다.” 스승께서는 “재가 신자여, 그대처럼 생명을 죽이는 이를 성스러운 이라 부르지 않는다. 성스러운 이들은 누구도 해치지 않는 삶을 굳게 지킨다” 하시고 이 게송을 읊으셨다.

```original
Bālisiko cintesi – ‘‘satthā sabbesaṃ nāmāni pucchati, mamampi nāmaṃ pucchissati maññe’’ti. Satthā tassa icchaṃ ñatvā, ‘‘upāsaka, tvaṃ ko nāmosī’’ti pucchitvā ‘‘ahaṃ, bhante, ariyo nāmā’’ti vutte ‘‘na, upāsaka, tādisā pāṇātipātino ariyā nāma honti, ariyā pana mahājanassa ahiṃsanabhāve ṭhitā’’ti vatvā imaṃ gāthamāha –
```

<a id="cscd-19-09-u002"></a>
## 제270게와 생명을 해치지 않는 이

<a id="cscd-19-09-u002-v001"></a>

<pali-poem>

> **제270게**  
> 생명을 해치는 이를 성스러운 이라 부르지 않는다.  
> 어떤 생명도 해치지 않는 이를 성스러운 이라 부른다.[^r3-01]

[^r3-01]: 낚시꾼의 이름 아리야(ariya)는 게송의 “성스러운 이”와 같은 빨리어다. 스승께서는 이 이름을 계기로 어떤 행실을 하는 이를 성스럽다고 부르는지 밝히신다.


```original
270.
‘‘Na tena ariyo hoti, yena pāṇāni hiṃsati;
Ahiṃsā sabbapāṇānaṃ, ariyoti pavuccatī’’ti.
```

</pali-poem>

<a id="cscd-19-09-u002-p001"></a>

생명을 해치는 이는 성스러운 이라 할 수 없다. 손으로든 다른 방법으로든 어떤 생명도 해치지 않고, 자애 같은 마음을 닦아[^r3-02] 남을 해치는 일에서 멀리 벗어난 이를 성스러운 이라 부른다는 뜻이다.

[^r3-02]: 〈자애 경〉은 어머니가 하나뿐인 아이를 목숨으로 지키듯 모든 생명을 향해 한량없는 마음을 닦으라고 한다. [《숫따니빠따》 1.8 〈자애 경〉](https://dhammatalks.net/suttacentral/sc2016/sc/pi/snp1.8.html)

```original
Tattha  ahiṃsāti ahiṃsanena. Idaṃ vuttaṃ hoti – yena hi pāṇāni hiṃsati, na tena kāraṇena ariyo hoti. Yo pana sabbapāṇānaṃ pāṇiādīhi ahiṃsanena mettādibhāvanāya patiṭṭhitattā hiṃsato ārāva ṭhito, ayaṃ ariyoti vuccatīti attho.
```

<a id="cscd-19-09-u002-p002"></a>

법문이 끝나자 낚시꾼은 예류과를 얻었다. 모인 이들도 법문에서 이로움을 얻었다.

```original
Desanāvasāne bālisiko sotāpattiphale patiṭṭhahi, sampattānampi sātthikā dhammadesanā ahosīti.
```

<a id="cscd-19-09-u002-e001"></a>

낚시꾼 이야기, 아홉째.

```original
Bālisikavatthu navamaṃ.
```
