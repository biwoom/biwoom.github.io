# 05-11-2 잠부까의 참회와 출가
원문서명: 담마빠다 주석서(Dhammapada-aṭṭhakathā) | 저자: 미확정 | 출처: 《담마빠다 주석서》 제1부, VRI CSCD 로마자 XML 5753–5821행

- **품** · 제5품 어리석은 이의 품(Bālavaggo)
- **빨리어 표제** · Jambukattheravatthu

<a id="cscd-05-11-u003"></a>
## 스승을 찾아온 사천왕과 삭까와 대범천

<a id="cscd-05-11-u003-p001"></a>

붓다들은 새벽에 세상을 살피는 일을 거르지 않는다. 어느 날 세존께서 새벽에 세상을 살피실 때 아지와까 잠부까가 앎의 그물에 들어왔다. 스승께서 ‘어떤 일이 일어날까?’ 하고 살피시니 그가 무애해[^r3-05]와 아라한과를 얻을 바탕을 갖추고 있었다. ‘이 사람을 계기로 게송 하나를 설하겠다. 게송이 끝나면 팔만 사천 중생이 법을 깨달을 것이다. 이 사람 덕분에 많은 이에게 이로움이 있을 것이다’라고 아셨다. 다음 날 라자가하에서 탁발하고 돌아오셔서 아난다 장로에게 “아난다여, 아지와까 잠부까에게 가겠다”라고 하셨다. “존자시여, 홀로 가시겠습니까?” “그렇다. 나 혼자 가겠다.” 그림자가 길어질 무렵 스승께서는 잠부까에게로 향하셨다.

[^r3-05]: 뜻과 가르침과 말, 그리고 앞의 세 가지를 풀이하는 데 막힘이 없는 네 가지 앎이다.

```original
Buddhānampi  kho paccūsakāle lokavolokanaṃ avijahitameva hoti. Tasmā ekadivasaṃ bhagavato paccūsasamaye lokaṃ volokentassa ayaṃ jambukājīvako ñāṇajālassa anto paññāyi. Satthā ‘‘kiṃ nu kho bhavissatī’’ti āvajjetvā tassa saha paṭisambhidāhi arahattassūpanissayaṃ disvā ‘‘ahaṃ etaṃ ādiṃ katvā ekaṃ gāthaṃ bhāsissāmi, gāthāvasāne caturāsītiyā pāṇasahassānaṃ dhammābhisamayo bhavissati. Imaṃ kulaputtaṃ nissāya mahājano sotthibhāvaṃ pāpuṇissatī’’ti ñatvā punadivase rājagahe piṇḍāya caritvā piṇḍapātapaṭikkanto ānandattheraṃ āmantesi – ‘‘ānanda, jambukājīvakassa santikaṃ gamissāmī’’ti. ‘‘Bhante, kiṃ tumheyeva gamissathā’’ti? ‘‘Āma, ahamevā’’ti evaṃ vatvā satthā vaḍḍhamānakacchāyāya tassa santikaṃ pāyāsi.
```

<a id="cscd-05-11-u003-p002"></a>

신들은 ‘스승께서 저녁에 잠부까에게 가시는데, 잠부까는 대소변과 이쑤시개로 더럽혀진 넓적바위에 산다. 비를 내려 그 바위를 씻어야겠다’라고 생각하고 그 자리에서 신통을 부려 비를 내렸다. 넓적바위가 티 없이 깨끗해지자 그 위에 다섯 빛깔의 꽃비를 내렸다. 스승께서 저녁에 이르러 “잠부까여” 하고 부르셨다. 잠부까는 ‘어떤 버릇없는 자가 나를 잠부까라고 함부로 부르는가’ 하고 생각하며 물었다. “누구시오?” “나는 수행자다.” “큰 수행자여, 무슨 일이오?” “오늘 밤 여기서 묵을 곳을 내주시오.” “큰 수행자여, 여기에는 묵을 곳이 없소.”

```original
Devatā cintayiṃsu – ‘‘satthā sāyaṃ jambukājīvakassa santikaṃ gacchati, so ca jegucche uccārapassāvadantakaṭṭhakiliṭṭhe piṭṭhipāsāṇe vasati, devaṃ vassāpetuṃ vaṭṭatī’’ti attano ānubhāvena taṃ muhuttaṃyeva devaṃ vassāpesuṃ. Piṭṭhipāsāṇo suci nimmalo ahosi. Athassa upari  pañcavaṇṇaṃ pupphavassaṃ vassāpesuṃ. Satthā sāyaṃ jambukājīvakassa santikaṃ gantvā ‘‘jambukā’’ti saddamakāsi. Jambuko ‘‘ko nu kho esa, dujjano maṃ jambukavādena vadatī’’ti cintetvā ‘‘ko eso’’ti āha. ‘‘Ahaṃ samaṇo’’ti. ‘‘Kiṃ mahāsamaṇā’’ti? ‘‘Ajja me ekarattiṃ idha vasanaṭṭhānaṃ dehī’’ti. ‘‘Natthi, mahāsamaṇa, imasmiṃ ṭhāne vasanaṭṭhāna’’nti.
```

<a id="cscd-05-11-u003-p003"></a>

“잠부까여, 그러지 말고 하룻밤 묵을 곳을 내주시오. 출가자는 출가자를 찾고, 사람은 사람을 찾고, 짐승은 짐승을 찾는 법이오.”

```original
‘‘Jambuka, mā evaṃ kari, ekarattiṃ me vasanaṭṭhānaṃ dehi, pabbajitā nāma pabbajitaṃ patthenti, manussā manussaṃ, pasavo pasava’’nti.
```

<a id="cscd-05-11-u003-p004"></a>

“당신도 출가했소?”

```original
‘‘Kiṃ pana tvaṃ pabbajito’’ti?
```

<a id="cscd-05-11-u003-p005"></a>

“그렇소, 출가했소.”

```original
‘‘Āma, pabbajitomhī’’ti.
```

<a id="cscd-05-11-u003-p006"></a>

“출가했다면 박 바가지와 불을 다루는 국자와 제사용 실[^r3-06]은 어디 있소?”

[^r3-06]: 이야기에서 잠부까는 물을 담는 박 바가지, 불을 다루는 국자, 제사용 실을 출가 수행자가 지녀야 할 물건으로 여겼다.

```original
‘‘Sace tvaṃ pabbajito, kahaṃ te lābukaṃ, kahaṃ dhūmakaṭacchuko, kahaṃ yaññasuttaka’’nti?
```

<a id="cscd-05-11-u003-p007"></a>

“그것들은 내게 있소. 하나하나 들고 다니기 번거로워 내 안에 지니고 다니오.”

```original
‘‘‘Atthetaṃ mayhaṃ, visuṃ visuṃ pana gahetvā vicaraṇaṃ dukkha’nti abbhantareneva gahetvā carāmī’’ti.
```

<a id="cscd-05-11-u003-p008"></a>

잠부까는 “결국 그런 물건도 없이 다니시는구려” 하며 화를 냈다. 스승께서 “잠부까여, 그만 화내고 묵을 곳을 알려 주시오”라고 하시자 “큰 수행자여, 여기에 묵을 곳은 없소”라고 했다.


```original
So ‘‘carissasi tvaṃ etaṃ aggaṇhitvā’’ti kujjhi. Atha naṃ satthā āha – ‘‘hotu, jambuka, mā kujjha, vasanaṭṭhānaṃ me ācikkhā’’ti. ‘‘Natthi, mahāsamaṇa, ettha vasanaṭṭhāna’’nti.
```

<a id="cscd-05-11-u003-p009"></a>

스승께서는 잠부까의 거처에서 멀지 않은 바위턱을 가리키며 “저 바위턱 아래에는 누가 사오?”라고 물으셨다. “큰 수행자여, 아무도 없소.” “그렇다면 그곳을 내주시오.” “큰 수행자여, 뜻대로 하시오.” 스승께서는 바위턱 아래 앉을 자리를 펴고 앉으셨다.

```original
Satthā tassa vasanaṭṭhānato avidūre ekaṃ pabbhāraṃ atthi, taṃ niddisanto ‘‘etasmiṃ pabbhāre ko vasatī’’ti āha. ‘‘Natthi koci, mahāsamaṇā’’ti. ‘‘Tena hi etaṃ mayhaṃ dehī’’ti. ‘‘Tvaññeva jāna, mahāsamaṇā’’ti. Satthā pabbhāre nisīdanaṃ paññāpetvā nisīdi.
```

<a id="cscd-05-11-u003-p010"></a>

초저녁에 사천왕이 사방을 환히 비추며 스승을 모시러 왔다. 잠부까는 빛을 보고 ‘무슨 빛일까?’라고 생각했다. 한밤중에 신들의 왕 삭까가 왔다. 잠부까가 그를 보고 ‘저이는 누구일까?’라고 생각했다. 새벽녘에는 손가락 하나로 한 세계를, 둘로 두 세계를, 열 손가락으로 열 세계를 밝힐 수 있는 대범천이 숲을 온통 환히 비추며 왔다. 잠부까는 대범천을 보고도 ‘저이는 누구일까?’라고 생각했다.

```original
Paṭhamayāme cattāro mahārājāno catuddisaṃ ekobhāsaṃ karontā satthu upaṭṭhānaṃ āgamiṃsu. Jambuko obhāsaṃ disvā ‘‘ko obhāso nāmeso’’ti cintesi. Majjhimayāme sakko devarājā āgami. Jambuko tampi disvā ‘‘ko nāmeso’’ti cintesi. Pacchimayāme ekāya aṅguliyā ekaṃ, dvīhi dve, dasahi dasa cakkavāḷāni obhāsetuṃ samattho mahābrahmā sakalaṃ araññaṃ ekobhāsaṃ karonto āgami. Jambuko tampi  disvā ‘‘ko nu kho eso’’ti cintetvā
```

<a id="cscd-05-11-u003-p011"></a>

잠부까는 날이 밝자마자 스승께 다가가 인사하고 한쪽에 서서 물었다. “큰 수행자여, 사방을 비추며 온 이들은 누구입니까?”

```original
pātova satthu santikaṃ gantvā paṭisanthāraṃ katvā ekamantaṃ ṭhito satthāraṃ pucchi – ‘‘mahāsamaṇa, tumhākaṃ santikaṃ catasso disā obhāsento ke āgatā’’ti?
```

<a id="cscd-05-11-u003-p012"></a>

“사천왕이오.”

```original
‘‘Cattāro mahārājāno’’ti.
```

<a id="cscd-05-11-u003-p013"></a>

“무슨 까닭으로 왔습니까?”

```original
‘‘Kiṃ kāraṇā’’ti?
```

<a id="cscd-05-11-u003-p014"></a>

“나를 모시러 왔소.”

```original
‘‘Maṃ upaṭṭhātu’’nti.
```

<a id="cscd-05-11-u003-p015"></a>

“그럼 당신은 사천왕보다 높으십니까?”

```original
‘‘Kiṃ pana tvaṃ catūhi mahārājehi uttaritaro’’ti?
```

<a id="cscd-05-11-u003-p016"></a>

“그렇소, 잠부까여. 나는 그 왕들보다 높은 왕이오.”

```original
‘‘Āma, jambuka, mahārājūnampi atirājā’’ti.
```

<a id="cscd-05-11-u003-p017"></a>

“한밤중에는 누가 왔습니까?”

```original
‘‘Majjhimayāme pana ko āgato’’ti?
```

<a id="cscd-05-11-u003-p018"></a>

“잠부까여, 신들의 왕 삭까요.”

```original
‘‘Sakko devarājā, jambukā’’ti.
```

<a id="cscd-05-11-u003-p019"></a>

“무슨 까닭으로 왔습니까?”

```original
‘‘Kiṃ kāraṇā’’ti?
```

<a id="cscd-05-11-u003-p020"></a>

“나를 모시러 왔소.”

```original
‘‘Maṃ upaṭṭhātumevā’’ti.
```

<a id="cscd-05-11-u003-p021"></a>

“당신은 신들의 왕 삭까보다도 높으십니까?”

```original
‘‘Kiṃ pana tvaṃ sakkadevarājatopi uttaritaro’’ti?
```

<a id="cscd-05-11-u003-p022"></a>

“그렇소, 잠부까여. 나는 삭까보다 높소. 그는 내가 아플 때 나를 돌보고, 율에 맞게 필요한 일을 도와주는 사미와 같소.”

```original
‘‘Āma, jambuka, sakkatopi uttaritaromhi, eso pana mayhaṃ gilānupaṭṭhāko kappiyakārakasāmaṇerasadiso’’ti.
```

<a id="cscd-05-11-u003-p023"></a>

“새벽녘에는 누가 온 숲을 밝히며 왔습니까?”

```original
‘‘Pacchimayāme sakalaṃ araññaṃ obhāsetvā ko āgato’’ti?
```

<a id="cscd-05-11-u003-p024"></a>

“바라문이 재채기를 하거나 발을 헛디딜 때 ‘대범천께 경배합니다’라고 하지 않소? 바로 그 대범천이오.”

```original
‘‘Yaṃ loke brāhmaṇādayo khipitvā pakkhalitvā ‘namo mahābrahmuno’ti vadanti, so eva mahābrahmā’’ti.
```

<a id="cscd-05-11-u003-p025"></a>

“당신은 대범천보다도 높으십니까?”

```original
‘‘Kiṃ pana tvaṃ mahābrahmatopi uttaritaro’’ti?
```

<a id="cscd-05-11-u003-p026"></a>

“그렇소, 잠부까여. 나는 범천보다도 높은 범천이오.”

```original
‘‘Āma, jambuka, ahañhi brahmunāpi atibrahmā’’ti.
```

<a id="cscd-05-11-u003-p027"></a>

“큰 수행자여, 놀랍습니다. 저는 여기서 오십오 년을 지냈지만 그들 가운데 저를 모시러 온 이는 아무도 없습니다. 그 오랜 세월 바람을 먹고 줄곧 서서 지냈는데도 말입니다.”

```original
‘‘Acchariyosi tvaṃ, mahāsamaṇa, mayhaṃ pana pañca paññāsa vassāni idha vasantassa etesu ekopi maṃ upaṭṭhātuṃ nāgatapubbo. Ahañhi ettakaṃ addhānaṃ vātabhakkho hutvā ṭhitakova vītināmesiṃ, na tāva te mayhaṃ upaṭṭhānaṃ āgatapubbā’’ti.
```

<a id="cscd-05-11-u004"></a>
## 잠부까의 참회와 출가

<a id="cscd-05-11-u004-p001"></a>

그러자 스승께서 말씀하셨다. “잠부까여, 분별없는 사람들을 속이더니 나까지 속이려 하느냐? 그대는 오십오 년 동안 똥만 먹고 맨땅에 누웠으며 벌거벗고 다니고 딸라야자 씨 조각으로 머리카락을 뽑지 않았느냐? 그러면서 사람들을 속여 ‘나는 바람을 먹고 한 발로 서 있고 앉지도 눕지도 않습니다’라고 한다. 나까지 속이려 하는가? 그대는 전생에 그릇된 견해를 따랐기에 그토록 오랫동안 똥을 먹고 맨땅에서 자고 벌거벗고 다니며 딸라야자 씨 조각으로 머리카락을 뽑는 처지가 되었다. 지금도 그릇된 견해를 붙들고 있구나.”

```original
Atha naṃ satthā āha – jambuka, tvaṃ lokasmiṃ andhabālaṃ mahājanaṃ vañcayamāno mampi vañcetukāmo jāto, nanu tvaṃ pañcapaññāsa vassāni gūthameva khādi, bhūmiyaṃyeva nipajji, naggo hutvā vicari, tālaṭṭhikhaṇḍena kese luñci. Atha  ca pana lokaṃ vañcento ‘‘ahaṃ vātabhakkho, ekapādena tiṭṭhāmi, na nisīdāmi, na nipajjāmī’’ti vadesi, ‘‘mamampi vañcetukāmosi pubbepi tvaṃ pāpikaṃ lāmikaṃ diṭṭhiṃ nissāya ettakaṃ kālaṃ gūthabhakkho bhūmisayo naggo vicaranto tālaṭṭhikhaṇḍena kesaluñcanaṃ patto, idānipi pāpikaṃ lāmikaṃ diṭṭhimeva gaṇhāsī’’ti.
```

<a id="cscd-05-11-u004-p002"></a>

“큰 수행자여, 제가 무슨 일을 했습니까?”

```original
‘‘Kiṃ pana mayā kataṃ, mahāsamaṇā’’ti?
```

<a id="cscd-05-11-u004-p003"></a>

스승께서는 잠부까가 전생에 저지른 일을 알려 주셨다. 잠부까는 그 말씀을 듣자 이제껏 살아온 일이 두렵고 절박하게 다가왔다. 부끄러움과 잘못을 두려워하는 마음이 일어 쪼그려 앉았다. 스승께서 목욕할 때 두르는 천을 던져 주시니 그것을 두르고 절한 뒤 한쪽에 앉았다. 스승께서는 차례를 밟아 법을 설하셨다. 설법이 끝나자 잠부까는 무애해와 함께 아라한과를 얻었다. 스승께 절하고 앉은 자리에서 일어나 출가와 구족계를 청했다.

```original
Athassa satthā pubbe katakammaṃ ācikkhi. Tassa satthari kathenteyeva saṃvego uppajji, hirottappaṃ upaṭṭhitaṃ, so ukkuṭiko nisīdi. Athassa satthā udakasāṭikaṃ khipitvā adāsi. So taṃ nivāsetvā satthāraṃ vanditvā ekamantaṃ nisīdi. Satthāpissa anupubbiṃ kathaṃ kathetvā dhammaṃ desesi. So desanāvasāne  saha paṭisambhidāhi arahattaṃ patvā satthāraṃ vanditvā uṭṭhāyāsanā pabbajjañca upasampadañca yāci.
```

<a id="cscd-05-11-u004-p004"></a>

이때 그의 지난 업은 다했다. 그는 번뇌가 다한 큰 장로를 네 가지 말로 모욕했다. 이 큰 땅이 한 요자나하고도 세 가우따[^r3-07]만큼 높아질 때까지 아위찌 지옥에서 고통받았다. 그 과보가 남아 오십오 년 동안 이런 삶을 보낸 뒤에야 그 업이 다했다. 그가 이만 년 동안 한 수행의 결실은 그대로 남아 있었다. 그래서 스승께서는 오른손을 내미시며 “오라, 비구여. 괴로움을 바르게 끝내기 위하여 청정한 삶을 살라”라고 하셨다. 그 즉시 출가하기 전의 모습이 사라졌다. 그는 여덟 가지 필수품을 갖춘, 육십 안거[^r3-08]를 지낸 큰 장로의 모습으로 바뀌었다.

[^r3-07]: 요자나와 가우따는 옛 인도의 길이 단위다. 한 요자나는 네 가우따다. 앞에서 한 붓다와 다음 붓다 사이라고 한 세월을 여기서는 땅의 높이가 달라질 만큼 오랜 기간으로 그린다.
[^r3-08]: 안거는 우기에 한곳에 머물러 수행하는 기간이다. 이 주석은 막 비구가 된 잠부까의 모습을 육십 안거를 지낸 장로에 비유한다. 《테라가타》 주석은 예류과를 얻고 구족계를 받은 뒤 통찰을 닦아 아라한이 되었다고 전한다. [《테라가타》 주석](https://epitaka.org/my/book/Th-a-ii/5-jambukattherag%C4%81th%C4%81va%E1%B9%87%E1%B9%87an%C4%81-133)


```original
Ettāvatā tassa purimakammaṃ parikkhīṇaṃ. Ayañhi khīṇāsavamahātheraṃ catūhi akkosehi akkositvā yāvāyaṃ mahāpathavī tigāvutādhikaṃ yojanaṃ ussannā, tāva avīcimhi paccitvā tattha pakkāvasesena pañcapaññāsa vassāni imaṃ vippakāraṃ patto. Tenassa taṃ kammaṃ khīṇaṃ. Vīsati pana vassasahassāni iminā katassa samaṇadhammassa phalaṃ nāsetuṃ na sakkā. Tasmā satthā dakkhiṇahatthaṃ pasāretvā ‘‘ehi, bhikkhu, cara brahmacariyaṃ sammā dukkhassa  antakiriyāyā’’ti āha. Tāvadevassa gihiliṅgaṃ antaradhāyi aṭṭhaparikkhāradharo saṭṭhivassikamahāthero  viya ahosi.
```

<a id="cscd-05-11-u004-p005"></a>

마침 앙가와 마가다 사람들이 공양물을 가지고 찾아오는 날이었다. 두 나라 사람들이 공양물을 가지고 와서 여래를 보고 생각했다. ‘우리 잠부까 존자와 사문 고따마 가운데 어느 분이 더 높을까? 사문 고따마가 더 높다면 잠부까가 찾아갔을 것이다. 사문 고따마가 아지와까 잠부까를 찾아온 것을 보면 잠부까가 더 높은 모양이다.’

```original
Aṅgamagadhavāsīnaṃ tassa sakkāraṃ gahetvā āgatadivaso kiresa, tasmā ubhayaraṭṭhavāsino sakkāraṃ gahetvā āgatā tathāgataṃ disvā ‘‘kiṃ nu kho amhākaṃ ayyo jambuko mahā, udāhu samaṇo gotamo’’ti cintetvā ‘‘sace samaṇo gotamo mahā bhaveyya, ayaṃ samaṇassa gotamassa santikaṃ gaccheyya, jambukājīvakassa pana mahantatāya samaṇo gotamo imassa santikaṃ āgato’’ti cintayiṃsu.
```

<a id="cscd-05-11-u004-p006"></a>

스승께서 사람들의 생각을 아시고 말씀하셨다. “잠부까여, 그대를 후원해 온 사람들의 의심을 풀어 주어라.” 그는 “존자시여, 저도 그 말씀을 기다렸습니다” 하고 넷째 선정에 들었다. 선정에서 나와 딸라야자나무 한 그루 높이만큼 공중에 올라 “세존께서 제 스승이시고 저는 세존의 제자입니다”라고 했다. 내려와 절한 뒤 다시 두 그루, 세 그루 높이로 솟구쳤다. 그렇게 일곱 그루 높이까지 올라갔다 내려오며 자신이 붓다의 제자임을 알렸다. 사람들은 ‘놀랍구나, 붓다들은 비길 데 없는 덕을 갖추셨구나’ 하고 생각했다.

```original
Satthā mahājanassa parivitakkaṃ ñatvā, ‘‘jambuka, tava upaṭṭhākānaṃ kaṅkhaṃ chindāhī’’ti āha, so ‘‘ahampi, bhante, ettakameva paccāsīsāmī’’ti vatvā catutthajjhānaṃ samāpajjitvā uṭṭhāya tālappamāṇaṃ vehāsaṃ abbhuggantvā ‘‘satthā me, bhante bhagavā, sāvakohamasmī’’ti vatvā oruyha vanditvā puna dvitālamattaṃ titālamattanti evaṃ sattatālamattaṃ vehāsaṃ abbhuggantvā oruyha attano sāvakabhāvaṃ jānāpesi. Taṃ disvā mahājano ‘‘aho buddhā nāma acchariyā anopamaguṇā’’ti cintesi.
```

<a id="cscd-05-11-u004-p007"></a>

스승께서는 사람들에게 말씀하셨다. “이 사람은 오랫동안 그대들이 가져온 공양을 꾸사 풀 끝에 묻혀 혀끝에 대면서 ‘고행을 합니다’라고 하며 여기에 살았다. 이제 이 사람은 먹을 때가 맞는지, 그 음식이 율에 맞는지 확신이 서지 않으면 한 끼를 삼간다. 예전 방식으로 백 년을 고행해도 이렇게 삼가는 선한 의도의 열여섯 몫 가운데 한 몫에도 미치지 못한다.” 스승께서는 이어 다음 게송을 설하셨다.

```original
Satthā mahājanena saddhiṃ kathento evamāha – ‘‘ayaṃ ettakaṃ kālaṃ tumhehi ābhataṃ sakkāraṃ kusaggena jivhagge ṭhapetvā ‘tapacaraṇaṃ pūremī’ti idha nivuṭṭho, sacepi iminā upāyena vassasataṃ tapacaraṇaṃ pūreyya, yā cassa idāni kālaṃ vā bhattaṃ vā kukkuccāyitvā abhuñjantassa bhattacchedanakusalacetanā, tassā taṃ tapacaraṇaṃ soḷasiṃ kalampi na agghatī’’ti anusandhiṃ ghaṭetvā dhammaṃ desento imaṃ gāthamāha –
```

<a id="cscd-05-11-u005"></a>
## 제70게와 고행보다 큰 선한 의도의 결실

<a id="cscd-05-11-u005-v001"></a>

<pali-poem>

> **제70게**  
> 어리석은 이가 달마다  
> 꾸사 풀 끝으로 음식을 먹는다 해도  
> 법을 분명히 아는 이들의  
> 열여섯 몫 가운데 한 몫에도 미치지 못한다[^r3-09].

[^r3-09]: 이 게송은 법을 분명히 아는 이를 기준으로 견준다. 파트나의 평행 게송은 승가에 대한 믿음을, 《우다나바르가》와 《마하와스뚜》의 평행 게송은 붓다에 대한 믿음을 기준으로 든다. [평행 게송 빨리어·산스크리트어 원문](https://ancient-buddhist-texts.net/Buddhist-Texts/C3-Comparative-Dhammapada/CD-05-Bala.htm)

```original
70.
‘‘Māse māse kusaggena, bālo bhuñjeyya bhojanaṃ;
Na so saṅkhātadhammānaṃ, kalaṃ agghati soḷasi’’nti.
```

</pali-poem>

<a id="cscd-05-11-u005-p001"></a>

뜻은 이렇다. 법을 알지 못하고 계행을 비롯한 덕을 갖추지 못한 어리석은 이가 다른 교단에 출가한다. ‘고행을 하겠다’고 마음먹고 달마다 꾸사 풀 끝으로 음식을 먹으며 그렇게 백 년을 지낸다고 하자. ‘법을 분명히 아는 이들의 열여섯 몫 가운데 한 몫에도 미치지 못한다’에서 ‘법을 분명히 아는 이들’이란 가르침의 뜻을 분명히 아는 사람들이다. 예류자부터 번뇌를 다한 아라한까지를 가리킨다. ‘어리석은 이는 법을 분명히 아는 이들의 열여섯 몫 가운데 한 몫에도 미치지 못한다’라는 말에서 게송은 두 부류의 사람을 견준다.

```original
Tassattho  – sace bālo apariññātadhammo sīlādiguṇā paribāhiro titthāyatane pabbajito ‘‘tapacaraṇaṃ pūressāmī’’ti māse māse patte kusaggena bhojanaṃ bhuñjanto vassasataṃ bhuñjeyya  bhojanaṃ. Na so saṅkhātadhammānaṃ, kalaṃ agghati soḷasinti saṅkhātadhammā vuccanti ñātadhammā tulitadhammā. Tesu heṭṭhimakoṭiyā sotāpanno saṅkhātadhammo, uparimakoṭiyā khīṇāsavo. Imesaṃ saṅkhātadhammānaṃ so bālo kalaṃ na  agghati soḷasinti puggalādhiṭṭhānā desanā.
```

<a id="cscd-05-11-u005-p002"></a>

여기서 뜻하는 바는 이렇다. 주석은 그들이 품는 의도를 견준다. 한 사람은 고행하려는 의도를 백 년 동안 이어 간다. 또 한 사람은 법을 분명히 알기에, 먹을 때가 맞는지 그 음식이 율에 맞는지 분명치 않으면 한 끼를 삼가겠다는 선한 의도를 일으킨다. 백 년 동안 이어 온 고행의 의도는 한 끼를 삼가는 이 선한 의도의 열여섯 몫 가운데 하나에도 미치지 못한다. 그 선한 의도의 결실을 열여섯 몫으로 나눈 뒤 각 몫을 다시 열여섯으로 나누면 모두 이백쉰여섯 몫이 된다. 그중 한 몫도 어리석은 이의 백 년 고행이 낳는 결실보다 크다는 뜻이다.


```original
Ayaṃ panettha attho – yā cassa tathā tapacaraṇaṃ pūrentassa vassasataṃ cetanā yā ca saṅkhātadhammānaṃ kālaṃ vā bhattaṃ vā kukkuccāyitvā abhuñjantānaṃ ekā bhattacchedanakusalacetanā, tassā cetanāya sā tāva dīgharattaṃ pavattacetanā soḷasiṃ kalaṃ na agghati. Idaṃ vuttaṃ hoti – yaṃ tassā saṅkhātadhammānaṃ cetanāya phalaṃ, taṃ soḷasa koṭṭhāse katvā tato ekekaṃ puna soḷasa soḷasa koṭṭhāse katvā tato ekassa koṭṭhāsassa yaṃ phalaṃ, tadeva tassa bālassa tapacaraṇato mahapphalataranti.
```

<a id="cscd-05-11-u005-p003"></a>

설법이 끝나자 팔만 사천 중생이 법을 깨달았다.

```original
Desanāvasāne caturāsītiyā pāṇasahassānaṃ dhammābhisamayo ahosīti.
```
