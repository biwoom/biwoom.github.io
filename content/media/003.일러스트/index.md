# 일러스트

아래 두 항목은 하나의 index.md에 여러 이미지의 정보를 적는 예시입니다. 이미지 제목은 대괄호 안에, 실제 파일 경로는 소괄호 안에 작성합니다. 설명은 자유롭게 여러 문단으로 추가할 수 있습니다.

확인된 정보가 있으면 다음과 같이 본문에 추가할 수 있습니다. 이 코드 예시는 모달에 표시되지 않습니다.

```markdown
## [이미지 제목](이미지파일.png)

이미지 설명을 작성합니다.

- 제작자: 확인된 이름
- 제작일: 확인된 날짜
- 이용조건: 확인된 이용조건

### 출처

[출처 이름](https://example.com/)
```
